## Что проверено
Исходные изображения не перерисованы: фигуры из третьего ряда новых листов отображаются через SVG-окна, равномерно масштабируются, сохраняют пропорции и ставятся на одну землю. Для каждой фигуры вручную указан ориентир макушки без покрова и нижняя опора, затем масштаб вычислен по двум ориентирам. Численная проверка всех пяти высот — `scale-check.json`; рендер PNG просмотрен, устранены попавшие в окна соседние части листов.

Оранжевые штрихи обозначают макушки. У ежа макушка скрыта покровом частично, поэтому анатомическая точка — авторская интерпретация рисунка, не замер черепа модели. Привязка рисунка к точкам имеет небольшую художественную погрешность; одна математическая шкала и отношения заданных ростов проверены.

## Границы точности
- Рост — целевое решение, а не сегодняшнее измерение сборки в игре. Рост по массе в источнике ещё не был подключён к сборке.
- Ширина/глубина не растянуты отдельно ради заполнения схемы. Это пропорции принятых рисунков, а не подтверждённый габарит текущего меша. Особенно у ежа и змеи численных поставок ширины/глубины нет.
- Рога, уши, иглы и трубки сохранены по рисункам, поэтому их верх может расходиться с приблизительными игровыми общими габаритами из письма. В частности рога здесь доходят примерно до 3.4 м, не до упомянутых в письме ≈3.6 м. Схема явно задаёт рост тела до макушки; новых точных размеров аугментов не утверждает.
- Змея — художественная цель ст.2, пока недостижимая в текущих правилах. Второе письмо уточняет: с хвостом в химерном слоте возможна ст.1, не ст.2. На схеме статус подписан. Погремушка на старой иллюстрации не означает её доступность человеку.
- Детали формы и органов на схеме наследуют исходные листы. Она не является новой поставкой анатомии и не отменяет замечания по каталогам аугментов.

## Воспроизведение
`build.py` читает исходные PNG, анализирует область рисунка и составляет SVG с внедрёнными изображениями; исходные PNG не меняются. `render.cjs comparison` переводит SVG-схему в PNG через bundled sharp. `anchors.json` фиксирует исходные координаты опоры/макушки. Среда: Anaconda Python с Pillow/numpy/scipy; Node/sharp из рабочего runtime.
