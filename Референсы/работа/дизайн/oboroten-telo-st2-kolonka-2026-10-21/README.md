# Голое тело оборотня ст.2 по принятой колонке

21.10.2026. Кандидат дизайн-линии на приёмку геймдизайнером; не новая витрина и не автоматически утверждённая цель 3D.

**Основной лист — `body-aligned.png`: анфас, левый профиль лицом влево, передний 3/4.** Матовая серая low-poly кожа, без гривы, всего длинного меха и хвоста; волчья голова, уши, кисти и лапы сохранены. Короткое тёмное бельё закрывает таз. Фигура целиком, ровный светлый фон без тени на полу. Руки немного отведены для просвета подмышек. Звериный наклон головы и согнутая опора намеренно сохранены: выпрямление в человеческую стойку меняло исходный силуэт.

## Источник и сверка

Источник — **только колонка ст.2** `Референсы/витрина/оборотень/ступени.png`. Копия исходного ряда — `source-stupeni.png`; точное окно третьей колонки без перерисовки — `source-column-st2.png` и SVG. Старый снятый лист `stupen-2-lowpoly-r2` не использовался.

`comparison.png` показывает исходную колонку рядом с новым голым телом. Это обзор для зрительной сверки, не наложение силуэтов в одном масштабе; в нём исходник вертикальный, а результат горизонтальный. Для размеров игры действует принятая шкала морфов, не заполнение страницы.

Авторская сверка перед передачей:

| Область | Что сохранено / уточнено |
| --- | --- |
| Общий характер | Поджарый двуногий зверь; узкие бока и таз, массивный верх бедра, лёгкий дистальный отдел; не прежний человеческий атлет с головой волка |
| Грудная клетка | Клин сходящихся плоскостей к животу; в профиль клетка глубокая, живот втянут. Не переносить на меш парные человеческие грудные шары из отвергнутого первого прохода |
| Голова и шея | Голова подана вперёд, шея выходит из лопаточных масс. Меховой воротник снят; его внешний контур не приравнивается к голому загривку |
| Ноги и лапы | Сохранена характерная согнутая цепь исходной ст.2; первые два прохода с выпрямленным и утяжелённым низом отклонены |
| Плечевой пояс | Последний проход уменьшил массу загривка и плечевых вершин, которую генерация ошибочно оставляла от гривы. Эта область требует особенно внимательной приёмки в профиль |
| Чистота листа | Три ракурса, одна пара ушей, нет меха и хвоста, нет теней, лапы и уши не обрезаны |

Масса под мехом — художественная интерпретация по `D-dizajn.md` §2: глубокие рёбра, две наклонные лопаточные массы, мускулистое основание шеи, втянутый живот. Скрытую анатомию невозможно буквально извлечь из мехового PNG; это реконструкция, а не замер существующего голого тела. Полного совпадения невидимой геометрии не обещаю.

## Высота и точность ракурсов

`body.png` — неизменённый результат ImageGen последнего прохода (1774×887). Найденные границы фигур — `view-bounds.json`: высоты 792 / 801 / 796 px по порогу max RGB < 210. Генеративный разброс около 1% устранён **только равномерным масштабированием каждого ракурса** при компоновке SVG; отдельные части тела не растягивались.

В `body-aligned.svg` / PNG (1800×900) верхние опорные точки находятся на Y=50, нижние — на Y=850, интервал 800 px для всех трёх. За границей порога сохранён запас, сглаженные крайние пиксели могут отличаться на 1–2 px. Это выравнивание листа, не гарантия геометрического соответствия ракурсов: длина морды, разворот пальцев и дальняя рука остаются генеративными. Профилю верить в глубине груди, втягивании живота и опоре; анфас — в ширине талии и постановке ног; 3/4 — в соединении объёмов. Не усреднять противоречащие детали автоматически.

Перед необратимым выбором цели для Hunyuan нужна приёмка геймдизайнера, особенно шеи/лопаток: в исходнике они частично скрыты гривой. Силуэт в игровом тумане этим листом не тестировался.
