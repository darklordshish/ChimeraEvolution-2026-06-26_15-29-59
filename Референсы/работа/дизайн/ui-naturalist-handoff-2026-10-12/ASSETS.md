# Графика и её готовность

**Готово сейчас:** выбранный концепт, композиционная схема, перечень состояний и стартовые визуальные параметры. **Не готово:** отдельные производственные спрайты, шрифтовой набор, атлас иконок, схема звёзд на каждый вид, интерактивный макет. Не импортировать концепт целиком как интерфейс.

| Группа | Что подготовить | Требования |
|---|---|---|
| Бумага | Фон страницы, светлая вставка, сгиб, край | Без текста и рисунков органов; края отдельно, пригодны для масштабирования |
| Орнамент | Редкие растения, поля, штрихи | Отдельный слой, легко отключить на малом экране |
| Атлас видов | Человек, волк, змея, лось, ёж | Иллюстрация отдельно от узлов; силуэты из утверждённых референсов; без подписей и звёзд в текстуре |
| Узлы | Обычный, выбранный, установленный, отказ, перенос | Отдельные графические признаки; крупная невидимая область захвата задаётся UI |
| Органы | Иконки по реальным вариантам органов | Без цифр/текста; единый тушевой язык; не считать тип слота единственной иконкой всех вариантов |
| Тело | Лысая базовая фигура и отображение сборки | Не запекать неизменное человеческое тело поверх изменённых органов; способ отображения согласовать с механиками/модельной |
| Гнёзда | Обычное, химерное, пустое, занятое, фокус, допустимое, отказ | Состояния собираются слоями; текст и цена отдельно |
| Навигация | Закладки, поиск, приближение, назад, закрыть | Одинаковая толщина штриха; без встроенных букв клавиш |
| Ресурсы | Тушевые шкалы, рамка, штриховка предпросмотра | Заливка и фон отдельно; числа динамические |
| HUD | Ресурсы, приёмы, сенсорные каналы, статусы | Согласовать с общей игровой легендой, не красить всё в сепию |
| Шрифты | Кириллица, цифры, знаки, fallback | Выбрать лицензионно пригодные файлы; проверить ё/й, минус, ×, стрелки и малые размеры |

Для крупных иллюстраций — прозрачный PNG с запасом около ×2 от целевого отображения; точный размер после фиксации макета. Для маленьких пиктограмм исходники с прозрачностью и несколькими контрольными размерами. Простые рамки и линии предпочтительно строить средствами UI, а не растягивать нарисованные углы. Окончательные формат, упаковка и импорт — ответственность исполнителя.

Обязательная поставка каждого графического набора: исходник, экспорт, назначение, размеры, прозрачность, известные ограничения. Рисунок звёзд — отдельные координаты относительно карточки вида, сопоставленные реальным органам; формат этих данных определяет механическая линия, не этот документ.

Будущие биомы в первом рабочем срезе не требуют выдуманных органов/иконок. Не добавлять в текущий каталог орла/скорпиона только потому, что они присутствуют на концепте.
