# Интерфейс CHIMERA — подготовка к реализации

12.10.2026 · дизайн-линия. Пакет передачи по выбранному геймдизайнером концепту. **Это подготовка, код интерфейса не изменён.**

## Что выбрано

Геймдизайнер выбрал общий стиль **«Заметки натуралиста»** для конструктора, боевого HUD, меню и инструментов исследования. Для конструктора — **асимметричный разворот: большой атлас слева и неподвижный лист тела с лысым человеком справа**, химерные гнёзда под ним.

Визуальная опора: [выбранный концепт](../augumenty-naturalist-kompozicii-2026-10-12/02-atlas-otkidnoj-list.png). Витрина этим пакетом не меняется. Ранее показанные «Карантин», центральное тело и гербарий остаются вариантами истории, не равноправными целями реализации.

**Утверждены стиль и общая композиция.** Приведённые далее размеры, детализация взаимодействий, графические компоненты и этапы — предложения дизайн-линии для реализации и проверки. Они не объявляют новую утверждённую спеку и не меняют правила аугументов.

## Исправления относительно картинки

Ввести всегда доступный источник человеческих органов. Географическую подложку сильно приглушить: это каталог видов, не карта мира. Звёзды должны быть контрастны на бумаге. Одному органу соответствует один интерактивный узел; декоративные точки явно слабее и не выглядят кнопками. Видимые подписи, цены и доступность берутся из реальной сборки.

Лысый человек — базовая анатомическая фигура без навязанной причёски. Его образ на листе не отменяет отображения установленного состава: не показывать вечного чистого человека после изменения тела. Способ получения такого изображения решает реализация; до него использовать честный схематический силуэт с органными маркерами.

## Первый результат, который стоит принимать

Рабочий конструктор с выбранным разворотом на существующих лесных донорах и человеке: источник → гнездо → расчёт → результат. Сначала убедиться, что он удобен без декоративной графики; затем подключить рисунки. Боевой HUD и остальные меню получают тот же стиль отдельными следующими срезами.

Пакет не содержит готового набора спрайтов или интерактивного прототипа. **Разрезать концепт PNG и переносить его подписи в игру нельзя:** в нём смешаны фон, надписи, рисунки и иллюстративные числа.
