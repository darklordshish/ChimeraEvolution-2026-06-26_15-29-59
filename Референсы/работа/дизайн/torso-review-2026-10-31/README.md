# Грудь и живот: разбор перед правкой

31.10.2026. Запрошенное геймдизайнером сравнение: актуальный утверждённый поджарый человек (витрина общей папки `ChimeraEvolution`, версия от 30.10), текущий экспериментальный меш, предложение направлений перелома. **Геометрия не менялась.**

- `comparison.png` — обзор; `comparison.svg` — та же схема с отдельными векторными линиями и встроенными исходными кропами.
- `lines.json` — координаты линий в исходном рендере, рамки кропов и SHA-256 источников.
- `draw_diagram.py` — воспроизводимое построение схемы (Anaconda/Pillow). Персонаж не перерисован генератором.

Рендер снят с `Experiments/shoulder-local-2026-10-31/candidate.blend`, Поджарый=1, коррекция плеч выключена, руки опущены. Команда получения исходного рендера — `Experiments/shoulder-local-2026-10-31/render_torso_review.py`. Эта схема не показывает, как будет выглядеть новая геометрия: линии обозначают только предлагаемое направление смены плоскостей.

Предложение: собрать нижнюю границу грудных без отдельных острых зубцов; уточнить рёберную дугу и отделить её от рельефа живота; добавить читаемую центральную ось и два коротких поперечных перелома пресса. Это не запрос углублять все линии, делать грудь бронепластиной или наращивать мышцы. Существующую массу широчайших сохранять. У актуального листа также много диагональных граней — сами по себе диагонали не дефект; важна их иерархия по массам.

**Ограничения:** свет, пропорции и масштаб кропов источников различаются, фигуры не зарегистрированы по анатомическим точкам. Сравнивать читаемость масс, не измерять миллиметры или IoU по этой схеме. Локальная витрина ветки содержит более старый лист: для этой работы использован актуальный файл из общей папки только на чтение. Витрина, игровые данные и меш не менялись.

## Уточнение r2 — кубикам быть

По уточнению геймдизайнера действует прямое требование задачи от 30.10: «Пресс у поджарого кубиками — это верно (жира нет); плохо только объём культуриста». Предыдущая разметка двух коротких поперечных переломов недостаточна и заменена для пресса на `comparison-r2.png` / `.svg`, `lines-r2.json`, `draw_diagram_r2.py`.

Показаны три пары отдельных масс с центральным разделением, умеренным выступанием и наклонными боковыми плоскостями. Замкнутые голубые контуры обозначают область каждой массы, **не прорезь и не шов отдельной детали**. Размеры контуров — предложение рисунка, не измеренный 3D-чертёж. Меш не менялся.
