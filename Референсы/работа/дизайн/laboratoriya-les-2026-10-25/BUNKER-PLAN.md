# Бункер-лаборатория: план и художественная спецификация для Лесника
25.10.2026 · дизайн-линия · черновик компоновки для сборки и проверки.

## 1. Что является решением
Из B0.1 (`Docs/superpowers/specs/2026-10-24-forest-lab-complex.md`, рабочая папка Лесника): единый комплекс **46×36 м**, четыре функции вокруг центра, ходибельность, двери ≥2 м, тёплый свет, обе камеры; место по сиду, не ближе 150 м от входа. Адрес маршрута — **LabDoor**, а не центр здания.

Новое прямое уточнение геймдизайнера в этом чате: «это не важно, вопрос входа, а внутри что так, что так». После описания закрытого центрального зала, хирургии, клеток, арены и отдыха, без открытого неба и внутреннего сада, ответил: «да, сделаешь?».
**Следствие для художественной цели:** один закрытый интерьер для подземного и скального размещения, сплошное перекрытие и искусственный свет. Не создавать отдельную пещерную планировку.

Это расходится с открытым атриумом Bastion в B0.1. Леснику/координатору оформить преемственность решения перед реализацией; дизайн-линия тело принятой спеки не редактирует. Точные размеры комнат ниже — сохранённое предложение §4.1, не новое утверждение геймдизайнера.

## 2. План: один уровень, связанные помещения
Фасад условно на юге; поворот всего здания при размещении не меняет внутренних связей.

```text
                         СЕВЕР
       ┌──────────────────────────────────────┐
       │ АРЕНА: свободный испытательный зал    │ 8.5
       ├───────────┬──────────────┬───────────┤
       │ ХИРУРГИЯ  │ крытый обход │  КЛЕТКИ   │
       │           │ ┌──────────┐ │           │
       │ 13.5 × 19 │ │ ЗАКРЫТЫЙ │ │13.5 × 19 │ 19
       │           │ │ ЗАЛ 14²  │ │           │
       │           │ └──────────┘ │           │
       ├───────────┴──────┬───────┴───────────┤
       │ ОТДЫХ сбоку      │ входной проход    │ 8.5
       └──────────────────┴───────────────────┘
                         LabDoor
                         ЮГ / ЛЕС
       ←──────── внешнее пятно 46 м ────────→
                     глубина 36 м
```

Здесь «14²» означает квадрат **14×14 м**, а не площадь 14 м².
Схема показывает функциональные полосы, не толщины стен. Центральная зона с обходом: 19×19 = 14 + 2×2.5 по каждой оси; боковые полосы: 13.5+19+13.5=46; продольные: 8.5+19+8.5=36. **Номинальные полосы включают будущие стены:** чистые размеры при раскладке уменьшатся. Нельзя одновременно обещать все эти числа как чистые внутренние размеры и пятно 46×36.

В северном и южном крыльях номинально 46×8.5. Длинная форма арены остаётся открытым вопросом старой спеки: не считать её принятой только потому, что она нарисована здесь.
Высота комнат 3.6 м, обход 2.5 м, вход 3 м, внутренние двери 2 м/высотой 2.6 — предложения §4.1, **не гарантированные габариты для всех химер**. Высоту перекрытия центрального зала следует выбрать отдельно: старые 8 м открытого атриума не становятся автоматически высотой закрытого зала.

### Связи
Вход → отдельная полоса движения южного крыла → общий зал/обход → четыре крыла. Место сна располагается сбоку от транзита. Путь к хирургии не проходит через клетки; путь к выходу не проходит через арену. Обход — свободная полоса, не узкий коридор между решётками.
Центр зала свободный, без колонны на постаменте. Если расчёт геометрии требует опор, сначала размещать их по периметру; не переносить автоматически колонну генератора из кадров 06/07.
Все переходы на одном уровне. Стол, табурет, открытая дверь и решётка не сужают требуемый проход. Вид через стекло не считается связью помещений.

## 3. Назначение и композиция комнат
| Комната | Основная масса | Второстепенное | Проход и свет |
|---|---|---|---|
| Общий зал | перекрытие, крупные балки, открытый пол | простые сиденья у стен | холодный искусственный общий свет; тёплые входы в крылья |
| Хирургия | один стол, стеклянная перегородка | тумба, шкаф, закрытые лотки, журнал | обход стола с доступом к двери; тёплая рабочая лампа |
| Содержание | глубокие отсеки, бетонные разделители, повтор решёток | низкие места отдыха животных, поилки по будущим видам | свободный служебный проход; холодный общий свет, локальные тёплые маркеры |
| Отдых | две низкие лежанки в нишах | шкафчики, стол, бумажные записи | спальные места в стороне от транзита; мягкий тёплый свет |
| Арена | пустой протяжённый пол | оборудование позднее | ровная читаемость пола и выхода; не добавлять бой/спавнер в художественный пакет |

Клетки на 07 местами выглядят как камеры для людей из-за раковин и лежанок. **Раковины не копировать**: для животных нужны функциональные низкие поилки/настилы, конкретные размеры зависят от вида. Три отсека на кадре — ритм для эскиза, не вместимость комплекса и не доказательство пригодности для лося.
Клетки остаются пустыми в текущем срезе. Специальные игровые функции мебели, отдых как лечение, взаимодействие с журналом и управление воротами этим документом не вводятся.

## 4. Единый low-poly язык
Большие плоские поверхности, редкие фаски, прямоугольный ритм несущих элементов. Мебель проще стен по числу мелких деталей. Крупные грани особенно видны на столах, сиденьях, светильниках и тканях.
Бетон холодный серый; металл угольно-серый; стекло приглушённое; оливковая ткань только в отдыхе. Ржавчина акцентами. Пол матовый: не переносить зеркальные блики из генерации.
Искусственный свет визуально имеет источник — подвесная панель, настенный светильник, рабочая лампа. Нет отверстия в потолке, замаскированного под светильник. Контраст «холодный путь / тёплая функция» помогает ориентации; не делать всю сцену оранжевой.
Нет внутренних деревьев, пещерных стен, неба, многоэтажных мостов и ям. Не заполнять пустоту ящиками. Научная атмосфера — через наблюдение, записи и рабочее оборудование, а не кровь и хирургические импланты.

## 5. Чему верить на изображениях
Актуальный набор: **05 общий зал · 06 хирургия · 07 клетки · 08 отдых**. 01–04 — история, не текущий интерьер.
Для свободного центра верить **05**. На 06 и 07 генератор повторил лишнюю опору/постамент; для модели она не задана. На 08 видимость клеток через дверь означает соседство через общий зал, а не обязательное прямое совмещение осей дверей. Не снимать метры с перспективы и не считать кадры согласованной моделью.

## 6. Передача в работу и проверка
1. Серый блокинг одного уровня по полосам плана; показать чистые размеры после учёта стен и реальных дверей.
2. Проверить маршрут LabDoor → каждое крыло → LabDoor и обе камеры. Проверить крупнейшее доступное тело и его капсулу, а не только человека; минимум 2 м сам по себе не гарантирует проход.
3. Снять общий зал, хирургическое рабочее место, проход клеток и отдых в одинаковом свете. На уменьшенных кадрах должны различаться функции, путь и реальные дверные проёмы.
4. Добавить крупную мебель, затем свет; мелкий реквизит последним. Сравнить свет без текстур: если всё сливается, не лечить деталями.
5. Проверить второй наружный облик на том же внутреннем плане, не меняя размеры ради картинки.
6. NavMesh, коллизия камеры, тени и бюджет света — проверки реализации Лесника. Арты их не подтверждают; бюджет ламп и технический способ затенения здесь не назначаются.
