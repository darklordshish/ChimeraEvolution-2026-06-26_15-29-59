# Пресс r2 — переходы в живот

31.10.2026. По просьбе геймдизайнера доведён предыдущий кандидат пресса. **Форма для визуальной оценки, не утверждённый игровой меш.**

- `comparison.png`: r1 сверху / r2 снизу; анфас, 3/4, профиль, одинаковые камеры, свет и масштаб.
- `poses.png`: r2 в покое, наклоне 25°, разгибании 15°, скручивании 30°.
- `before_rest_*.png`, `after_rest_*.png`: полные ракурсы до/после.
- `original_*.png`, `abs_*.png`: r1/r2 в тех же диагностических позах.
- Все кадры — реальные Blender-рендеры геометрии, без генерации или ретуши.

## Форма

Три пары сохранены. Замкнутый скос по контуру каждой массы заменён более непрерывной выпуклостью, связанной с общей кривизной передней стенки живота. Верхняя пара немного расширена, нижняя сужена, поперечные переходы слегка изогнуты. Цель — читаемые кубики без шести одинаковых накладок. Полностью сглаживать рельеф не предлагается.

Изменён только ключ «Поджарый» на 101 внутренней вершине живота; максимальное смещение ≈11.48 мм. Топология, база, остальные ключи, веса и кости побитно сохранены. Исходные внешние/граничные вершины участка сохранены. **Треугольников 5894, новых не добавлялось.** Геометрия грудных и широчайших в этом проходе не менялась. Существующая ломаная рёберная дуга над верхней парой ещё заметна; r2 не заявляется исправлением всей груди.

## Проверка

`verification.json`: ошибок 0. Экспорт FBX проверил веса и согласованность швов — нарушений 0. После повторного импорта в покое разворотов/складок/сжатий — 0, швы — 0 мм.

В передней области живота четырёх диагностических поз r1 и r2: отрицательных ориентационных флагов — 0, граней с площадью <25% исходной — 0. Максимальный разрыв швов ≈0.000045 мм, погрешность вычислений. См. `motion.json`.

Позы выполнены в Blender реальными костями живота и грудной клетки, угол разделён пополам; верхний пояс следует за грудной клеткой. Это не игровые анимации, не проверка самопересечений и не приёмка выключенной позовой коррекции плеч. Критерий технической целостности не заменяет художественную оценку новой формы.
