# Ресёрч 04.11: многоугольники с листа огранки и подгонка вершин

**Вывод.** Брать сейчас: `scipy.optimize.least_squares(loss='huber')` и `scikit-image` (felzenszwalb/SLIC) как проверку порога по линиям, OpenCV LSD как вторую руку для рёбер. Не брать: PolyFit, libigl-ARAP внутрь пайплайна, Quad Remesher. Главное: готового инструмента «несогласованные ортовиды → low-poly по граням листа» не нашли (не годится ничего), наш конвейер (скелет → RDP → лучи → Делоне → Хубер) уже ближе к задаче, чем любая найденная статья. Retopoflow бесплатен лишь условно (см. ниже). Даты «живости» взяты из GitHub API 04.11.2026.

## 1. Многоугольники с плоско затенённой картинки
- **Сегментация по тону: scikit-image `felzenszwalb`, `slic`, `quickshift`.** Плоские грани дают почти однотонные области, поэтому границы областей надёжнее порога по линиям (не рвутся на тонких местах). Дальше `find_contours` + RDP по каждой области. Лицензия BSD-3-Clause (copyright-файл репозитория), проект живой (коммит 03.11.2026), работает на Windows и numpy. https://github.com/scikit-image/scikit-image
- **LSD в OpenCV** (`cv2.createLineSegmentDetector`): отрезки прямо с градиента, без порога. Репозиторий OpenCV Apache-2.0, живой (04.11.2026). По документации, детектор вырезали в 3.4.6–3.4.15 и 4.1.0–4.5.3 из-за лицензии оригинала и вернули позже; какая именно лицензия у возвращённого кода, не проверено. Перед использованием проверить версию в anaconda. https://docs.opencv.org/4.x/javadoc/org/opencv/imgproc/LineSegmentDetector.html
- **Векторизатор vtracer** (MIT, коммит 22.10.2026): трассирует цветные области в сплайны/полигоны. Для плоских граней сгодится как быстрая проверка. Не проверено, как он ведёт себя на 2 000-гранном листе. https://github.com/visioncortex/vtracer
- **PolyFit, «Polygonization of line drawings»:** первоисточники не открыл, лицензии не проверял; PolyFit работает по облакам точек, к картинке не подходит. Не годится.

## 2. Low-poly из несогласованных ортовидов или скетчей
**Не годится ничего.** Найдено только: Lun et al., «3D Shape Reconstruction from Sketches via Multi-view Convolutional Networks» (arXiv 1707.06375): нейросеть даёт глубину и нормали, затем Пуассон, то есть плотная поверхность, а не низкополигональная сетка по граням. Ссылка на код есть у авторов, лицензию и пригодность не проверял. True2Form (кривые из одного скетча) для нескольких ортовидов слабо подходит. Остаётся своё: опорные грани с листа, привязка к базе, согласование между ракурсами через оценку шума.

## 3. Робастная подгонка вершин
- **SciPy `least_squares(loss='huber')`**: готовый IRLS-подобный решатель с Хубером, `f_scale` = наш порог 3 мм. BSD-3, живой (03.11.2026), в anaconda уже есть. Брать вместо самописного. https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html
- **libigl (python `igl`)**: ARAP, лапласиан, `pip install libigl`. Лицензия **GPL-3.0** (по странице репозитория, плюс MPL-2.0 для части кода); для инструмента вне игры допустимо, вшивать в игру нельзя. Колёса под Windows заявлены на странице установки, ARAP в биндингах не подтверждён (документация «устарела»). Пробовать, не обязательно. https://github.com/libigl/libigl-python-bindings
- **Shrinkwrap в Blender** (встроенный, GPL Blender): проекция вершин на базу; регуляризацию (симметрия, гладкость) делать самим в numpy.
- **trimesh** (MIT, 02.11.2026): ближайшая точка и проекция вне Blender. https://github.com/mikedh/trimesh

## 4. Ретопология по направляющим
- **RetopoFlow 3.4.x** (GPL-3.0 по README): код открыт, но проект продаётся на Blender Market и Superhive, «будущие обновления финансируются покупками». Zip с GitHub Releases (3.4.10, 29.01.2026; коммит 18.05.2026) заявлен скачиваемым, в README таблица совместимости «3.6 и выше», поддержка Blender 5.x НЕ подтверждена. Это условно бесплатное: помечаем «не годится» по правилу проекта, при необходимости можно пробовать для ручных штрихов на базе. https://github.com/CGCookie/retopoflow
- **QuadriFlow** (лицензия BSD-вид, текст в LICENSE.txt, без юридических оговорок; сторонний код Boost/MPL2/Apache): последний коммит 07.12.2019, брошен; даёт квады без направляющих кривых, число граней задаётся. Не годится под нашу цель (нужны не квады по потоку, а грани листа). https://github.com/hjwdzh/QuadriFlow
- **Instant Meshes** (BSD-3 по LICENSE.txt, 2015): последний коммит 03.11.2019, кисти направляющих есть, Windows-бинарник есть. Проект заморожен; тоже даёт квады по потоку поля, не по граням листа. Не годится как основа.
- **Quad Remesher:** платный, не годится.
- **bmesh-скрипты:** стартовая сетка плюс снап вершин на базу и правка рёбер в Python внутри Blender. Это наш путь; готовых библиотек «по кривым-направляющим» не нашли.
