# Цель «человек-лось» для ключа «Лось» (19–20.10.2026)

Вторая задача после оборотня: тот же рецепт на втором виде — ключ «Лось» на человеке К2 и черта ступени 2 куском самой цели.

**Вход:** последняя колонка листа `Референсы/витрина/человек-лось/ступени.png` — вырезки `chisto/front.png`, `left.png`,
`34.png`; `right.png` — зеркало `left.png` (вида сзади на листе нет). Дыры маски в бликах кожи залиты.

**Внешняя выгрузка** (постоянное разрешение геймдизайнера 14.10):

**Тракт:** A → рост с рогами 2.004 м (лист: колонка 4 к колонке 1 в анфас 346 : 319 px × 1.848) → ориентиры цели по
срезам 0.05 м (`orientiry-celi-v-poze-lista.json`) → `vypryamit_cel.py --dolya 0.5 --vzglyad 12`
(`orientiry-celi-v-poze-k2.json`) → `kluch_vida.py --imya Лось` рецептом ключа «Волк» (k18, `c844dc9`):
до поверхности цели средн. 4.3 см, 95 % — 12.8 см → `kusok_celi.py --imya Лось --golova_z 1.55 --golova_x 0.75
--dolya 0.05 --zazor 0.03` → объект `@Лось` (голова с рогами, подгрудок, холка, копыта; 1 673 тр; меха у лося нет — порог
3 см, при 1.2 см кожа цели, куда ключ не дотянулся, ложилась поясом на грудь) → `svesti_klyuchi.py` — ключ «Лось» и
`@Лось` в один меш человека с ключом «Волк» и `@Волк`/`@Волк1`.
