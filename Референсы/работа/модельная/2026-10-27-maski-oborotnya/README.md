# Маски ступеней оборотня (рабочие, модельная линия, 27.10)

Сняты `Docs/tools/sheet_mask.py` с `витрина/оборотень/ступени.png` (принят 20.10) для сверщика силуэта стенда
(`Tools/Blender/proba/stend_k2.py --maski`). В витрине масок нового ряда нет — эти рабочие; в витрину их переносит тот, кто её ведёт.

Порог 242, а не 195 по умолчанию: светлая кожа фигур ст.0–2 при 195 пробивала маску дырами на груди и плечах. Нижний край
профилей — строка 666: ниже линия пола (1–2 px), она сливается со ступнёй и раздувает рамку фигуры.

| файл | рамка листа x0,y0,x1,y1 |
|---|---|
| st0-front / st0-profile | 100,45,380,360 / 100,370,380,666 |
| st1-front / st1-profile | 430,45,720,360 / 430,370,720,666 |
| st2-front / st2-profile | 780,45,1110,360 / 780,370,1110,666 |

Лист не метрический чертёж (паспорт витрины): IoU — мера читаемости силуэта, а не точности в сантиметрах.
