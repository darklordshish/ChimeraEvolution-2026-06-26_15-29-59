# CHIMERA

Рогалик «по флоу» про последнего безумного учёного, который химеризует собственное тело органами убитых зверей — чтобы выжить среди сбежавших химер и добраться до сердца окуклившейся лаборатории.

**Сюжетная рамка.** Лаборатория создавала Химеру 0 — идеальную адаптивную химеру — на оригинальной мутагенной сыворотке. Вспышка: Химера 0 заразила коллег (они стали боссами-суперхимерами — трагическими жертвами, не злодеями), зверинец разбежался и одичал. Герой вкалывает себе чистую сыворотку по своей воле: управляемая химеризация — его оружие. Химера 0 тем временем пожирает и мутирует — растущая угроза и финальный босс.

**Ядро геймплея.** Убиваешь зверей → копится **родство** с видом → звериные органы дешевеют → в слот-конструкторе размениваешь человеческие органы на звериные (пул мутагена = ёмкость) → тело реально меняется: способности, чувства, статы. Вариативность «по флоу, а не по луту»: билд вырастает из того, каких зверей подкинул маршрут забега.

## Текущее состояние (прототип)

Играется сейчас:

- **Пять видов** (`Assets/_Chimera/Data/`): **волк** (стая: окружение, жетоны атаки, захват, мораль и бегство, вой), **змея** (засада, термозрение, яд, трёхстадийный удушающий обхват, невидимость-в-неподвижности с гремком), **лось** (массивная туша: таран копытами, рога, рёв, кровеупорность), **ёж** (пиннер: залп игл, клубок, сытость как кор-механика), **человек** (шасси игрока). Босс **Вервольф** — первая суперхимера, собран как человеческое шасси с полным волчьим комплектом.
- **Лес химеризуется сам**: NPC убивает — набирает родство — получает графт органа — сдвигается доминанта состава — `Metamorph` меняет ему психику. Волк с лосиными рогами может встретиться как обычный житель леса.
- **Конструктор химеры** (Tab, слоу-мо ×10): 6 слотов + химерный, мультидонор по слоту, экономика пула со скидками от родства, супремум-агрегация дублей.
- **Экосистема чувств (камень-ножницы-бумага)**: зрение (рвётся стенами) ↔ нюх (запаховые тропы) ↔ термозрение (тепло сквозь стены, слепо к холоднокровным) ↔ скрытность (камуфляж, гремок — единственная зацепка). Слух отвечает «кто шумит», чутьё — «что происходит».
- **Способности от органов**: меч, укус (вампиризм ↔ яд), пинок, рывок, обхват хвостом, рога, таран, перекат и клубок, залп игл, три голоса — вой (стан), рёв (страх), боевой клич (ярость по своей крови).
- **Витальность и стамина**: процентная модель (база шасси × бонусы органов), спринт и стелс.
- **Голод**: шкала сытость↔голод как движитель психик, метаболизм-цена химеры.
- Процедурная арена-лабиринт с NavMesh, спавнеры, отладочный HUD и Dev-панель.

**Морфология.** Тело собирается из данных в рантайме: сокет-план (`SpeciesSO.sockets`) — места на теле, у волка поверх него работает **скелет из костей** (`SpeciesSO.bones` → `BoneMesher`): оболочка строится скалярным полем и режется Surface Nets, по одному мешу на слот. Пробные Blender-модели отключены; см. `Docs/models/SPEC-model-contract.md`.

## Управление

Проверено по `PlayerInputDriver` и `PlayerController` — биндинги живут В КОДЕ, схемы ввода в ассетах нет.

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| движение / прицел | WASD или стрелки / мышь | левый стик / правый стик |
| меч | ЛКМ (или J) | X |
| рывок | Space или ПКМ | A |
| укус | Q | RT |
| пинок | E | B |
| рога | R | Y |
| вой · рёв · клич | Left Alt | RB |
| обхват хвостом | F | LT |
| предъявить жертву | C | LB |
| залп игл | СКМ | RB |
| спринт / стелс | Left Shift / Left Ctrl | нажатие левого стика |
| вид от 1/3 лица | V | — |
| органы и придатки | 1–8 | — |
| конструктор (слоу-мо ×10) | Tab | — |

Отладка: G бог · K/L/; +10 родства (волк/змея/лось) · N свой запах · T форс-термо · F1 легенда · `Chimera → Dev-панель` в редакторе.

Подробнее — раздел «Раскладка» в [CONSTRUCTOR_GUIDE](Docs/CONSTRUCTOR_GUIDE.md): там расписано, как одна кнопка меняет смысл от надетого органа (рывок → таран или перекат, Alt → вой, рёв или клич).

## Как открыть

1. Unity **6000.4.7f1** (URP, новый Input System, AI Navigation 2.0).
2. Открыть папку проекта → сцена `Assets/Scenes/SampleScene.unity` → Play.
3. Данные видов уже в репо (`Assets/_Chimera/Data/`); после правок `SpeciesBootstrap` — меню **Chimera → Создать дефолтные виды**. Префабы существ пересобираются генераторами (**Chimera → Создать префаб …**), не руками.

## Архитектура (кратко)

- **Тело = данные**: `CreatureBody` + `SpeciesSO` (шасси + доноры + экспрессия) — общее для игрока и NPC.
- **Психика = тонкий код**: решения вида (sense → think → act) поверх общих «глаголов тела».
- **Способность = доставка + эффекты**: переиспользуемые доставки (`BiteAbility`, `LeapAbility`…) × словарь эффектов (`Hit`/`HitEffect`).
- Статусы — компонентами (`Rage`, `Venom`, `Stagger`, `ColdBlooded`, `Camouflage`).

Подробно — в [Docs/CONSTRUCTOR_GUIDE.md](Docs/CONSTRUCTOR_GUIDE.md) (читать перед любой работой с видами).
