# Лось (*Alces alces*) — референсы

## Что нужно методу и почему

Тело строится **клеткой** (`Docs/models/SPEC-kletka-tela.md`): слот описан сечениями, сечение — это
многоугольник, а его точка — направление. **С одного профиля многоугольник не снять.**

| ракурс | зачем | без него не выйдет |
|---|---|---|
| **профиль**, все четыре ноги на земле, спокойная стойка | линия верха, глубина груди, высоты суставов | пропорции и поза |
| **анфас** | ширина груди, постав ног, ширина головы | сечение — станет плоским |
| **сверху** | ширина корпуса вдоль, разворот рогов | то же, плюс рога |
| **скелет в профиль** | устройство: что к чему крепится | углы брать нельзя (монтаж), только конструкцию |
| **череп: профиль, анфас, сверху** | голова строится оболочкой по сечениям | морда выйдет конусом |
| **миология / экорше** | какая мышца где и какую работу делает в силуэте | объём станет «шариками» |

Углы стойки берутся **только с живого зверя**: на смонтированном скелете позу задал таксидермист.

## Чего НЕ ХВАТАЕТ (по убыванию важности)

1. **ПРОФИЛЬ живого лося** — строго сбоку, все четыре ноги на земле и видны, ровный фон.
   Это главный блокер: с него снимается эталонный контур и все высоты суставов.
2. **Скелет В ПРОФИЛЬ** — есть только анфас. Нужен для устройства конечностей и грудной клетки.
3. **Череп в профиль** — три имеющихся ракурса MWNH профиль не покрывают.
4. **Экорше / миология** копытного — сгодится любой олень, важно устройство, а не вид.

## Как добавить

Положить файл в нужную папку с говорящим именем — этого достаточно, метод читает по папкам.
Либо скриптом, он же запишет лицензию и уменьшит до разумного размера:

```bash
cd Anatomy
python tools/commons.py cat "Alces alces"
python tools/commons.py get "File:Имя файла.jpg" species/moose/ref/photo/moose_profile.jpg
```

**Что бракуется сразу:** меньше 700 px по короткой стороне (контур снимается попиксельно, на мелком
он превращается в кашу); зверь в движении или лежит; сильная перспектива (снято в упор широким).
