# Материалы каньона — имена и настройка

Файлы FBX **не содержат финальных материалов**: в них лежат только слоты с именами
`CanyonRock`, `CanyonWater`, `CanyonFoam`. Unity-интегратор создаёт/находит общие ассеты
в этой папке и назначает их рендерерам. Дублировать материалы внутри FBX не нужно.

## Обязательные имена

| материал | на что | настройка |
|---|---|---|
| `CanyonRock.mat` | `CanyonAuthor`, `CanyonSkirtW/E`, `CanyonAuthor_LOD1`, `CanyonSkirtW/E_LOD1`, `CanyonCollider` (рендерер выключен) | URP Lit, `_BaseColor` = камень павильона, flat/faceted, без текстур и normal map, без triplanar |
| `CanyonWater.mat` | `CanyonWater`, `CanyonFallStep1..3` | URP Lit, `_BaseColor` = вода павильона, **непрозрачная** (alpha 1), roughness ниже камня, без ripple/alpha |
| `CanyonFoam.mat` | `CanyonFoam` | URP Lit, светлее воды на 10–15 L, **не белый**, непрозрачный, без альфы |

## Палитра (sRGB, из `s10` / ART-2026-11-03-canyon-mesh)

- камень сухой: `Rock` (0.50; 0.50; 0.50); второй тёплый тон `Scree` (0.42; 0.40; 0.34) —
  один слот или два, но не больше;
- сухая трава: `Turf` (0.40; 0.42; 0.24) — если появится отдельный слот на полку/бровку;
- мокрый камень: `Rock` × 0.72–0.78 (темнее, не синее) — если появится вершинный пояс;
- вода: `Water` (0.20; 0.45; 0.60) × 0.65–0.75 — тёмный вариант, непрозрачный;
- пена: `#C7D1D6` ≈ (0.78; 0.82; 0.84), не белый.

## Правила

- Грань бликует целиком: плоские нормали, без smooth, без normal map.
- Переходы — пояса по граням, не градиенты; джиттер ±1 грань.
- У воды и пены нет коллайдера.
- Материалы общие для павильона; новых семейств и текстур не заводить.
- Импорт FBX: `Material Creation Mode = None` (или внешние материалы по имени),
  чтобы не появились дубликаты внутри модели.

## Чего в поставке нет

- отдельного материала «мокрый камень» и «трава» — это будущий вершинный/слотовый слой;
- прозрачности, анимации воды, шейдерного течения, пены-частиц;
- второго `CanyonWater` для ручья по дну: в handoff лежит только полотно водопада,
  ступени и пена. Ручей/озеро — существующая вода мира, не этот файл.
