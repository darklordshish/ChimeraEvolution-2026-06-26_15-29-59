# УКАЗАТЕЛЬ: все документы проекта с аннотациями

Полный каталог. Аннотации сняты **с текста документов**, а не с их имён — за проект имя файла
расходилось с содержимым десяток раз, и это дорого стоило.

Куда идти по делу — [`СТАТУС.md`](СТАТУС.md). Здесь — что вообще есть и о чём оно.

## Три сорта документов, их нельзя путать

| сорт | правило |
|---|---|
| **Генерируемые** (`Диаграммы/`) | выгружаются командой, **руками не править** — перезапишутся. Числа брать отсюда: они сняты с фактически построенного тела |
| **Живые** (GDD, гайды, СТАТУС, паспорта) | ведутся руками, отражают текущее состояние, обновляются по ходу |
| **Спеки и планы** (`superpowers/`) | **снимок решения на свою дату.** Не обновляются задним числом: спека от 22.07 описывает то, что думали 22.07. Ищите преемника, а не считайте её ложью |
