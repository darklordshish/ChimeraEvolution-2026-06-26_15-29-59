# План: большой павильон — каньон, водопад, озеро

**Дата:** 2026-10-27. **Спека:** `2026-10-27-forest-bolshoj-pavilon-geografiya.md`.
**Ветка:** `les/runtime-builder`. **Станция и тела не трогаются.**

## Task 1 — данные и пол (без картинки)
- [ ] `DomeTerrace` — lift-слой: пятно, высота, радиус, блендинг; `Apply` тождество вне пятна.
- [ ] `DomeCanyon` — полилиния, `Build`, `Apply` (Carve), `Contains`, `StreamPath`, брод; без эллипса оврагов.
- [ ] `DomeFall` — `Site`: лип, основание, перепад, плёс; без меша.
- [ ] `DomeWorld.SampleGround`: `Hydro → Terrace → Canyon → Ravines → ramp → pad`; `Clear` обнуляет.
- [ ] `DomePass`, `DomeAshSite`, `DomeSlope`, `DomeLabSite` читают `SampleGround`, не сырое поле.
- [ ] Тесты: детерминизм, габариты, один пол, вне пятна — тождество, A/C при выключенных флагах.

## Task 2 — вода
- [ ] `DomeWaterMesh`: плёс, ручей по дну, полотно водопада (Slab/сегменты, без коллайдера), пена/кромка — простые плашки.
- [ ] Уровень озера/плёса/ручья из `SampleGround`, не `SampleHydro + 0.25`; вода не выше земли.
- [ ] `DomeWaterShapeTests`: вода над дном, берег замкнут, водопад верх/низ, нет висящей воды.
- [ ] Гейт воды для спавнера/логова: не рожать под водой, не ставить логово на обрыве.

## Task 3 — сцена и кадры
- [ ] `ForestPavilion.unity` — Ø2000, `terrainQuads 48`, `buildTerrace/buildCanyon = true`, `buildClimate = true`, лаборатория/план, `buildRavines = false`.
- [ ] `PavilionShot` — режимы `CanyonTop`, `Canyon3_4`, `CascadePool`, `Lake`; проверка камеры на стену; не перехватывать `Camera.main`.
- [ ] Кадры: каньон, водопад, озеро, туман в низине, ночь; топдаун-контроль.
- [ ] `ForestPavilionTests`: Entry→LabDoor, каньон/вода, `Clear`, повторная сборка; `ForestSceneCameraTests` + путь сцены.

## Task 4 — климат по высоте
- [ ] `HeightBands`/`ClimateAt` — чистая функция от `ground − lakeLevel`; туман в низине, дождь/ночь снаружи; станция — байпас.
- [ ] `DomeRain` следует за землёй под камерой, не Y=0.
- [ ] Тесты: пояс тотален/монотонен, станция не читает внешний пояс, `Clear` сбрасывает.
- [ ] Кадры: низина/плато день, туман, ночь.

## Task 5 — приёмка
