# План S4 — эрозия и дороги (P5 full + P6)

**Дата:** 2026-11-01. **HEAD:** `e6596319` (дополнение 01.11.2026 (2)).
**Спека:** [`2026-11-01-landshaft-s4-eroziya-i-dorogi.md`](../specs/2026-11-01-landshaft-s4-eroziya-i-dorogi.md).
**Ветка:** `les/runtime-builder`. **Статус:** **В РАБОТЕ · решения ПРИНЯТЫ и ДЕЙСТВУЮТ
(01.11.2026), дополнены 01.11.2026 (2).**
**Правка 01.11 (2):** гидроэрозия — **запекание при старте** (вариант B), не офлайн-ассет;
POI v0 = **база, ворота уровня, лабораторные остовы, общие зоны** (боевых арен нет); «P6 после
B1» снято; вода — **водопой + тактика**; **лазание закладываем** (допуски уклонов, механику
не решаем); плотность 3000–3500 — пятнами, S4 её не меняет.

Правило: каждый шаг — вертикальный срез, играбельный после шага. Сначала данные/детектор,
потом поведение. A/C/B0 не меняются без `worldVersion` и отдельного профиля.

## Зависимости (без них не начинать)

| зависимость | что нужно | кто даёт |
|---|---|---|
| **S1** | `HeightField`, `SamplingContract`, `worldVersion`, детерминированный `SeededHash` | S1 |
| **S2** | семь форм и их footprint (входят в `preErosion` и маску); S4 их не двигает | S2 |
| **S3** | крючок `[erosion]` в `ShapeGround` **до POI**: `Shape0 → Erosion → POI → pad/ramp/crevice → SampleGround`; один пол для поляны/коридоров/флоры/NavMesh | S3 |
| **POI v0** | замороженный список адресов из кода: **база** `LabDoor`, **ворота уровня** `Entry`, 5 лабораторных остовов (`Clearings`, не арены), общие зоны — вода (водопой/брод/плёс) и корм (адрес ещё не заведён) (см. спеку §5.1) | S4 (данные), B-lite (пятна) |
| **B1** | `ForestPlace`, `ForestLink`, `ForestPlaces`: **расширение v1**, не условие старта | B1 (в коде пока нет) |
| **S5** | общий гейт 20 сидов и отчёт | S5 |
| **кеш гидроэрозии** | ключ `(seed, worldVersion, erosionVersion, resolution)`, `persistentDataPath`; без кеша — запекание при старте; предзапекание — опция | S4 |

**Стоп-условие:** если S3 не даёт крючок, S4 делает только офлайн-прототип и не трогает
`DomeWorld`. **Если POI v0 не заморожен — P6 не начинается.** B1 не блокирует: база, ворота,
пятна-остовы и вода уже есть в коде; без них гейт «после B1» был бы фиктивным.

## Task 1 — контракт слоя и маска (S4, без картинки)

- [ ] `ErosionConfig` (ScriptableObject): `enabled`, `version`, `grid 512`, `talus 30`,
      `iterations 6`, `rate 0.4`, `clamp 0.4`, `hydraulicBake`, `bakeCacheDir`, параметры
      droplets (капли, шаги, инерция, ёмкость, растворы).
- [ ] `ErosionMask`: **только формы до эрозии** — каньон (`Contains + 6`), терраса
      (`+blend+5`), холм, **формы S2 (footprint + blend)**, вода (озеро/русло +2).
      **Площадка/рампа/расщелина/`Entry`/логова/ясень/пятна-остовы в маску не входят** — они
      строятся после эрозии (S3 И2). Кольцо — граница домена, не маска.
- [ ] `preErosion` снимок: **`Shape0`** (после hill, до POI), **не** `BaseGround` и
      **не** `SampleGround`; площадка последняя.
- [ ] `DomeErosion.Apply(state, h, x, z)`: билинейно, вне сетки/null — тождество.
- [ ] `ErosionFieldTests.Off_IsIdentity`, `ProtectedMask_IsZero`.
- [ ] `GenTrace`: слой `erosion`, кандидатов/принято/время; отдельно `preErosion=Shape0`.
- **Проверка:** EditMode зелёный; сборка без флага не меняет ни одного числа A/C.
- **Коммит:** `лес: контракт эрозии и защищённые зоны`.

## Task 5 — гидроэрозия запеканием при старте (вариант B)

- [ ] `DomeHydraulic` (C#): droplets 60–120 тыс. (старт 96 тыс.), 32–48 шагов (старт 40),
      512², сетка из **`Shape0`**; дельта `R16`, квант 0,02 м, кламп ±1,5 м.
- [ ] Параметры — `ErosionConfig`/`ScriptableObject`, не константы; **все** входят
      в `erosionVersion` (число капель, шаги, инерция, ёмкость, растворы, кламп).
- [ ] **Ключ один:** `(seed, worldVersion, erosionVersion, resolution)`; RNG —
      `SeededHash("hydro", …)`, фиксированный обход, без `UnityEngine.Random`/`Time`.
- [ ] Кеш `ErosionBake-<hash>.bin` в `Application.persistentDataPath/ErosionBake/`
      (не `Resources`): заголовок (magic, ключ, разрешение, квант, сумма) + `R16`;
      битый/чужой — пересборка, не «примерно то же».
- [ ] Порядок в слое: `hydro(Shape0) → thermal(result)`; гидро не читает `SampleGround`,
      не видит площадку и POI. Запекание — **один раз при старте сборки**, не на чанк/кадр.
- [ ] **Время не режет мир:** нет таймаута, нет «меньше капель по времени»; бюджет
      (цель ≤4 с, верх 6 с) только пишется в `GenTrace`; предзапекание — опция для канонических
      сидов (тот же ключ/формат).
- [ ] Fallback: нет кеша и запекание упало/нет памяти/нет прав — `hydraulic=missing` с причиной,
      тепловая остаётся, мир собирается; `WorldFingerprint` смешивает ключ **и сумму дельты**.
- [ ] `HydraulicBakeTests.BakeKey_IncludesSeedWorldErosionResolution`, `Bake_IsDeterministic`,
      `CacheHit_MatchesFreshBake`, `MissingBake_FallsBackToThermal`, `Bake_DoesNotLowerWater`,
      `Bake_ReadsShape0_NotSampleGround`, `Bake_RespectsBudget` (время в trace, не таймаут).
- [ ] Вода не убита: дно не ниже `lakeLevel+0.35`, уровень один, русло монотонно;
      броды ищутся **после** эрозии на готовом поле (маски брода нет).
- **Проверка:** EditMode + 3 полные сборки (1337/4/9); замер времени/памяти в `GenTrace`;
  первый кадр ≤12 с; повторный старт — попадание в кеш ≤50 мс.
- **Коммит:** `лес: гидроэрозия запеканием при старте и кеш`.

## Гейты

- **Г1:** крючок S3 `[erosion]` в `ShapeGround` **до POI** есть; иначе Task 3 не начинается.
- **Г2:** офлайн-метрика **тепловой** выбрала talus/итерации; если метрика не улучшилась —
  параметры пересматриваются, эрозия остаётся (решение 01.11), отмена — только геймдизайнером.
  Параметры droplets калибруются тем же замером, но живут в сборке (Task 5).
- **Г3:** **POI v0 заморожен** — база, ворота уровня, лабораторные остовы, общие зоны
  (вода; корм — если адрес есть) + дедуп с B1 по R8; B1 — расширение, не блокер.
  Без v0 P6 не начинается; «ждать B1» больше не гейт.
- **Г4:** A/C-базлайн 52/700/10 и B0 12 — зелёные.
- **Г5:** 20 полевых + 5 полных; `>35°` ≤2 % (новых вне маски — 0); корень базы; ≥3 сектора
  из 4; ширина/уклон/ступень/брод; нет дорог с лазанием; NavMesh `PathComplete`;
  время тепловой ≤0,5 с, **гидро-запекания ≤4 с (кеш ≤50 мс)**, первый кадр ≤12 с,
  дорог ≤0,3 с, 20 полевых ≤60 с; `Fingerprint` стабилен.
- **Г6:** плейтест — последним, за геймдизайнером.
- **Г7:** гидроэрозия не режет мир таймаутом: число капель фиксировано ключом; «не успели» —
  это отчёт и предзапекание, а не меньше капель.

## YAGNI

Без stream-power в рантайме, WFC, физики/плавания, мостов/тоннелей, выемки/насыпи дорог
в первом срезе, Indirect/LOD, правок тел, плана, климата, зверей, новых видов.
**Без механики лазания** — только допуски уклонов и ступеней. Гидроэрозия не пересчитывается
на чанк/кадр и не подменяет поле на ходу: один раз при старте, кеш по ключу; «меньше капель
по времени» — запрещено. S4 не переписывает `SampleGround` — это S3; не выбирает POI — адреса
v0 берутся из кода, новые места дают S2/B1; боевых арен нет.
