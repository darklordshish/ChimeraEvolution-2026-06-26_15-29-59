# План: станция под куполом — камеры и климат

**Дата:** 2026-10-27. **Ветка:** `les/runtime-builder`.
**Предмет:** лаборатория — павильон-купол с искусственными сутками и погодой; станция 46×36 внутри — закрытый объём с постоянным искусственным светом. Климат павильона не должен протекать внутрь станции; игровые камеры не должны быть стендовыми.

## 1. Решения

- **Павильон** (`ForestClimate`, `DomeSkyRig`, `DomeRain`, `DomeWeather`) владеет внешним климатом.
- **Станция** — зона внутри `DomeLabComplex.Result`; дождь и туман внутри выключаются, материалы станции не входят в мокрость. Лампы станции не зависят от фазы павильона.
- **Зона** — геометрический запрос по локальным границам `DomeLabComplex`, без триггеров/лучей/NavMesh.
- **Камеры**: в игровых сценах активна только `Main Camera`; `TopCam`/`SandboxCam` — инструменты, включаются только съёмкой.
- **Высота камеры** считается от земли, а не от корня персонажа.

## 2. Задачи

### Task 1 — камеры (P0)
- [ ] `BodySize.FromGround(y)` — `bottom + y*Scale`, не `bottom + (y-bottom)*Scale`.
- [ ] `CameraFollow`: первое лицо проверяет стену; буфер `SphereCast` 32; третье лицо под крышей.
- [ ] `ForestFragment`/`ForestSandbox`: `TopCam`/`SandboxCam` `m_Enabled: 0`; `ForestScenicTool.SetupCameras` включает их для кадра.
- [ ] Тесты: `BodySizeTests.FromGround_*`, `CameraFollowTests` (FPS у стены, 3-е под потолком), сцена — одна активная камера.

### Task 2 — зона станции и климат (P0)
- [ ] `DomeLabComplex.Contains(Result, worldPos)` — локальный бокс.
- [ ] `ForestClimate.lab` + `ApplyVisuals(viewPoint)`; внутри: `fog=false`, дождь выключен; при смене «снаружи/внутри» — сразу.
- [ ] Убрать материалы `DomeLabComplex` из `wetMaterials`; станция не мокнет.
- [ ] Лампы станции остаются постоянными; повреждённая не оживает.
- [ ] Тесты: дождь/туман не внутри, снаружи остаются; `Clear` снимает; A/C не тронуты.

### Task 3 — рантайм и свет
- [ ] `DomeLabDamage` — `Destroy`/`DestroyImmediate` по режиму.
- [ ] `ForestClimate.SetWeatherImmediate` сразу пишет статики.
- [ ] `DomeSun.shadows = Soft`; крыша станции кастит тень; остальные детали — Off.
- [ ] `Clear` возвращает `RenderSettings.fog*` и базовые интенсивности (если успеваем; иначе записать долг).
- [ ] Smoke `ForestFragment` в Play: 0 Error/Exception.

### Task 4 — приёмка
- [ ] Полный EditMode/PlayMode.
- [ ] Кадры: снаружи купола/вход, зал день/ночь, порог.
- [ ] `СТАТУС`, `УКАЗАТЕЛЬ`, спека/план, `chimera-testing`/`unity-gotchas`.

## 3. Инварианты

- И1: в Play активна ровно одна игровая камера; стендовые выключены.
- И2: глаз первого лица не выше макушки и не в стене; третье лицо не в потолке/стене станции.
- И3: дождь/туман снаружи не видны внутри станции; материалы станции не мокнут.
- И4: лампы станции не меняются от внешней ночи; погашенная повреждением не включается.
- И5: `Clear` не оставляет климат/дождь/стандартные глобальные настройки.
- И6: A/C (`ForestSandbox`) не меняются.

## 4. YAGNI

Не делать: второй `ForestClimate`, мульти-зоны, небо/сад внутри станции, триггеры/лучи для «внутри», per-object wet-маски, тени у всех 163 деталей, правку плана/сидов/повреждений.
