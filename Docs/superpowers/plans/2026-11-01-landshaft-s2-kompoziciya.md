# План S2 — композиция ландшафта

- **Дата:** 2026-11-01. **Спека:** [`2026-11-01-landshaft-s2-kompoziciya.md`](../specs/2026-11-01-landshaft-s2-kompoziciya.md).
- **HEAD:** `85e2e1bb`. **Ветка:** `les/runtime-builder`.
- **Кто исполняет:** S2 — только документы; код исполняют S1 (поле), S3 (порядок), S5 (верификация).
  Этот план не разрешает менять A/C, B0, тела, воду, логова и интерьер станции.
- **Статус:** ЧЕРНОВИК; шаги 0–2 — предпосылки, без них шаг 3 запрещён.

## Шаг 0 — развилки геймдизайнера (блокер)

- [ ] Р1: чаша **да/нет**. Если нет — её объём становится третьим мысом или плоской поляной; форма 5 из §1.2 спеки удаляется.
- [ ] Р2: вода **стена/ресурс**. Если стена — S2 требует броды/берега в З4; если ресурс — вода остаётся проходимой.
- [ ] Р3: плотность **1500/3000–3500**. От неё зависит, виден ли силуэт гряды в лесу.
- [ ] Р4: вертикаль **декор/механика**. Механика требует траверса и S5-тестов; декор — только уклоны ≤22°.
- [ ] Записать ответы в шапку спеки, сменить `решения НЕ ПРИНЯТЫ` на `решения ПРИНЯТЫ`.
- **Проверка:** четыре строки с датой и автором; без них шаг 3 не начинать.
- **Коммит:** `лес: S2 композиция — решения геймдизайнера` (docs).

## Шаг 1 — S1: примитивы формы

- [ ] Согласовать с S1 API: `crest` (плоская бровка/дно), `side` (борт с ограничением уклона), `foot` (подошва 10–30 м), `cut` (выемка), `slopeAt` (сэмпл уклона).
- [ ] S2 даёт числа H, D, H/D, бровку, подошву из §1.2; S1 реализует функции, не S2.
- [ ] Запретить S1 любой `SmoothStep` через всю полуширину, который даёт уклон >20° на гряде.
- [ ] Детерминизм: форма — функция `(seed, anchors, index)`, без `UnityEngine.Random`.
- **Проверка:** на синтетической гряде H24/D220 максимум борта ≤20°, бровка ≤4°, подошва ≤8°.
- **Коммит:** `лес: S1 формы рельефа — бровка, борт, подошва` (S1).

## Шаг 2 — S3: порядок пола

- [ ] В `DomeWorld.Build`/`SampleGround` поставить `landform` **после** воды, террасы, каньона, оврагов и **до** `DomeHill`/POI, как в §2.1 S3: `ShapeGround → POI → pad/ramp`.
- [ ] S3 отдаёт S2 маски, известные до landform: `station`/`entry`/`ramp`/`water`/`ring`; `arena`/`route` — целевые маски, которые S3 соблюдает после landform. S2 не ищет станцию и арены и не строит POI; станция ищется на `ShapeGround` без landform в своём пятне, landform получает маску `station` (S3 §4).
- [ ] Поднять версию формы (`worldVersion` у S1 / `TerrainVersion` у S3 — имя за S1+S3, S2 его не выбирает) и `LayoutVersion` (если меняется выбор арен); `cfg.version` не трогать.
- [ ] `Clear` обнуляет композицию; A/C не получают форм (`buildRelief = false`, отдельный флаг S3).
- **Проверка:** `SampleGround` в одной точке даёт одно число для чанка, NavMesh, флоры и спавнера; A/C байт-в-байт по числам.
- **Коммит:** `лес: S3 порядок пола — landform до станции` (S3).

## Шаг 3 — `DomeComposition` вместо P5-lite

- [ ] Завести `DomeComposition` (или переписать `DomeRelief`) по §1.2: 7 форм, якоря, `v`-сдвиг при коллизии, лог причины.
- [ ] Удалить случайные циклы `attempt` и соли `9951…9966`; удалить `SmoothStep`-гребень.
- [ ] Проверять до добавления формы то, что известно до POI: R30 маршрут, вода, рампа, плита, R75 ясень, ring−30, R25 логова, R6 дорожки. R50 арены и 28 м коридоры — проверка S5 **после** выбора POI (иначе S2 снова начнёт искать арены сам).
- [ ] Плато станции не строить здесь — шаг 4; композиция не входит в `station`-маску 46×36+10 и оставляет под неё плоскую полку.
- [ ] При коллизии: сдвиг по `v` до 100 м → уменьшение D на 10–20 % → пропуск с записью; без «нарисую поверх».
- [ ] Добавить сторожа в S5: 0 вершин в запретах, уклоны, 20 сидов.
- **Проверка:** 20 сидов, 0 нарушений З1–З12; ни одна арена R50 не имеет уклона >5°; ни один коридор 28 м — >5° поперёк.
- **Коммит:** `лес: S2 композиция — гряда, мысы, чаша, ложбина, ворота` (S2/S3).

## Шаг 4 — плато станции

- [ ] `DomeHill` из купола в **плато**: верх 70×55 ≤5°, кромка 12–16°, подошва 30 м; H +8 над базой; слой идёт **после landform**, вокруг `LabCenter`, найденного по S3.
- [ ] Сохранить вырез северной расщелины и южный спуск; дверные проёмы и 15 м видимости не трогать.
- [ ] Плита 46×36+10 м остаётся выше формы; рампа/уклон не меняются.
- [ ] `StationHill_CoversRotatedPad_AndHasRelief` и `LabDoor → LabNorthDoor` остаются зелёными.
- **Проверка:** кадр с земли: плато, не купол; северная расщелина и южный спуск читаются; дверь не засыпана.
- **Коммит:** `лес: S2 плато станции` (S2).
