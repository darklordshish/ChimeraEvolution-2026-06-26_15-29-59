## Зачем этот план

Архитектура уже есть и модульна в двух осях:

- **Тело = данные** (`CreatureBody` + `SpeciesSO` `Player/SpeciesSO.cs:10`, `CreatureBody.Identity.cs:24` вес `chassis 0.1 + 0.9/AugPool`)
- **Функции** = доставка×эффекты (`WindupAbility` + `Hit/HitEffect` `Combat/Core/Hit.cs:7`)
- **Психика** = тонкий код по доминанте (`PsycheDispatch` `Enemies/PsycheDispatch.cs:8` → `MostKin`, `Metamorph`)

**Модель — хаос:** слот ≠ единица, вес не от `Identity`, локальность перенормировкой, бюджет не ограничен, пасть закрыта общими вершинами (`SPEC-kletka:21`), детектор врёт (волк глаза 1401% щель `КАРТА_ТЕЛ:149`). Задача — перенести **те же** данные механики/состава на модель: слот = таблица, вес = `Identity`, локальность = граф, бюджет = 800 трис, пасть = исключение.

Принцип фикса (`SPEC-kletka:48`): `радиус[станция][сектор] = Σ вес(вид)·таблица[станция][сектор] × калибр(носитель)` — покомпонентное среднее, вершина к вершине, без сшивания. Топология `M×N` одинакова у всех видов для слота → химера даром.

## Фазы — вертикальные срезы, игра играбельна после каждой

- Артефакт: спека v0.4, чек-лист §12 закрыт.
- **Не делать:** доменные генераторы, семантическую интерполяцию `posture`.

### Ф1. Инфраструктура данных (3д) — владелец Юнити, помогают Математик+Морфолог
- Что: `SpeciesSO.cage` поле `CageTable {slot,M,N,landmarks,radii: Ratio[]}` (без метров, И4), `MorphBuilder.Build(plan,cage)` ветка: если `cage != null` → `shell()` как `cagemesh.py:69`, иначе фолбэк полем `SPEC-kletka:153`. Миграция `SpeciesBootstrap`, сериализация `ScriptableObject`, дефолт как `SpeciesSO.skinCell:57`.
- Кросс-чек: Морфолог `audit.py` — в доноре нет метров; Математик `SameTopology` + `Σ=1` + `caliber` только носителя; Дизайнер один генератор.
- Приёмка: чистый волк `вес=1` → байт-в-байт прежний меш (И5), `CARТА_ТЕЛ` зелёная.
- **Взаимопомощь:** Математик даёт тип `CageTable m n`, Юнити сериализует, Морфолог даёт доли.

### Ф2. Волк — вертикальный срез + честный детектор (5д) — владелец Дизайнер-Blender, помогают Морфолог+Юнити+Математик

- Приёмка: `compare.py` профиль+анфас+верх <3.5 см, 0 щелей кроме Пасти, тождественность.
- Цена уже оплачена: L1-L3 чист, 112 костей, 25 мышц.
