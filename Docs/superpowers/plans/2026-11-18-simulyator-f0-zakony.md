# План Ф0 симулятора: законы игры — в сборку без движка

- **Спека:** `Docs/superpowers/specs/2026-11-18-simulyator-evolyucii.md` — §0 (решения 18.11), §3.2 (таблица Ф-1…Ф-17), §10 Ф0
- **Исполнитель:** Sonnet по срезам; приёмка каждого среза — ГеймБосс (основная модель)
- **Правило всего плана:** поведение игры НЕ меняется. Каждый срез кончается зелёными тестами, их ожидания не правятся,
  карта тел и `ХИМЕРЫ.md` те же. Исключения есть только в двух срезах, которые прямо названы «смена поведения»
  (С6, С8). Они идут отдельным коммитом.

## Устройство

- **Папка `Assets/_Chimera/Laws/`**, сборка `Chimera.Laws.asmdef`:
  - `noEngineReferences: true`, `rootNamespace: Chimera.Laws`;
  - в коде только `System`: `MathF` и `float`, без `double`, чтобы числа совпадали с `Mathf`;
  - округление `MathF.Round(x)` — к чётному, как `Mathf.RoundToInt`;
  - на `Chimera.Laws` ссылаются `Chimera.Runtime`, `Chimera.Editor` и обе тестовые сборки.
- **Законы — статические классы над простыми данными:**
  - вход и выход — `struct`/`class` с полями-числами в той же сборке;
  - `SpeciesSO`, `Organ`, `AbilityData` и прочие типы Unity в законы не попадают;
  - на стороне игры адаптер переводит ассет во вход закона (`ToLaw()`), он живёт в `Scripts/`.
- **Случайность — внедрённая:** `ILawRandom` (`Next01()`, `Range(int,int)`) и детерминированная реализация
  `XorShiftRandom(seed)` в `Laws`. Игра передаёт обёртку над `UnityEngine.Random`, симулятор — свою по сиду.
- **Симулятор вне Unity — `Tools/Sim/ChimeraSim.csproj`:**
  - `net10.0`, консоль;
  - законы подключаются как `<Compile Include="../../Assets/_Chimera/Laws/**/*.cs" />`: файлы те же, копии нет;
  - проверка `dotnet build Tools/Sim` встаёт в гейт рядом с EditMode, если задеты `Laws/` или `Tools/Sim/`.
- **Выгрузка данных:**
  - Unity-команда `chimera-sim-export` пишет `Docs/Диаграммы/Эволюция/данные.json`: входы законов для всех видов, органов, записей приёмов, `EvolutionConfig`, логов сцены `ForestPavilion` (ёмкость, темп) и площадь купола;
  - отпечаток содержимого лежит в шапке файла;
  - сторож EditMode `SimExportFreshTests`: выгрузка, собранная заново в тесте, равна файлу. Устарела — красный тест.
- **Сторож паритета `LawsParityTests` (EditMode):**
  - для каждого вида, каждой одиночной прививки каждого донора и трёх полных химер (как в `ChimeraMatrix`) сравнивает то, что тело выставило компонентам, с тем, что даёт закон;
  - допуск — ноль.
- **Сторож одной копии `LawsSingleCopyTests`:** текстовый поиск по `Scripts/` (как `PsycheDataTests`). Произведение скорости хода, формулы урона и шанс химеризации встречаются только в `Laws/`.

## Гочи (из CLAUDE.md, касаются этого плана)

- **Бутстрап не обнуляет поля**, которые перестал присваивать. Числа переносятся в данные явным присваиванием, старое поле
  гасится явно.
- **Новое `[SerializeField]`** у компонента в сцене приходит нулём. Ноль читается как «не настроено».
- **`git mv`** — только парой `.cs` и `.cs.meta`. Новые файлы в `Laws/` получают `.meta` от Unity: открыть редактор и дать ему
  импортировать.
- **Статика переживает тест.** `LawsConfig` грузится лениво; тест, подменивший его, возвращает оригинал в `TearDown`.
- **Прогон тестов:** `set_autotick --enable true` → `run_tests` → `test_status` (скилл `chimera-unity`). Headless закрыть в
  конце.
