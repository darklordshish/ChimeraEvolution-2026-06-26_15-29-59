## 1. Проблема

Референсы лежали в четырёх местах, и действующий не был назван нигде:

1. `Anatomy/species/*/ref/` — вне git (решение 01.09), в каждой копии свой набор: у модельной линии и дизайн-линии по
   171 файлу, у координатора 133; листы ChatGPT/Meshy 24.09 и 3D Hunyuan (`ref/mv/*.glb`) у координатора отсутствовали.
2. `Docs/design/` — в git, листы дизайн-линии.
3. `Docs/models/handoff/silhouettes/` — маски сверщика, снятые с листа волка 24.09.
4. `Chimera_game/Experiments/` — вне всех копий и вне git: там лежал чистовой волк дизайн-линии
   (`wolf-shape-study-01`, 05.10) и детали на аугменты; его не видел никто, кроме автора.

Цена (08.10): волк модельной линии снят с листа 24.09, оборотень — со ступеней дизайн-линии, геймдизайнер сравнивал с
третьим; голова оборотня «крошечная», потому что крошечная голова у волка, снятого не с того листа.

## 2. Решения

1. **Хранилище `Референсы/` в репозитории — три яруса:** `витрина/` (утверждённое), `работа/дизайн/` и
   `работа/модельная/` (текущее линий), `архив/` (ушедшее из витрины и прежние листы).
2. **В витрине путь — по РОЛИ, а не по версии:** `витрина/<объект>/вид.png`, `мышцы.png`, `ступени.png`, `masks/`,
   `паспорт.md`. Сменился эталон — прежний уходит в архив, новый ложится под тем же именем: ссылки не рвутся и не
   указывают на устаревшее. Объект — вид (`волк`) или химера (`оборотень`, `человек-лось`…).
3. **Мерят только по витрине.** Числа модельной линии, сверки координатора, маски сверщика, IoU — от витрины. «Работа»
   — черновик автора, второй источник из неё не делается.
4. **В витрину — только словом геймдизайнера.** Работу дизайн-линии берём (она арт-дизайнер), но в витрину её переносит
   решение геймдизайнера, а не коммит линии. Перенос делает координатор, коммит называет решение.
5. **Каждая линия пишет только в свою «работу»** — продолжение «одна линия — одна папка».
6. **Архив только пополняется:** файл переезжает с датой в имени, в каталоге остаётся строка «заменён чем, когда».
7. **Маски — производные** листа витрины: снимаются скриптом, руками не правятся; сменился лист — маски пересняты тем
   же коммитом.
8. **Каталог `Референсы/КАТАЛОГ.md` — единственный указатель**, сверяется машиной (`Docs/tools/refs_catalog.py`, в
   гейте рядом с детектором спек): файл витрины или архива без строки каталога, строка без файла — красное.
9. **Хранение — оба способа:** листы, маски, лёгкие детали — в git через LFS (по 1–3 МБ, проходят); тяжёлое сырьё —
   фото, 3D Hunyuan, рабочие папки экспериментов — в общей папке машины `Chimera_game/_refs-local/` вне всех копий,
   одной на все линии; в каталоге такие строки помечены «локально». Решение 01.09 действует для этого сырья.

## 3. Этапы

1. **Структура, каталог, детектор, витрина утверждённого 08.10:** волк (вид — `wolf-shape-study-01`, мышцы), оборотень
   и пять пар ступеней дизайн-линии с масками, человек (лист атлета 23.09 и маски сверщика, мышцы), мышцы лося и ежа;
   листы 24.09 — в архив.
2. **Переезд рабочих мест** после коммита дизайн-линией текущих правок: `Docs/design/` → `Референсы/работа/дизайн/`,
   `Experiments/` и `Anatomy/species/*/ref/` → `_refs-local/`; маски волка — с листа витрины; сверщик силуэтов читает
   маски витрины.
3. **Инструменты от витрины:** сверка по поясам «где и насколько», маски с 3D-эталона той же камерой.
