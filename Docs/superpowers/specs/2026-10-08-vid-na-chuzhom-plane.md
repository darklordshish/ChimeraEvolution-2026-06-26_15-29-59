# Вид на чужом плане и посадка головы в глобальном слое

- **Дата:** 2026-10-08
- **Статус:** ЧЕРНОВИК · решения ДЕЙСТВУЮТ (геймдизайнер 08.10); код не начат
- **Отменяет:** `2026-10-07-globalnyj-sloj-shablon-plana.md` — §2 п.6 в части головы: пропорции, наклон и посадка головы
  и шеи смешиваются глобальным слоем (§2 п.3 здесь); блоки-детали головы по-прежнему не смешиваются. И §2 п.4 в части
  «цель пары разных планов — числа вида в его собственном шаблоне через таблицу»: цель — тело вида на плане шасси
  (§2 п.1 здесь). Остальное в той спеке ДЕЙСТВУЕТ.
- **Мотив (геймдизайнер 08.10):** на кадр ступеней 07.10 — человек худел к пропорциям настоящего четвероногого волка, а
  листы дизайн-линии (`Docs/design/stupeni-*`) показывают, как он набирает звериную массу. Решение: «двуногость — это

  частично должна меняться, но надо смотреть, как с аугментами смотреться будет».
- **Опирается на:** спека глобального слоя `2026-10-07-globalnyj-sloj-shablon-plana.md`; кадр
  `Docs/Диаграммы/Кадры/Ступени-оборотня-2026-10-07/`; листы дизайн-линии 08.10 (`25089f8`): оборотень, человек-лось,
  человек-ёж, человек-змея — последняя колонка у всех — зверь в двуногом плане.

## 1. Проблема

Глобальный слой тянет числа групп шасси к числам цели. Для пары одного плана (волк ↔ лось) цель — числа вида, так и
задумано. Для пары разных планов (человек ↔ волк) 07.10 цель была та же — числа волка в шаблоне четвероногого. Кадр
показал, что это не тот зверь: у четвероногого волка рядом с человеком поджарые плечи, тонкие руки и короткое мощное
бедро. Человек к нему худеет, а на листах он набирает массу. В последней колонке листов стоит не волк, а **волк на плане
человека** — тело, которого в данных нет.

Ступень 3 (чистый вид) даёт только родное шасси (спека двух слоёв §2.2). Значит, на шасси человека тело последней колонки
не достигается никогда — оно только **цель, к которой тянутся числа**. Строить его целиком (меш, графы) незачем: нужны
только числа его групп.

## 2. Решения

1. **У вида есть тело на каждом чужом плане — числа групп шаблона этого плана.** Свой план — числа из графа вида (как
   сейчас). Чужой — поставка модельной линии, снятая с последней колонки листа ступеней. Тело вида — тотальная функция
   «план → (группа → числа)»: свой план вычисляется, чужие записаны. Глобальный слой для пары разных планов берёт тело
   цели на плане шасси, таблица планов (`plan-dvunogij__chetveronogij.json`) больше не нужна для смешения — она
   остаётся сторожем полноты пар.
2. **План — шасси онли.** Ступени 1–2 любого состава на шасси человека — двуногий; переход в чужой план только сменой
   шасси (ступень 3). Это подтверждение решения 8 спеки двух слоёв («стойка за шасси»), не новое правило. Ноги, копыта,
   когти по-прежнему приносят аугменты по швам.
3. **Голова — частично глобальным слоем.** Смешиваются пропорции цепей `шея` и `голова` на уровне узлов графа: длина и
   толщина шеи, размер головы, наклон шеи к торсу и головы к шее (посадка). Блоки-детали (морда, зубы, уши — ригблоки
   и раскладки головы) по-прежнему едут за узлами и меняются только аугментом. Доля головы от силы ступени — ручка
   `kHead` (0…1), подбирается кадром **с аугментами и без** («надо смотреть, как с аугментами смотреться будет»).
4. **Единицы — доли масштаба цепи** (исправление 07.10, `GlobalLayer`): положение вдоль сегмента, длина, радиусы,
   смещения — метры, делённые на масштаб цепи (сегмент между метками у конечностей и шеи, торс между корнями конечностей
   у хребта); сечения — множители. Эти же единицы — формат поставки тела на чужом плане: он не зависит от костей вида и
   не содержит метров (закон «в данных донора нет метров» соблюдается сам). Углы посадки — в градусах относительно
   родительской цепи.

## 3. Данные (схема — механики, числа — модельная линия)

- **Файл:** `Docs/models/handoff/<вид>-na-<план>.json`, например `volk-na-dvunogom.json`:
  ```json
  { "species": "Волк", "plan": "двуногий",
    "groups": [ { "name": "грудная клетка", "u": 0.46, "len": 0.36, "r0": 0.24, "r1": 0.30,
                  "x": 0.0, "z": 0.06, "section": 1.1, "depth": 1.2 }, … ],
    "head":   { "neckLen": 0.42, "neckR": 0.14, "neckPitch": 35, "headScale": 0.31, "headPitch": -20 } }
  ```
  Точный состав `head` уточняется на шаге 0 по графам шеи и головы пяти видов.
- **Импорт:** `SpeciesHandoff` читает файлы вида в `SpeciesSO` (поле тел на чужих планах), как раскладки.
- **Пары на сейчас:** четыре вида на двуногом (волк, лось, ёж, змея). Человек на четвероногом не нужен: шасси-
  четвероногое с человеческими органами — отдельная ветка, когда до неё дойдёт.

## 4. Сторожа

1. **Полнота тела на чужом плане:** у каждого файла — каждая группа шаблона плана ровно один раз; чисел в метрах нет.
2. **Тождество:** тело вида на своём плане, вычисленное из графа, совпадает с его же числами до микрона (проверка, что
   формат и `Metric` — одно и то же).
3. **Сдвиг к цели:** на ступени 2 расстояние до тела цели меньше, чем на ступени 1, чем у шасси.
4. **Силуэт:** IoU шасси с телом цели при `g` = 1 против маски последней колонки листа (`Docs/design/stupeni-*/masks/`)
   не ниже, чем у шасси без сдвига.
5. **Нет файла — ступень на числах родного плана цели и строка долга** (как матрица), а не молча.

## 5. Порядок — срезами, каждый с кадром

0. **Схема** (механики): формат файла, импорт, `GlobalLayer` берёт тело цели на плане шасси; сторожа 1, 2, 5; стенд
   `Stand.Stages` снимает шасси при `g` = 1 рядом с листом.
1. **Волк на двуногом** (модельная линия): числа по листу оборотня, приёмка — кадр и IoU против маски.
2. **Голова** (механики): смешение узлов шеи и головы, ручка `kHead`; кадр ступеней без аугментов и с «Пастью» и
   «Чутьём» волка — геймдизайнер выбирает `kHead`, `g₁`, `g₂`.
3. Лось, ёж, змея на двуногом — по листам 08.10.

## 6. Развилки за геймдизайнером
