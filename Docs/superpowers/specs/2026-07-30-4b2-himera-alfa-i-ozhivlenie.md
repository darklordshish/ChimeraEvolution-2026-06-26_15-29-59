# CHIMERA — #4b-2: химера-альфа + оживление тест-химеры

- **Дата:** 2026-07-30
- **Статус:** спека слайса (implementation-oriented). Второй слайс #4b (женерик-психика), после `2026-07-30-4b1-test-himera-testbed.md`. См. `2026-07-28-arhitektura-tri-osi-refaktor.md` §6-7 и `2026-07-30-4a-kin-identity-predikat.md`.
- **Родилось из:** брейншторма #4b-2. Видение пользователя: тест-химера — не код-в-стол, а **живой генератор химер = фундамент супер-химеры-босса** (замена вервольфа). Один носитель обслуживает и тестбед, и будущего босса; на нём же проверяется, что психика рулит телом, собранным ИЗ ДАННЫХ (краш-тест модели «тело=данные»). Границу слайса согласовали: оживление + альфа + тривиальный диспатч; видовые модули / боссовость / унификация построения видов — отдельные слайсы.

## 0. Контекст: где мы в #4b

#4b — САБ-ПРОЕКТ. Полное видение — диспатч (идентичность→модуль) + capability-generic поведение + химера-альфа-фолбэк + видовые-модули + боссовость. #4b-1 дал **носитель** (тест-химера: состав + ридаут, психики нет). **#4b-2 — ОЖИВИТЬ носитель и дать ему первую психику: универсальную ХИМЕРУ-АЛЬФУ.** Диспатч пока тривиальный (всегда альфа) — точка роста под #4b-3.

## 1. Scope #4b-2

1. **Оживить тест-химеру** до минимально-полноценного NPC (ходит по навмешу, дерётся, получает урон).
2. **Химера-альфа** (`ChimeraAlphaPsyche`) — компактный дженерик-автомат: охотится на всё не-кин, бьёт **любой доступной** доставкой (арсенал от случайного состава).
3. **Диспатч-роутер** — по идентичности вешает психику (в этом слайсе всегда альфа + лог доминанты).
4. **Телеграф-развязка** — замах читается И тинт-по-составу держится.

Результат-срез: **спавнишь химеру → она оживает и охотится составом, что ей достался.** Замах монстра читается телеграфом.

## 2. Дизайн

### 2.1 Оживление носителя
Шаблон живого NPC — `WolfPrefab.BuildWolf`. Ключевое: **движение идёт через `CharacterController` + `NavMesh.CalculatePath`, `NavMeshAgent` НЕ нужен** (`NavLocomotion.Move` двигает CC; путь считает навмеш). Арена уже с навмешем.

Спавнер (`TestChimeraSpawner`, после сборки состава) до-навешивает на сферу:
- **`CharacterController`** — вместо сносимого `SphereCollider` (габариты сферы: height≈1, radius≈0.5, center≈0.5). Он же коллайдер, он же мотор для `NavLocomotion.Move`.
- **`Health`** — психики требуют (`[RequireComponent(typeof(Health))]`). Витальность тело задаёт в `Recompute` (модель V-слайсов).
- **базовая `BiteAbility`** — «зубы/когти по умолчанию»: гарантия хотя бы ОДНОЙ атаки у любой химеры (даже без спец-органов). Числа — из тела через `OnBodyStats`.
- **`Telegraph`** — язык замаха (см. §2.4).
- **`ChimeraAlphaPsyche`** (§2.2) — она через `[RequireComponent(typeof(NavLocomotion))]` до-создаст локомоцию.

**Спец-доставки и статусы навешивать НЕ надо** — тело уже до-создаёт их само по флагам органов в `Recompute` (`QuillVolley`, `Constrict`, `CurlDefense`, `Thorns`, `VenomResist`, `Massive`…). Они появятся от случайного состава — **это и есть краш-тест «тело=данные».**

### 2.2 Химера-альфа (`ChimeraAlphaPsyche`)
Новый компонент в `Enemies/`. Маленький автомат, `IBodyStatConsumer` (числа урона/скорости от тела). Подход **A** из брейншторма: свой компактный код, дженерик через опрос тела, БЕЗ базы-класса и без трогания 5 видовых психик (правило трёх — базу извлечём в #4b-3, когда появятся видовые модули).

**Восприятие (максимально просто):** `Physics.OverlapSphere` радиусом (без конусов зрения/слуха — они #4b-3+). Цель = **ближайший не-кин**: у кого `CreatureBody.Regard(other, me) < KinTier.Weak`. Для истинной химеры (кин никому) это **всё живое** → «монстр для всех». Стыкуется с уже готовым «угроза = не-кин» ежа.

**Арсенал (опрос тела):** `GetComponents<WindupAbility>()` (наследники: `BiteAbility`/`LeapAbility`/`QuillVolley`/`ChargeAbility`) + классификация по дистанции срабатывания (у доставок есть range). **Захват `Constrict` — отдельный канал** (машина из `Combat/Machines/`, НЕ `WindupAbility`) → опрашивается отдельным `GetComponent<Constrict>()`. Правило выбора:
- есть **дальняя** доставка (`QuillVolley` — снаряды; `LeapAbility` — прыжок с средней дистанции) и цель дальше её порога → бей ей;
- цель вблизи → **ближняя** (`BiteAbility`) или **захват** (`Constrict`, если есть).
Никакого дерева приоритетов — берём первую подходящую по дистанции. Пусто (нечем) — только сближение.

**Движение:** `NavLocomotion.Arrive` к цели (плавный подход, не лезем вплотную), `Wander` когда целей нет. Преследование по навмешу.

**Цикл (Update):**
```
если стан/захвачен/мёртв → ничего;
ретаргет по таймеру → ближайший не-кин в радиусе;
если цель есть:
    выбрать доставку по дистанции; в радиусе атаки и готова → пустить;
    иначе Move(Arrive(target));
иначе Move(Arrive(Wander)).
```

### 2.3 Диспатч
Тонкий **роутер-метод** (не компонент — YAGNI), напр. `PsycheDispatch.Attach(CreatureBody body)` в `Enemies/`:
```
var dom = body.MostKin(out var tier);
if (dom == null)            → body.gameObject.AddComponent<ChimeraAlphaPsyche>();   // истинная химера
else { /* #4b-3: видовой модуль по dom */
        Debug.Log($"диспатч: доминанта {dom.speciesName} ({tier}) → видовой модуль (TODO #4b-3), пока альфа");
        body.gameObject.AddComponent<ChimeraAlphaPsyche>(); }
```
Спавнер зовёт `Attach` **после** сборки состава (Configure+Install синхронны, `MostKin` уже валиден). Роутер переиспользуем: позже его же позовут боссовость (#4b-4) и обычная химеризация NPC.

### 2.4 Телеграф-развязка (тинт-по-составу × Telegraph)
**Проблема (проверено в коде):** `Telegraph.Awake` запоминает «родной цвет» из `sharedMaterial` (стр. 45-48), а `Apply` при гашении замаха возвращает К НЕМУ — не к цвету-по-составу, который `tintComposition` кладёт через MPB позже. Итог: первый же замах стирает состав в исходный серый.

**Решение — переснять базу:** метод `Telegraph.Rebase()` перечитывает ТЕКУЩИЙ per-renderer `_BaseColor` из MPB как новый `baseColors` (родной для телеграфа). `CreatureBody.UpdateTint()` в конце зовёт `GetComponent<Telegraph>()?.Rebase()`. После этого замах мигает поверх состава и гаснет **в состав**. ~10 строк, без шейдеров.

Безопасность: `Rebase` no-op если `renderers == null` (Telegraph.Awake ещё не отработал). Тело пере-базирует на каждом `Recompute` → после появления Telegraph хоть один вызов случится.

## 5. Риски / гочи
- **НАВМЕШ под сферой:** тест-химера спавнится в зоне арены (спавнер в центре) — CC должен встать на навмеш. Проверить высоту спавна (сейчас `y=0.5`); если проваливается/висит — подобрать center CC.
- **Health/витальность:** проверить, что тело реально задаёт `Health` максимум в `Recompute` (иначе химера с 0 HP умрёт мгновенно). Если канал не автоматический — задать явно при оживлении.
- **Порядок оживления:** Configure+Install синхронны в `SpawnRandom`; психику и диспатч вешать ПОСЛЕ (состав готов, спец-доставки до-созданы, `MostKin` валиден). Базовую `BiteAbility` — ДО тела/психики, чтобы `OnBodyStats` её нашёл (как в `WolfPrefab`).
- **Telegraph.Rebase порядок:** зовётся из `UpdateTint` (в `Recompute`). Если Telegraph добавлен ПОСЛЕ первого `Recompute` — этот `Recompute` его не переснимет; следующий (при `Install`/повторный) — да. Гарантировать вызов `Recompute`/`Rebase` после навешивания Telegraph (напр. спавнер добавляет Telegraph ДО последнего Install, либо явный `body.SendMessage`/повторный Recompute в конце).
- **Кин-цель доминантной химеры:** с тривиальным диспатчем волчья-доминантная химера тоже получает альфу → атакует не-волков (волки ей кин, `Regard≥Weak`). Семантически ок даже сейчас.
- **Игрок как цель:** истинная химера видит игрока как не-кин → атакует (заготовка босса). Если игрок нахимерен под её доминанту — `Regard≥Weak`, не атакует. Норм.
- **Пустой арсенал:** базовая `BiteAbility` гарантирует хотя бы одну атаку — химера не «беззубая».
- **Перекомпиляция в Play** обнуляет тест-химер (рантайм-объекты) — спавнить заново, не баг (общая гоча проекта).

## 6. Верификация (плейтест)
1. Спавн химеры → она **оживает**: ходит по арене (`Wander`), не стоит столбом.
2. Видит не-кин (игрок/NPC) → преследует и **атакует** доступной доставкой.
3. **Арсенал от состава:** химера с залпом игл — стреляет; с захватом — вцепляется; без спец-органов — кусает базово.
4. **Телеграф:** замах мигает; после замаха тело возвращается в **цвет-по-составу** (не в серый).
5. **Истинная химера враждебна всем** — атакует и игрока, и волков, и лосей.
6. Доминантная химера (напр. волчья) — пока тоже альфа; в консоли лог «доминанта Волк → TODO модуль».

## 7. Порядок слайса

## 8. #4b-ЗАДЕЛ (полное видение, строим по слайсам)

- **#4b-4:** боссовость-модуль. Супер-химера как босс локации: фазы/телеграфы/вой-стан стянуть с вервольфа (небольшой отдельный модуль), заменить вервольфа. Роутер §2.3 — точка подключения.
