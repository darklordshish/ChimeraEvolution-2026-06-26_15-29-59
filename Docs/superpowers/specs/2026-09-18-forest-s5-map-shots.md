## Проблема

Лес нельзя показать: поле высот — числа в тестах, террейн — по команде в песочнице,
карты нет вовсе. Нужны детектор рельефа (как КАРТА_ТЕЛ для тел) и первые скрины.

## Решение (s5: построение карты + скрины, биомы — позже)

`Scripts/Forest/Scenic/`:

- `ForestMapBuilder` (чистый): `BuildColors(cfg, res, step)` — базовый рельеф
  (низина сочная → камень серый → высота костяная — как вертекс-цвет террейна);
  `BuildSteepMask` — крутые клетки отдельным слоем (в базовый PNG не запекаем —
  убивает шкалу); `BuildStats` (min/max высота, макс уклон, крутые/всего);
  `ColorsHash` — хэш по цветам клеток, не по байтам PNG (кодировщик поплывёт).
- `ForestMapWriter` (тонкий IO, без тестов — как `ShotSpecies`/`Stand`): два PNG
  (`КАРТА_ЛЕСА.png` база + `КАРТА_ЛЕСА-крутизна.png` с красным слоем) + `КАРТА_ЛЕСА.md`
  (сид, статистики, подпись «рельеф, не биомы; слой логовищ — s2b»). PNG 256 при сетке 64.
- `ForestScenicTool` (энтрипойнты для `run_script`): `GenerateMap`, `SetupCameras`
  (TopCam сверху-орто + SandboxCam 3/4 — два пресета, карта перспективой не снимается),
  `BuildTerrain`/`WipeTerrain` (террейн строится командой, не хранится — как Полигон).
- Скрины: `capture_game_view` TopCam (топдаун-орто, детектор) + SandboxCam (3/4, красота) →
  `Docs/Диаграммы/Лес/Кадры/`. Сцена хранит только Sun/камеры.

Принято от связки: слой крутизны отдельно + подпись «не биомы» + хэш по цветам +
негатив DifferentSeeds + Writer тонкий.

## Инварианты (EditMode `Tests/EditMode/Forest/Scenic/ScenicTests.cs`, 5 тестов)

Тот же сид — те же цвета; разные сиды — разные; размеры res²; плоский конфиг — 0 крутых,
крутой — >0; Stats чист ⟺ `WorldRules.CheckGrid` чист (согласованность детекторов).

## Что НЕ делаем

- Слой логовищ на карте (фейковые точки запрещены — ждём реальные `LairSite`, s2b).
- Биомы/растительность, свет/туман в сцене (s3b-визуал), LOD.
- Правки чужих файлов — только чтение.

## Приёмка

`run_tests --mode editor` зелёный (5 новых) + карта и 3 скрина лежат в `Docs/Диаграммы/Лес/`.
Диагностика цвета 3D (задел s3b-визуалу): вертекс-цвета URP/Lit не ест (кадр ровно-синий);
планарный UV + текстура из цветов карты легли (красный краситель — темно-красный),
но рендер сине-серый: свет intensity 2 картину не меняет — свет/sky нуждаются в разборе.
Геометрия доказана (силуэт, нормали +Y тестом, совпадение с картой).
Плейтест не нужен. `Docs/СТАТУС.md` — за `docs-keeper` при мердже.
