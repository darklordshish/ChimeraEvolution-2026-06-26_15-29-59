## 0. Контекст: тип-B и его кластеры

Поведение видов захардкожено через `GetComponentInParent<XxxPsyche>` (~17 геймплейных мест + 6 дев). Химера-NPC не имеет одного `XxxPsyche` → тип-чеки об неё ломаются. Рекон разложил их по СМЫСЛУ:

| Кластер | Что решает | Слой | Куда |
|---|---|---|---|
| **КИН** (~7) | «свой ли (не пугать/собрать/не глушить)» | чистая идентичность | **#4a (эта спека)** |
| **Странный шум** (1) | «не-свой ли звук» | идентичность (не-кин) | **#4a** |
| **Добыча/угроза** (~6) | «моя добыча / мой хищник» | НАПРАВЛЕННЫЙ матчап (состав) | #4b |
| **Голос-реакция** (3) | «кто как отзывается на вой/рёв» | поведение-модуль | #4b |
| **Дев-тулзы** (6) | счётчики видов в дев-панели | editor-only | позже (реестр) |

**Почему добыча/угроза НЕ здесь:** это не идентичность, а матчап способностей. В коде прямо: змея БЕЖИТ от ежа (`SnakePsyche:363`) — «против него у неё нет ни одного приёма: яд не берёт, бросок налетает на иглы, обхват срывается об них же»; волк ест ежа только голодным (иглы-риск). Причины = яд vs ядоупор, обхват vs иглы — рассуждение о СОСТАВЕ, то есть поведение (#4b с женерик-ядром).

## 1. Scope #4a

**Заменить кин-тип-чеки на ТИР-ОСОЗНАННЫЙ предикат идентичности.** Кин-кластер + странный шум. Поведение-сохраняюще для 5 чистых видов. Кладёт идентичностный фундамент, на котором #4b построит таргетинг.

## 2. Дизайн: тир-осознанный кин-предикат

**Уже есть:** `static KinTier Regard(CreatureBody observer, CreatureBody target)` (Identity.cs); `enum KinTier { None, Weak, Medium, Strong }` (порядковый: None=0…Strong=3); `MostKin(out KinTier)` — доминантный вид тела.

**Новое — инстанс-хелпер на `CreatureBody` (Identity.cs):**
```csharp
// «признаёт ли ЭТО тело во мне своего» — тир-осознанно. Порог по умолчанию Weak (внутривидовое узнавание
// лениво: свои читают тебя рано). Химере даёт градиент: чем больше моего вида в теле, тем выше тир
public bool IsKin(CreatureBody other, KinTier minTier = KinTier.Weak) => other != null && Regard(this, other) >= minTier;
```

**Градиент узнавания (инфраструктура #4a, гейм-эффект — с химерами #4b):**
- **Weak** — «настораживается, не сразу нападает».
- **Medium** (tier-2) — «путает за своего» (химера «вид с изюминкой»).
- **Strong** — «полностью свой» (зовёт в стаю).
Разные кин-поведения МОГУТ гейтиться на разных тирах — но это ручки эпохи химер; в #4a дефолт `Weak` (лениво, внутривидовое).

**Поведение-сохраняюще:** у 5 чистых видов `Regard` между разными видами = `None`, к своему = `Strong`. Любой порог (Weak…Strong) даёт то же самое, что бинарный тип-чек. Тир-градиент оживает только на телах со СМЕШАННЫМ составом (химеры, химеризующийся игрок).

## 3. Замена тип-чеков (кин-кластер)

Каждое место: взять `CreatureBody` соседа (`GetComponentInParent<CreatureBody>`) и `ownBody.IsKin(otherBody)` вместо `GetComponentInParent<XxxPsyche>`. Психики уже кэшируют `ownBody` для существующих `Regard`-вызовов.

| Файл:строка | Сейчас | Станет |
|---|---|---|
| `MoosePsyche:206,249` | `GetComponentInParent<MoosePsyche>()==null` → пугать | `!ownBody.IsKin(other)` → пугать не-кина (лосей щадим) |
| `MoosePsyche:210` | найти лося-собрата | найти кина рядом |
| `WolfPsyche:158` | найти волка-собрата (спасение) | найти кина |
| `WolfPsyche:569,845` | счёт/разлёт волков-стаи | счёт/разлёт кинов |
| `WerewolfPsyche:234` | `GetComponent<WolfPsyche>()==null` → глушить | `!ownBody.IsKin(other)` → глушить не-кина (своих не глушим) |
| `WolfPsyche:142` (странный шум) | `Snake\|MoosePsyche != null` | `ownBody.Regard(srcBody)==None` (не-кин звук странен) |

**Гоча:** странный шум (142) — сейчас исключает и игрока (src=игрок → не странен). Через `Regard==None` не-волчистый игрок станет «странным» (волк любопытствует на его шум). Скорее приемлемо (мелочь), но проверить на плейтесте; при желании оставить явное «не игрок» рядом.

## 4. НЕ трогаем (осознанно)

- **Добыча/угроза (матчап)** → #4b. Направленные хищник-жертва (RPS-круг ёж→змея→волк→ёж) не сводятся к скаляру, причина — контры способностей. Женерик-ядро #4b решит таргетинг на `IsKin` (отсюда) + рассуждении о составе.
- **Голос-реакция** (KinVoice/PlayerHowl: кто как отзывается) → #4b (поведение-модуль).
- **Дев-тулзы** (счётчики видов) → позже (реестр видов), не геймплей.

## 5. #4b-ЗАДЕЛ (записано, НЕ строим сейчас — носителя-химеры нет)

Идея пользователя, зафиксирована как направление #4b:
- **Вневидовая классификация:** чужие читают химеру по её ДОМИНАНТНОЙ идентичности (`MostKin`), не по `Regard(наблюдатель, цель)`. Лось видит доминанту=волк → относится как к волку (угроза). Волк-со-змеиным-хвостом = «волк с изюминкой» и для волков, и для чужих.
- **Асимметрия порогов:** ВНУТРИвидовой (свои узнают) — послабее (`Weak`), ВНЕвидовой (чужие классифицируют как вид-X для таргетинга) — построже (`Medium`/tier-2). Ниже tier-2 — «сомнения, кто ты».
- Всё это тюнится, когда есть NPC-химеры-носители; строить вслепую — модель впереди носителя.

## 7. Риски / гочи

- **Поведение-сохраняюще для 5 видов** — контрольная проверка: волк так же зовёт волков, лось так же щадит лосей, вервольф так же не глушит волков; ничего не изменилось у чистых видов.
- **Странный шум** (см. §3) — единственное место с возможным сдвигом (игрок теперь может стать «странным» для волка). Проверить.
- **Игрок-химера — живой носитель ВНУТРИвидового тира УЖЕ сейчас:** волчистый игрок (родство-волк ↑) должен читаться волками как кин по порогу. Лёгкая проверка градиента без NPC-химер.

## 8. Верификация (плейтест-чекпоинты)

1. **Чистые виды не изменились:** волчья стая собирается/спасает/разлетается как раньше; лось не пугает лосей рёвом; вервольф войом не глушит волков; змея/лось детектятся волком как прежде.
2. **Странный шум:** волк реагирует на шум змеи/лося как раньше (любопытство); проверить поведение на шум игрока.
3. **Градиент (лёгкий, игрок-химера):** нахимеренный в волка игрок постепенно перестаёт быть чужим для волков (по мере роста родства-волк → тир). Полный эффект — с #4b/NPC-химерами.
