## Проблема

Оружие бьёт только в руках: подготовить поле боя нечем. Нужен силок — положенный заранее
удар без владельца рядом.

## Решение (s4c: ловушка как отложенный MeleeBlow)

`TrapDef` (plain-класс, Gear/): id, damage, bleedStacks, slowStacks, radius, uses=1 + Validate
(урон/радиус/uses > 0, стаки ≥ 0). Это НЕ захват: рвёт/калечит, не душит и не держит —
слово «захват» в именах/текстах не используем (иначе врём ожиданиям).

`PlacedTrap` (`MonoBehaviour`, Gear/): `Arm(owner, def)` → `Update` поллит
`TargetScan.Healths` (те же правила, что удары: без себя, игнор триггеров) → первая живая
чужая Health (трупы не триггерят) → `MeleeBlow{damage,bleed,slow}.Deliver(Hit(owner))` +
`uses--` → при 0 самоуничтожение. Одна жертва за тик. Владелец умер/деспавнился (null) —
ловушка инертна (null-check). Установка игроком (кнопка/инвентарь) — не здесь.

Принято от связки: паёк вместо машины Constrict + атрибуция владельцу (родство/эволюция
работают заочно, как яд/снаряды) + uses=1 с заделом (перезарядка — YAGNI).

## Инварианты (2 EditMode + 2 PlayMode)

EditMode `TrapDefTests.cs`: валидный чист, битый ловится.
PlayMode `TrapTests.cs`: `Trigger_HitsVictim_Consumes` (телепорт + SyncTransforms + 2×yield:
HP −damage, uses 2→1 без сноса, затем исход; снос проверяем после кадра — Destroy отложен),
`IgnoresOwner` (владелец в радиусе — цел, uses цел). Болванка: `SphereCollider`
с `isTrigger=false` явно. `TearDown`: `timeScale=1`.

## Что НЕ делаем

- Перезарядку ловушки, фильтр «чужой по Regard» (сейчас любой не-owner), установку игроком,
  SO-ассеты, свет/звук срабатывания.
