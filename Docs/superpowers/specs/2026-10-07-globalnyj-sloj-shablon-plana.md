## 1. Проблема

Спека двух слоёв задала, ЧТО делает глобальный слой (ступени, смешение в логарифмах, черты), но не КАК соответствуют
массы тел: скелеты сопоставлены метками, а мышечные бугры у каждого вида свои, и по §4.1 в соответствии не участвуют.
Тогда химера по ступеням не перетекает к цели, а растворяет одни бугры и проращивает другие; а «парное тело» на каждую из
20 пар пришлось бы переносить офлайн. Это та же беда, что консилиум формы назвал «общей задачей вместо конечной таблицы».

## 2. Решения

1. **Мышечные массы — общий шаблон плана тела.** У всех видов одного плана один набор мышечных групп (двуногий,
   четвероногий; змея — своё семейство). Группа — узел формата `rel` на кости цепи: `{at, offX, offZ, len, r0, r1}`
   в долях кости и её радиуса, плюс мягкость слияния. **Набор групп и их кости — правило плана; доли — числа вида.**
   Человек и оборотень, волк и лось различаются только числами. Закон «в данных донора нет метров» соблюдается сам.
2. **Отображение — смешение чисел шаблона** (подход 1 ресёрча). Длины и радиусы в логарифмах, повороты по SO(3) —
   формулы §4.3 спеки двух слоёв, по каждому узлу и группе. Цена — сотни операций; дальше прежняя сборка поля.
3. **Пары одного плана** (волк ↔ лось ↔ ёж): тело цели — её числа в шаблоне шасси, никакого переноса.
4. **Пары разных планов** (человек ↔ четвероногие — это и оборотень): **таблица соответствия групп
   «двуногий ↔ четвероногий»** — конечная, авторская. Группе без пары — рост из нуля или угасание по ступени, как черте.
   Стойка за шасси (решение 8): переносятся массы и пропорции, а не постановка ног.
5. **Черты вида** (грива, хвост, горб) — по-прежнему свободные узлы вида, растут из нуля по ступени (§5 спеки двух
   слоёв). Шаблон — для общих масс, черты — для отличительного.
6. **Детали** (кисть, ригблоки, блоки головы) глобальным слоем не смешиваются — едут за костями, как сейчас. Их формы-
   ключи «→ вид» — отдельный шаг, когда носителей станет больше одного.
7. **Первый срез — человек → волк** (оборотень): ступени 1 и 2, черты волка, сутулая поза; кадр рядом с листом
   оборотня. Остальные пары — после того, как метод доказан кадром.

*Это не возврат «лепки слоями» (⛔ 10.09):* та лепила тело костями вида и вручную; здесь тело — по-прежнему поле
(`BoneMesher`), группы — его узлы по правилу плана, числа снимаются с листа подбором по силуэту.

## 3. Данные (схема — механики, числа — модельная линия)

- **Узел-группа в графе вида:** поле `group` (имя группы шаблона, например `дельта.перед`) у узла `rel`. Один узел на
  группу и сторону; зеркало — как у прочих узлов.
- **Шаблон плана:** `Docs/models/handoff/plan-<план>.json` — список групп: имя, кость цепи (по метке сегмента, а не по
  имени узла вида), сторона. Автор состава групп — модельная линия; механики проверяют полноту.
- **Таблица планов:** `Docs/models/handoff/plan-dvunogij__chetveronogij.json` — пары групп; группа без пары — явно.
- **Тело на ступени:** `body(g) = local ∘ global_g(chassis)` (§5 конструктора): сначала числа шасси идут к числам цели
  с весом `g`, затем локальные аугменты по швам смещённого тела.

## 4. Сторожа

1. **Полнота шаблона:** у каждого вида плана — каждая группа ровно один раз; лишних групп нет (свободное — только черты).
2. **Тождество:** чистый вид на родном шасси (`g` = 0 к себе) — тело как сейчас, до микрона.
3. **Сдвиг к цели:** расстояние по меткам и группам — ступень 2 ближе к цели, чем ступень 1, чем шасси (§7.4 спеки двух
   слоёв).
4. **Нет метров у донора:** числа группы — доли.
5. **Матрица химер** — список долга не растёт; **силуэты** — IoU чистых видов против листа не падает после перевода на
   шаблон.
6. **Кэш оболочки:** ключ включает ступень и цель.

## 5. Порядок — срезами, каждый с кадром

0. **Схема** (механики): поле `group`, чтение шаблона и таблицы в `SpeciesHandoff`, детектор полноты.
1. **Шаблоны двуногого и четвероногого** (модельная линия): человек и волк переводятся на группы; приёмка — кадр и
   силуэт не хуже нынешних, критик.
2. **Таблица «двуногий ↔ четвероногий»** (модельная линия), по листу оборотня.
3. **Функция ступени и смешение** (механики): `g` по порогам §2.2 спеки двух слоёв; сторожа §4.
4. **Кадр «человек · оборотень ст. 1 · ст. 2 · волк»** рядом с листом — геймдизайнер выбирает `g₁`, `g₂`.
5. **Черты волка** (грива, хвост) из нуля; **поза** — поворот грудного отдела у оборотня.
6. Лось и ёж на шаблон четвероногого; остальные пары.

## 6. Развилки за геймдизайнером

- состав групп шаблона — предлагает модельная линия, утверждает геймдизайнер;
- `g₁`, `g₂` — по кадру среза 4;
- сутулость оборотня — глобальный слой ступени 2 или черта волка.
