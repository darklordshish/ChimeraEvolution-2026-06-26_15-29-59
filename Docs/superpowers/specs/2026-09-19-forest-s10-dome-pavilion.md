## Проблема

Бриф-облако геймдизайнера: лес — один из павильонов лаборатории (тёплый биом под куполом
с искусственным солнцем, днём/ночью, погодой), а сейчас это открытый кусок 190м без воды,
без хвойных, без границ мира и без единой постройки. Хотелки: карта ×10 (возможно чанками,
как в индустрии), река+озеро, густой лес, хвойные + папоротники, купол со скалами по периметру,
лаборатория/наблюдательный пункт в центре, ангарная дверь в скалах, светильники-солнце/луна
на своде, ночью светящийся мох как звёзды, погода только ясно/дождь/туман, каменистый склон
с пещерами и гнёздами змей, одно гигантское дерево-ясень с совой, три яруса леса.

## Ресёрч (что сказала команда, сжато)

1. **Чанки/рельеф (techlead):** рантайм-стриминг не нужен — 1.2км влезает в память целиком.
   Паттерн: офлайн-бейк в редакторе + меши чанков с LODGroup. Не берём CDLOD-морф, clipmaps,
   рантайм-эрозию. Рельеф: FBM 5 октав + Ridged 4–5 с маской гор + domain warp 3–4, heightmap
   2048² (0.59м/тексель), генерация Burst `IJobParallelFor`. Эрозия: GPU-droplets 150–250k
   (r=2–3, TTL 32–64) + thermal 20 проходов. Вода: Priority-Flood + D8 + carve 2–3 рек
   (ширина 3–10м, глубина 2–5м) + заливка озёр. NavMesh — один глобальный бейк.
   Зелень — только Indirect/Resident Drawer: 5–10k деревьев + ~100k травы в радиусе 80м.
   Бейк всей карты ~15–40с — норма итерации.
2. **Текущий пайплайн (интегратор):** точки врезки размечены. `SampleHeight(cfg,x,z)` уже
   в мировых координатах — чанк-готов. Резать надо `TerrainApplier.Build()` (сегодня единый
   квадрат, потолок `resolution ≤ 128` — первая стена ×10). Вода сейчас СКАЛЯР `waterLevel` —
   замена на маску/линию заденет ровно трёх потребителей (`FloraScatter`, `FloraWaterTint`,
   `PaintRelief`) + слой воды на карте. Новые виды флоры — `FloraKind` → `FloraMeshKit` →
   диспетч `k%3` → `FloraConfigSO`, соли брать свободные (11/22/33/44 заняты). Здания —
   повторять паттерн бункера s9 (кит-раскладка + плейсер + витрина + exclusion).
3. **Купол/небо (художник):** скальное кольцо — отдельный меш-лента (`ridged-fbm(angle)`,
   пик 60–120м, ширина 80–150м). Свод — инвертированная сфера R~800–900м, ОДИН Unlit-шейдер:
   дневной градиент + 2D FBM-облака + ночной мох-звёзды + диски солнца/луны; переключение
   uniform `DayNightT`. Orbital rig: 1 Directional за раз (тени кастит одно тело, второе
   выключено), Forward, лимит `1 main + ≤8 additional`. Дождь + `Wetness` земли, туман —
   две кривые от фазы суток (дальний + приземный height-слой, пики на рассвете/закате).
   Не берём: volumetric-облака/туман, VFX Graph, рёбра панелей на своде, стор-киты.
   Лаборатория — свой микро-кит 12–15 мешей на сетке 2м, 1–2 атласных PBR-мастера;
   POI и коллайдеры — данные в SO, сцена чистая.
   ⚠️ Поправка арт-директора (см. раздел «Арт-направление»): градиент/облака свода —
   квантованные 3–4 ступени (не смус), мох-звёзды — инстанс-геометрия (не emissive-маска,
   HDR>1 и bloom вычеркнуты), ripple-нормали удалены (puddle — плоский блик), дождь —
   flat-призмы (не мягкие Shuriken-стрипы).
4. **Экосистема (эколог):** порядок сева: деревья → кусты → трава. Кластеризация
   `clump=FBM(60–120м), mask=smoothstep(T=0.50–0.55, falloff 0.15–0.25)`; пояса:
   хвойные выше/суше, лиственные кольцом 10–30м у воды. Деревья 8–15k, кусты 5–10k,
   трава 0.5–1.5 клампа/м² (300–700k в данных, 30–120k видимо, cull 80–120м, без теней).
   Озеро 80–140м по длинной оси + речка 3–5м × 300–600м, уклон 1–3%, берега `wetMask`.
   Склон: `slope>30–35°`, скалы 300–800 инстансов, пещеры — ТОЛЬКО ниши-обманки
   (арка + тёмная карта + портал-данные, heightfield не умеет козырьки), гнёзда —
   POI поверх логово-системы (3–6). POI: лаборатория flatten R20–30м, супер-дерево
   exclusion 35–50м и >80–120м от лаборатории, ангар-дверь Gateway в кольце лицом внутрь,
   связность — BFS по сетке 2–4м как acceptance-тест генерации.

## Решение (масштаб + интерфейс утверждены 19.09; код — пофазно s10a…s10i)

- **Масштаб: Ø2000 (R1000, дефолт), настраиваемый одним полем `mapDiameter`.** Формулы
  масштабирования (перепроверка techlead 19.09, D — вход): `R=D/2`, `n_чанков=ceil(D/250)`
  (D=2000 → 8×8×250м, из них ~50 накрывают круг; 10×10×200 отклонено: +56% чанков без
  выигрыша), `N_HM=2^ceil(log2(D/0.6)) ∩ [2048,4096]` (D=2000 → 4096², тексель 0.49м;
  2048² на 2000м НЕ режет речку 3м), `drops=0.177×A` (R1000 → 500–650k батчами ≤150k,
  иначе TDR), NavMesh ТОЛЬКО тайлами (`tiles=ceil(D/112)²`, воксель 0.35м; моно-бейк
  44M ячеек / 3–6ГБ — запрещён), `Rin=R-80, Rout=R+140`, пик кольца 100м const,
  `Rv=1.4×R`, `far=4×R`, cull деревьев `min(350,0.35R)`/cut `0.8R`, билборды 300–800м
  обязательны. Бюджеты Ø2000: деревья 35–45k целью (сырца 47–66k), кусты 12–20k,
  трава 500k–1M записей, флора ТОЛЬКО Indirect (8–16 draws), кадр 1.0–1.5M tris
  (старый лимит 300–600k мёртв). Бейк полный 70–140с тайловый; **fast-preview 20–45с
  обязателен** (прокси 1024² + HM2048 + крупный воксель).
- **Интерфейс подключения — 1:1 как арена (сверка с `ArenaWalls` 19.09, ДЕЙСТВУЕТ).**
  Новый `ForestBuilder : MonoBehaviour` на пустом объекте в центре мира,
  `[RequireComponent(typeof(NavMeshSurface))]`: сериализованные `seed` (дефолт 1337) +
  `randomSeed` (дефолт true, рогалик) + `mapDiameter` (дефолт 2000, аналог `arenaSide`) +
  поля плотности (аналог `mazeCells`); `Awake()`: сид → террейн → флора → постройки →
  `collectObjects=Children` + `BuildNavMesh()`; всё построенное — дети `transform`
  (никаких `GameObject.Find("~...")` в игровом пути); лог-фраза дословно по образцу:
  `"ForestBuilder: случайный сид {seed} (для воспроизведения — выключи randomSeed и впиши
  его)"` + итоговый лог состава; сцена хранит только объект с полями, геометрия
  перестраивается каждый Play; `Clear()` на пересборку сохранить. Команды
  (`Showcase`/`BuildPreview`/`BuildTerrain`) остаются редакторским инструментом, не путём
  подключения. Один сид → один мир: террейн, скаттер, руины едят тот же `seed`.
- **Бейк в редакторе + рантайм-путь через `ForestBuilder`, чанки 8×8×250м**
  (LOD0 128² <150м / LOD1 64² 150–500м / LOD2 16² >500м, skirt+общий бордер,
  видимое 250–550k tris террейна, 30–50 draws). NavMesh — тайлами + линки на бродах.
- **Рельеф/вода по п.1 ресёрча** (числа — выше). `waterLevel`-скаляр умирает, рождается
  `WaterMask` (озеро-плейн + лента реки); три потребителя переключаются тем же заходом.
- **Купол/небо/свет по п.3** (один шейдер свода, orbital rig, fog-кривые, Shuriken-дождь).
  Снег в павильоне запрещён таблицей шансов (enum `Snow` остаётся для других павильонов).
- **Экосистема по п.4** (3 яруса, озеро+речка, склон-ниши+гнёзда, супер-ясень 40–60м +
  сова как `LairSite{Nest}` в кроне, лаборатория 4 бокса + ангар-Gateway, BFS-связность).
- **Сквозные инварианты линии (не обсуждаются):** детерминизм сидом (новые потоки —
  новые соли, старые не сдвигаются), `version++` при смене алгоритма, сцена чистая
  (`Clear()` на всё построенное), бейк разом собирает коллайдеры, кадры+карта на каждую фазу.

## Арт-направление: атмосферный лоу-поли (вердикт designer-artdirector 19.09)

Канон проекта подтверждает: плоские грани — язык мира (`BoneMesher.Flat`, выбор 17.09),
палитра — приглушённо-холодная (Valheim-школа), туман — часть стиля и бюджета (GDD §9:
«техника дешёвой красоты»), силуэт первичен. Эталон флоры уже в кадре: ствол-призма +
крона из 2–3 икосаэдров.

- **Фасетка обязательна везде** (чанки, кольцо, постройки, флора, скалы, кромка воды);
  smooth — только диски светил и нутро ниш. Приёмка: «грань бликует целиком».
- **Палитра закрыта:** террейн `#4A7D3B`/`#808080`/`#DED4B8`, туман `#C7D1D6` (Exp2 ≤0.012 —
  верх дня, не норма), солнце `#FFF1DB` 1.3 + трилайт `#A8BFD4`/`#7D8578`/`#5C594D` 0.75,
  постройки по s9 (`#6E7478`/`#54595E`/`#23262A`/`#5A6B3A`/`#8A4A2B`). Маркер крутизны
  `#D9261A` — только детектор, в игру запрещён.
- **Переходы — жёсткие пояса** slope/height/aspect + джиттер ±1 грань. Triplanar с мягким
  блендом запрещён (мыло против фасетки): только плоские заливки по маскам.
- **Свод:** градиент и облака квантовать 3–4 ступени (banding как стиль); облака — фасеточные
  блины или квантованный FBM, дрейф жёстким скроллом; звёзды — инстансы-октаэдры 2 ступеней
  по `DayNightT`, без bloom.
- **Вода:** плоская заливка + 2-ступенчатый блик; берег — `wetMask`-пояс темнения на ступень.
  Дождь — flat-призмы, 2 кадра флипа; wetness — ступень альбедо + ступень roughness.
- **Бюджеты:** дерево 150–400 тр, куст 40–120, трава без теней, скала 80–200 (300–800 шт),
  супер-ясень ≤5к (один); видимое — 300–600к тр.
- **Туман** — две кривые суток с пиками на рассвете/закате; топдаун-кадры — без тумана
  (прецедент s9). Приёмка фаз — кадры день/закат/ночь: силуэт читается с 10м.

## Фазы (каждая — спека-довесок + код + тесты + кадры, мердж в `infra/forest` только целиком)

- **s10a** рельеф: `DomeGenConfigSO` (сид+`randomSeed`+`mapDiameter`=2000+плотности) +
  `DomeGenRules` + чанки + FBM/Ridged/Warp на Burst + GPU-эрозия батчами + скальное кольцо
  + скелет `ForestBuilder` (поля+лог-фраза, без полного Awake-пути). Тесты: конфиг/правила,
  швы чанков 1:1, slope-gate, детерминизм. Кадры: топдаун + 3/4.
- **s10b** вода: Priority-Flood + D8 + carve реки + котловина/плейн озера + `WaterMask`
  вместо скаляра. Тесты: река монотонно вниз, озеро = spill+epsilon, берега гейтят флору.
- **s10c** купол+свет: свод-меш + квантованный шейдер неба + звёзды-геометрия + orbital rig
  + fog-кривые. Приёмка кадрами (день/закат/ночь), без автотестов осознанно (жанр «глазами», как s7).
- **s10d** флора: хвойные + папоротники в ките + ярусы + Indirect-контейнер + LOD/billboard/cull.
  Тесты: outward-нормали, объём, shared-материалы, перф-бюджет Build.
- **s10e** склон: slope/aspect-маска + rock-kit + 2–4 ниши + 3–6 гнёзд поверх `LairSite`.
- **s10f** лаборатория + ангар: микро-кит 2м + 4 бокса + Gateway-дверь + POI-данные + BFS-тест.
- **s10g** супер-ясень + сова (отдельный префаб, exclusion, Nest в кроне).
- **s10h** погода павильона: таблица без снега + flat-дождь + wetness-ступени (без ripple/puddle-нормалей) + туман-расписание.
- **s10i** витрина `DomeShowcase` + карта + 5 кадров + сводный отчёт.

## Что НЕ делаем (зафиксировать, чтобы не расползалось)

- Рантайм-стриминг чанков, CDLOD-морф, clipmaps, воксели/marching cubes ради пещер,
  честные тоннели в heightfield, volumetric-облака/туман, VFX Graph, снег в этом павильоне,
  ручная расстановка чего-либо, GameObject на каждое дерево.
- По запретам лоу-поли (арт-вердикт): smooth-шейдинг мира, triplanar с мягким блендом,
  смус-градиенты свода, bloom ради звёзд, ripple-нормали и puddle с нормалями, мягкие
  полупрозрачные партиклы дождя, рёбра/панели на своде, расширение палитры построек за s9.
