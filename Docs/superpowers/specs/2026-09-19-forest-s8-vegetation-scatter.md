## Проблема

Лес без деревьев — не лес: есть террейн, нет ни ствола. Нужны стволы/скалы/кусты/трава
и вода хотя бы числом.

## Решение (s8: кит + scatter + вода-заглушка, без FBX)

`Scripts/Forest/Flora/`:
- `FloraKind`: PikeTree/UmbrellaTree/DeadHook/SlabRock/SpikeRock/Bush/Grass.
- `FloraConfigSO`: counts (trees 40/rocks 12/bushes 24/grass 200), minDistance 3м.
- `FloraMeshKit` (чистый): процедурный кит гранями — сужающийся брусок-ствол,
  крона = 2–3 сплюснутых икосаэдра, скала-плита (бокс), шип (конус), куст = 3 икосаэдра
  гроздью, трава = кросс-квады. Канон как у ригблоков. Порядок обхода — наружу
  (сторожит тест outward-нормалей; эмпирика winding — из `TerrainApplier`: нормаль Unity =
  `cross(B−A, C−A)`).
- `FloraScatter` (чистый): rejection sampling по гриду (ячейка = minDist, проверка 3×3),
  детерминирован (`SeededHash` + счётчик, без `Random`); фильтры: уклон > лимита и
  `y < waterLevel` (пруды чистые). Возвращает точки (pos/scale/rotY), может меньше count.
- `FloraWaterTint` (чистый): затемнение клеток ниже waterLevel к мокрому дну.
- `FloraPlacer` (`MonoBehaviour`): `world + flora`, 4 shared-материала
  (ствол/лист/камень/трава, `enableInstancing`, декор без теней — авто-инстансинг вместо
  ручного Indirect: тот же GPU-батчинг, в 10 раз меньше кода; дистанционный cull — позже).
  Блокеры: ствол-капсула ~0.3м, шип — MeshCollider, плита >1м — бокс; кроны/куст/трава —
  без коллайдеров (куст скрывает, но проходим — как `ForageSpawner`). Корень `Flora`
  под GO аппликатора (тест) — бейк разом собирает стволы, carve только динамике.
- Вода: ТОЛЬКО число `waterLevel` в `WorldGenConfigSO` (s1-правка тем же заходом,
  дефолт −1.5м) + исключение из scatter + тинт террейна (хук 3 строки в `PaintRelief`,
  s5-правка тем же заходом). Плоскости с fresnel нет (GDD: море — v3.0, здесь только
  будущий водопой).
- Энтрипойнты `FloraPreview.BuildPreview/WipePreview` (в `FloraPlacer.cs`): террейн +
  флора в песочнице для кадров.

Принято от связки: кит вместо 7 FBX + бейк разом + вода числом + shared-материалы
(отклонение от Indirect зафиксировано здесь).

## Инварианты

EditMode `FloraTests.cs` (~9): детерминизм, min-distance, нет точек на крутизне/в воде,
counts в норме, габарит кита, outward-нормали (кроме травы), тинт (ниже темнеет, выше цел).
PlayMode `FloraPlacerTests.cs` (1): мелкий террейн + флора + бейк → коллайдеры стволов есть,
трава на одном материале, угол-угол `PathComplete`.

## Что НЕ делаем

- FBX-модели, LOD/cull дистанции, Volume-трава с ветром, рыбу/водную симуляцию,
  `LairSite` в кустах (s2b-контекст), чистопородность.
