## 0. Контекст: где мы в #4b

#4b — САБ-ПРОЕКТ (не один слайс). Полное видение — диспатч (идентичность→модуль) + capability-generic поведение + матчап-таргетинг + химера-альфа-фолбэк + видовые-модули. **Первый слайс — НОСИТЕЛЬ-first: тест-химера-ТЕСТБЕД.** Не психика, не диспатч, не поведение — а КОНКРЕТНОЕ смешанное тело, на котором мы будем ВИДЕТЬ идентичность/состав и против которого проверять следующие слайсы (диспатч, химера-альфа, capability-generic).

## 1. Scope #4b-1

**Dev-спавнимая тест-химера:** сфера-заглушка + случайный-СПАННИНГ состав (шасси+аугументы) + тинт-по-составу + ридаут идентичности. **Психики/поведения НЕТ** — сфера просто стоит и показывает, кто она по составу. Тестбед.

## 2. Дизайн

### 2.1 Тело тест-химеры
`CreatureBody` со случайным шасси + случайными донорами + случайно надетыми аугументами. Спавнер (рантайм) собирает её на лету.

**Проблема:** `chassis`/`donors` — приватные `[SerializeField]`, в рантайме не выставить (генераторы префабов ставят их `SerializedObject`-ом в editor-time). **Решение — новый публичный runtime-конфиг на `CreatureBody`:**
```csharp
// РАНТАЙМ-СБОРКА (тест-химера/будущая стохастическая химеризация NPC): задать шасси+доноров и пересобрать.
// Обычные тела конфигурятся сериализацией (префаб/бутстрап); это — для рождённых на лету
public void Configure(SpeciesSO newChassis, SpeciesSO[] newDonors)
{
    chassis = newChassis; donors = newDonors;
    BuildSlots(); Recompute();
}
```
Затем спавнер ставит случайные аугументы через уже публичный `Install(slot, variant)` (из #2A).

### 2.2 СПАННИНГ спектра идентичности (не равномерный рандом)
Нужны ВСЕ случаи для будущего диспатча:
- **доминанта-вид** (в основном один вид + пара чужих органов → tier Medium/Strong) — тест «получит видовой модуль»;
- **истинная химера** (мешанина, `MostKin` == null) — тест «получит химеру-альфу».
Генерация: случайное шасси; случайное ЧИСЛО аугументов (0..N) от случайных доноров в случайные слоты. Малое число → доминанта шасси; много разных → истинная химера. Ре-ролл даёт разброс по спектру.

### 2.3 Идентичность-ридаут (определение почти готово)
`MostKin(out KinTier tier)` уже возвращает доминантный вид + тир (null = «кин ни к кому» = истинная химера). Слайс: ПОКАЗАТЬ это над сферой — дев-панель-ридаут выбранной/ближайшей тест-химеры: «доминанта: Волк (Medium)» или «истинная химера (доминанты нет)». Переиспользуем паттерн показа родства игрока.

### 2.4 Сфера + тинт
Примитив-сфера (заглушка, модели — по роадмапу позже). **`CompositionTint` включить на тест-химере** (сейчас `if (move != null)` — только игрок; NPC — запечённый материал). У сферы-заглушки нет запечённого материала/`Telegraph` (он у игрока) → тинт-по-составу без конфликта. Механизм готов (`CompositionTint` в `CreatureBody.Tint.cs`).

### 2.5 Спавн
Дев-панель (`ChimeraDevWindow`, уже спавнит виды) — кнопка «спавн тест-химеры» + ре-ролл. Опция «собрать конкретную» — позже, если понадобится точный кейс (пока случайно+реролл).

## 3. НЕ в #4b-1 (следующие слайсы)
- **Диспатч** (идентичность→модуль) — #4b-2.
- **Химера-альфа психика** (агрессивный апекс, `!IsKin`) — модуль-фолбэк, #4b-2/3.
- **Capability-generic поведение** (психика юзает любой канал тела, вкл. бонусный термал) — по ходу.
- **Матчап-таргетинг** (добыча/угроза направленный) + **голос-реакция** — извлечение модулей позже.
Тест-химера ПОКА без психики — стоит и показывает состав.

## 4. Точки касания
- `Player/CreatureBody.cs` — `Configure(chassis, donors)` runtime-API.
- `Player/CreatureBody.Tint.cs` или `Recompute` — включить `UpdateTint` для тест-химеры (флаг/условие «тинтить NPC»).
- `Editor/ChimeraDevWindow.cs` — кнопка спавна + ридаут идентичности.
- Новый рантайм-спавнер тест-химеры (сфера + `Configure` + случайные `Install`) — `Progression/` или `Debug/`.

## 5. Риски / гочи
- **Runtime-`Configure` vs жизненный цикл:** `BuildSlots`/`Recompute` рассчитаны на Awake/сериализацию; вызвать вручную после `AddComponent` — проверить порядок (компоненты-приёмы до-создаются в `Recompute`; сфера-заглушка без психики их не драйвит, но провизия отработает).
- **Тинт NPC vs Telegraph:** у сферы `Telegraph` нет → конфликта нет; но условие «тинтить NPC» не должно задеть обычных NPC (запечённый материал). Гейтить по флагу/только тест-химере.
- **Случайный билд degenerate:** ролл может дать «почти чистого» (не химера) или пустого — норм для спаннинга, но ридаут должен честно показать «доминанта X» / «истинная химера».
- **Пул/бюджет:** NPC надевают органы без гейта пула (BuildSlots ставит native; Install для аугументов) — проверить, что случайные Install не упираются в пул (или игнорить пул для тест-химеры).
- **Истинная химера (`MostKin` null) — РЕШЕНО, достижима:** пользователь проверил — собирал ИГРОКА в химеру, не кин никому (`MostKin` null). Значит определение «истинная химера = `MostKin` null» держим СТРОГО (не переопределять на «доминанта ниже Medium»). Спавнеру нужен лишь разброс аугументов по МНОГИМ видам, перебивающий вклад шасси (как у нахимеренного игрока) — генерация-спаннинг (§2.2) это и даёт.

## 6. Верификация (плейтест)
1. Дев-кнопка спавнит сферу-химеру; ре-ролл даёт РАЗНЫЕ (цвет меняется — состав виден).
2. Ридаут показывает идентичность: часть роллов — «доминанта Волк/Змея/… (тир)», часть — «истинная химера».
3. Спектр покрыт: есть и доминантные, и истинные химеры (важно для диспатча потом).
4. Цвет сферы = смесь тинтов видов состава (волчистая — серее, змеистая — зеленее, каша — грязнее).

## 7. Порядок слайса
1. `CreatureBody.Configure` runtime-API + включение тинта для тест-химеры.
2. Рантайм-спавнер: сфера + `Configure` случайным шасси/донорами + случайные `Install` (спаннинг).
3. Дев-панель: кнопка спавн + ре-ролл + ридаут идентичности.
4. Коммит: «фича: тест-химера-тестбед — сфера, случайный состав, тинт, ридаут идентичности».

## 8. #4b-ЗАДЕЛ (полное видение, строим по слайсам)
Диспатч: `доминанта дотянула до порога → её модуль; иначе → химера-альфа (апекс, чужд всем)`. Модули = видовые психики, доведённые до capability-generic + предикатов (тип-B → идентичность). Присвоение психики переезжает с префаба в рантайм-компилятор. Матчап-таргетинг (сенсорика+контрах, RPS-круг) и голос-реакция — извлекаемые модули. Асимметрия порогов узнавания: внутривидовой слабее, вневидовой строже (см. #4a-спеку). Payoff — стохастическая химеризация оживляет лес.
