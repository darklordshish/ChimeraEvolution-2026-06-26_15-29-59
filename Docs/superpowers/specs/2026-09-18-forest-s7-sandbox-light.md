## Проблема

Террейн синий: intensity 1→2 байты 1:1. Диагноз связки: `Sun m_Type:2` = Point с Range 10
в точке внутри террейна 60м (дефолт `AddComponent<Light>`) — дальнее поле освещено только
ambient (`Sky 0.21/0.22/0.26, Mode 0` — вот и синева); коричневый фон — нижняя полоса
дефолтного скайбокса в `SandboxCam`. Только код, руками в инспекторе не лазить.

## Решение (s7: риг света кодом, Volume — позже)

`ForestLightSetup.SetupSandbox()` (`Scripts/Forest/Scenic/`, entry для `run_script`):
- Sun: `Directional`, угол (35,140,0) оставить, `Intensity 1.3`, `Color #FFF1DC`,
  тени Soft + Strength 1.0, `RenderSettings.m_Sun = Sun`.
- Ambient: `Trilight`, Sky #A8C0D4 / Equator #7E8478 / Ground #5C5A4E, Intensity 0.75.
- Skybox: процедурный ассет `Assets/_Chimera/Materials/ForestSky.mat` (создаётся кодом,
  не руками): SkyTint #9BB6CE, Ground #6A6A5E, Exposure 1.0, SunSize 0.04.
- Fog: Enabled, Exp2, Density 0.012, Color #C7D0D6.
- Сохранение сцены — командой (`save_scene`), только песочница.

Принято от связки: числа художника + Volume не заводить (RenderSettings достаточно для v0)
+ приёмка парой кадров + сверка тона с картой.

## Инварианты

Автотестов нет (прецедент: свет — жанр «кадр глазами», golden-кадров нет от флаков).
Приёмка: `Лес-топдаун.png` (TopCam) + `Лес-34.png` (SandboxCam) пересняты в
`Docs/Диаграммы/Лес/Кадры/` + тон террейна ≈ тонам `КАРТА_ЛЕСА` + обе моды зелёные
