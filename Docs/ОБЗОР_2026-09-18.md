## 1. Резюме одним экраном

**CHIMERA** — Unity 6 (6000.4.7f1) URP рогалик «по флоу» про учёного, химеризующего своё тело (`CLAUDE.md:3`). Статус: давно превзошла MVP (3→5 видов), играбельна, лес живёт без игрока, эволюция NPC замкнута.

| Измерение | Факт |
|---|---|
| **Геймплей** | Петля `петля → родство → конструктор → босс` замкнута. 5 видов (человек/волк/змея/лось/ёж) + босс-суперхимера из того же конструктора |

## 2. Геймплей

**Источник:** `Docs/CHIMERA_GDD_v0.18.md:1` (646 строк / 97 КБ), `Docs/CONSTRUCTOR_GUIDE.md:1` (200 строк), `Docs/СТАТУС.md:58`

**Премиса (GDD §1):** Последний создатель сбежавшей Химеры-0 вкалывает её же сыворотку и идёт сквозь окуклившуюся лабораторию. Жанр — слэшер/ARPG рогалик «по флоу», PC 18+, URP.

**Петля (GDD §4):** `Человек (шоссе) → Арена (стаи волков, засады змей, территориальный лось, ёж-стрелок) → убийства → родство → Лаборатория-конструктор (размен органов в пуле мутагена) → зачистка? → Босс-суперхимера → след. зона`. Смерть сбрасывает сборку/шкалу мозга/родство; переносится — разблокировки/мета-валюта. Вариативность — в маршруте зон + родстве от боссов, не в рандоме перков (Hades-паттерн).

**Зоны и биом (GDD §8):** Живой лес кругом `ёж → змея → волк → ёж`, живёт без игрока (едят, охотятся, расходятся). Игрок может стравливать. `ForageSpawner` (кормёжка лося), `PackCoordinator:8000` (стаи).

**Босс (СТАТУС §3, GDD §4):** С 11.09 вервольф как отдельный вид удалён. Босс — химера человека + случайный вид (`ChimeraFactory:6000`), плюс модуль `Bossness:6000` (2 химерных слота сверх нормы, `HpMult`, экспрессия, награда). Рецепты `Оборотень` и `Случайная химера`. Награда `SuperBossReward` (+4 пула + химерный слот) снова достижима.

**Мета:** первый килл типа босса = перманент. Сеты на 2/4/6 (Diablo3-стайл) — план. Баланс моно↔микс: скидка+сеты vs кросс-синергии+мульти-сет.

## 4. Структуры данных

**Схема (`SpeciesSO:1` 17 полей, `BodySocket:181` 22, `Organ:88` 55, `Bone:1` 17, `OrganPart` 6):**

```
SpeciesSO                 ★ единственный источник вида
  speciesName, tint, mutagenPool, baseHp/Stamina/Regen
  sockets: BodySocket[]   // план тела
  bones: Bone[]           // силуэтный граф (пусто = места)
  skeletonHides, skinCell/Grain, skinBlend, skinFur, organs: Organ[]

BodySocket                // место на теле
  name (=Organ.slot)      // ← инвариант: механика и адрес визуала не расходятся
  parent, attach, attachOffset, sizeRel, baseSize, baseEuler
  mirrorX, inner, graft, chain/chainForward/link*, formFrom+formRole, solid
  parts: OrganPart[]      // shared (шкура) + visualParts + visualSegments

OrganPart                 // кусок формы
  scale/offset (в КАЛИБРАХ сокета!), euler, shape, node, block, role, color
  // node: X/Y в диаметрах конца узла, Z в длинах узла (поставка 5)

Bone                      // узел силуэтного графа = капсула SDF
  length, dir, r0/r1, section/depth, blend, layer, socket, freeOrigin...
```

**Инварианты в типах:**
*   `BodySocket.name = Organ.slot` — разойтись не могут (`УСТРОЙСТВО_ТЕЛА.md:29`)
*   `OrganPart.offset/scale` в долях `baseSize` → переносимость между шасси
*   Корень `хребет` при `parent==""` берёт `baseSize` минуя `sizeRel` → у корня пропорция не выражается (довод спеки `2026-09-11-edinyj-nabor-mest.md`)
*   `formFrom+formRole` (Eye/Ear/Nose/Pit) — признак чувства принадлежит органу, не месту

**`CreatureBody:14` (481 строк + 7 партиалов 43к) — центр всего:**
`Awake:88` навешивает всем отсутствующим `Personality/SpawnVariance/Morale/Noise/Satiety/ScentTrail/EmotionTint` — «тело даёт поведение, психика читает». `Recompute:342` — единственная точка сборки: группировка по `slot` → `Contribution.Sup` (супремум дублей) → сумма → раздача `Health/Stamina/Senses/PlayerAttack/IbodyStatConsumer` → `MorphBuilder.Build` → `Rebuild()` всех кэширующих `Renderer[]`. `CreditKiller:193` + `Feed` + `tally` + `TryChimerize`.

**`MorphBuilder:1` (811 строк):** `SizeOf` (рекурсивно к корню), `ChainDiameter`, `Place` (наследование поворота, `axisOf` приколот по чистому шасси), `Piece` (приоритет `formFrom→свой орган→место`, фильтр по роли), `BuildLinks`, `BoneMesher.Build` если `bones` непуст. Химерный слот — плавающий, дубли `Sup`. Кэш `MissingBlocks`, статика `ResetCatalog()` в `TearDown` (гоча `CLAUDE.md:69`).

**`BoneMesher:1` (440 строк):** каждая кость — капсула SDF, мягкий минимум, `Surface Nets`, один `SkinnedMeshRenderer` на слот. Внутри слота `blend` полный, между слотами `Weld=0.3`. `skinCell = Grain = 0.084` на проект (волк 2104 тр, лось 7704 тр — `СТАТУС.md:313`). Кэш по `speciesName#число_костей#слои#грани` — числа поля не в ключе (гоча `CLAUDE.md:68`, сторож `BoneMesherCacheTests`).

**`BodySlots:1` (105 строк)** — единый словарь, `IsSlot/IsPlace/IsKnown/TryKind:86`.

## 5. DSL / Конструктор существ

**Документ-канон:** `Docs/CONSTRUCTOR_GUIDE.md:1` — единственный носитель правил (`CLAUDE.md:41`), спеки — доводы и история.

**Три закона (`CONSTRUCTOR_GUIDE.md:6`):**
1.  Тело строится единообразно: `шасси + органы → статы + способности + восприятие`. Тело = данные.
2.  Психика — тонкий код `sense→think→act` поверх глаголов тела. Словарь режимов.
3.  Способность = доставка + эффекты. Числа — в `Organ.abilities: AbilityData[]`, доставки/грани своих не держат.

**Граф мест:** `parent/attach/attachOffset/sizeRel/baseSize/baseEuler/mirrorX/chain*`. `attach` — доля вдоль длинной оси родителя (авто-выбор по max `baseSize`, гоча `CLAUDE.md:65`: правка 0.128→0.132 развернула ветку). `chainForward` — флаг у ребёнка (от хребта в обе стороны для змеи).

**Идентичность (`CreatureBody.Identity:9000` + `Affinity:4000` + `Expression:6000` + `MorphBlend:11000`):** локально в теле (`GetAffinity/AddAffinity`, глобального счётчика нет). `MostKin` + `KinTier` (Weak 0.65 диспатч, Medium 0.85 метаморфоза). Четыре слоя с владельцами (спека 14.08): форма (донор) · пропорция (смесь) · калибр (носитель) · топология (носитель). Формула `base ×(1+Σ bonus×Э)`. Правило-детектор: в данных донора нет чисел в метрах (`ChimeraPlanTests`, `MorphLocalityTests`). `sizeRel` смешивается геометрическим средним, `baseEuler` slerp'ом (находка спеки `2026-09-11-telo-kak-rassloenie.md`: `Part` — произведение пространств разной структуры, смешивать сложением нельзя).

**Химерный слот — плавающий:** выбирает орган, не место; число наград = бюджет графтов. Дубли одного типа слота — `Sup` (max/min/OR), на месте виден родной. Суперхимерный (дубли частей тела) — отдельно, позже.

**Рецепты (`CONSTRUCTOR_GUIDE.md:45`):**
*   Добавить орган → числа в `SpeciesBootstrap.CreateDefaults` → запись `abilities` → `Chimera→Создать дефолтные виды`
*   Добавить вид → ассет `SpeciesSO` + доноры игрока + NPC-префаб + психика + сокет-план с корнем `хребет`
*   Добавить способность → наследник `AbilityData` (`[Expressed]/[MustBePositive]`) + `WindupAbility+IOrganAbility` (ИИ) / `MonoBehaviour+IAbility` (игрок)
*   Добавить сенсорику → 8-шаговый чек-лист, + пересев при `Metamorph` (ещё не закрыт — шаг 5 ревизии)

**Тюнинг-карта (`CONSTRUCTOR_GUIDE.md:147`):** числа органов → `SpeciesBootstrap→Data/*.asset`; живучесть → `baseHp+hpBonus`; сытость → `Satiety/eatsMeat/ForageSpawner`; морфология → `BodySocket`; проверка тел → `BodyRules` (щель 8% толщины, нахлёст 75% глубины).

**Детализация по осям:**

*   **Roguelike vs Hades/Dead Cells/Slay the Spire:** CHIMERA ближе к Hades («освоил оружие → открыл новое») + Spore. Вариативность в маршруте+родстве, не в рандом-перках — верно.
