## Задача одной фразой

Найти способы изготавливать форму существ CHIMERA так, чтобы у формы была **причина** (строение: опоры, массы,
крепления), а не копия силуэта и теней листа; и чтобы это работало для пути человек → вид по доле массы (ступени
ст.0–ст.3) и для химер из частей разных видов. На выходе ресёрча — топ-10 различимых решений (конвейеров) с
трейдоффами; выбирает геймдизайнер.

## Повод

Ст.2 оборотня r11: критик 8.5/10, совпадение с масками листа 0.835 / 0.816, но геймдизайнер: «сделал примерно по форме,
не понимая сути — имитирует подкожные мышцы, но не понимает, что делает». Его гипотеза: скелет → мышцы-объёмы на костях →
кожа обтяжкой. Её проверять наравне с альтернативами, не считать ответом заранее.

## Что есть сейчас (кратко)

- Вид — цельный меш по утверждённому листу (анфас/профиль/3/4), заготовка Hunyuan3D-2mv по ракурсам, доводка скриптами в
  Blender, риг на именованный скелет, FBX в Unity 6 (URP, SkinnedMeshRenderer, ≤4 веса на вершину).
- Ступени идентичности (доля массы вида 0.65 / 0.85 / 1.0) — формы-ключи (blend shapes) на меше шасси + поза ступени;
  ст.3 — смена шасси. Химера — меш шасси + куски органов других видов, посаженные по швам-кольцам.
- Подгонка: поза и оболочка подбираются функционалом по маскам листа (IoU по ракурсам), рельеф берётся из 3D-цели;
  пробовали NICP, перенос в позе с обратным скиннингом.
- Приёмка: маски/IoU, кадры, независимый ИИ-критик (порог показа 8.5), витрина утверждённых листов.
- Стиль: гранёный low-poly, крупные плоскости, силуэт читается чёрным контуром в тумане на 20 м (`SPEC-model-contract.md` §7.4), 2–2.5 тыс. треугольников на тело.

## Прошлые подходы (что уже не сработало — не предлагать заново без отличия)

Примитивы на сокетах; лепка «кости → мышцы → покровы» вручную без референса (отменена 10.09: разрывы, несплавленные
массы, огромный бюджет); клетка тела (таблицы сечений, смешение вершин); библиотека форм на всё тело (стопка блоков);
тело полем по силуэтному графу + ригблоки (капсульные массы, ноги-столбы, рябь; тупик 13.10). Действуют: меши по листам,
куски, ключи ступеней, подгонка по маскам.

## Жёсткие ограничения

- Только бесплатное/открытое (лицензия кода, весов, данных; без non-commercial в продукте; без платных аддонов/сервисов).
- Unity 6 + Blender (headless), исполняется ИИ-агентами скриптами; геймдизайнер — только художественный выбор.
- Игра, а не натурализм: силуэт в тумане, крупные грани; физика мышц в рантайме не нужна (анатомия — способ авторинга).
- Пять видов сейчас (человек, волк, лось, ёж, змея), рост до 10–15.
