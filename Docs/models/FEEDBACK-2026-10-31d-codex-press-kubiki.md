# Первый меш пресса по принятой разметке r2

Геймдизайнер подтвердил расположение кубиков и разрешил работу. Разметка — `Референсы/работа/дизайн/torso-review-2026-10-31/comparison-r2.png`, меш и три ракурса до/после — `Референсы/работа/дизайн/abdomen-lowpoly-2026-10-31/`.

Проба сохранения числа вершин не дала широких плоскостей. В показанном кандидате локально заменён передний участок живота: бюджет тела 5738→5894 (+156 треугольников). Только экспериментальная ветка, не игровая поставка. Остальное тело сохранено; новые ключевые вершины интерполированы, поэтому позовая коррекция требует пересверки. В покое после FBX развороты/складки/сжатия 0, швы 0 мм, веса до четырёх. Подробности и ограничения — README рядом с кадрами.

Место кубиков было утверждено; эта конкретная геометрическая форма ещё нет. В витрину и Assets не переносить до оценки.
