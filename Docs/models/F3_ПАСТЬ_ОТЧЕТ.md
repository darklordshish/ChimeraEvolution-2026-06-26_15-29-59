## 4. Рендеры открытая/закрытая

Команда:
```bash
cd Tools/Blender
python cagerun.py wolf
blender -b -P make.py -- --species wolf --layer 3 --views head --slots
# закрытая — дефолт; открытая — с поворотом челюсти
blender -b -P make.py -- --species wolf --layer 3 --views head --jaw 28 --out out/wolf_head_open.png
blender -b -P make.py -- --species wolf --layer 3 --views head --jaw 0  --out out/wolf_head_closed.png
```

Артефакты (генерируются, в git не едут — см. `Tools/Blender/out/`):
- `out/wolf_head_closed.png` — профиль головы, пасть сомкнута, клыки сомкнуты (нижний перед верхним), губа 0.34 мм, щель режется слоем Cut `рот.р`
- `out/wolf_head_open.png` — та же камера, челюсть `челюсть` повернута 28° (угол из `JawController.openAngle`), пасть открыта, клыки разведены, язык/нёбо видно (вырезано `рот.р`), зубы как FEATURE-детали сохраняют форму
- `out/wolf_L3_head.png` — полный слой 3 голова (для сверки с `wolf_cage_head.png`)
- `out/wolf_cage_head_slots.png` — окраска по слотам (Пасть отдельно от головы)

Критерий приёмки: на обоих рендерах Пасть — **замкнутая своя оболочка**, не сшита с черепом (излом виден как фасеточная грань — стиль), при открытии **вся челюстная ветка** (ветвь+челюсть+клык_н) уезжает целиком, верхние клыки остаются на черепе.
