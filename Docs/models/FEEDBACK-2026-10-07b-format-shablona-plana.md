# Codex: формат шаблона плана готов (на потом, после кисти)

- **Дата:** 2026-10-07 · **От:** ГеймБосс · **Кому:** модельная линия (Codex)
- **Основание:** спека `2026-10-07-globalnyj-sloj-shablon-plana.md`, шаг 0 (механики)

Сейчас — кисть. Это на потом, читать не срочно. Схема для шагов 1–2 спеки готова, чтобы ты положил данные сразу
в проверяемый формат.

- **Узел-группа** в графе вида: обычный узел `rel` + поле `"group": "<имя группы>"`. Один узел на группу (зеркало — как
  у прочих узлов).
- **Шаблон плана** — `Docs/models/handoff/plan-<план>.json`:
  `{ "plan": "двуногий", "groups": [ { "name": "дельта.перед", "limb": "перед", "endMark": "локоть" } ] }`.
  `endMark` — метка конца кости, на которой сидит группа (`локоть` — плечо); пусто — любая кость цепи (хребет).
- **Таблица планов** — `plan-dvunogij__chetveronogij.json`:
  `{ "a": "двуногий", "b": "четвероногий", "pairs": [ { "a": "дельта.перед", "b": "плечевая.перед" }, { "a": "ягодица", "b": "" } ] }`.
  Пустая сторона — группа без пары; каждая группа шаблона упомянута ровно раз.
- **Проверка** — `PlanTemplateTests`: полнота групп у каждого вида плана, доли (`rel`), цепь и сегмент, нет групп вне
  шаблона; таблица — только имена своих шаблонов, без пропусков. Пока файлов нет, тест пропускает, сторожит самотест.
- Код: `Assets/_Chimera/Scripts/Player/PlanTemplate.cs`, поле `Bone.group`.

Состав групп предлагаешь ты, утверждает геймдизайнер (спека §6). Прогоны тестов и матрицы на твоей ветке — по письму, у
меня: береги лимиты на форму.
