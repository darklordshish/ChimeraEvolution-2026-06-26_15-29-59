# Задача дизайн-линии: бесшовные плитки кожи видов

10.11.2026 · ставит ГеймБосс. Решение геймдизайнера — спека `Docs/superpowers/specs/2026-11-10-kozha-organa-proekciej.md`: кожа органа Шкура — бесшовная плитка вида, которая проецируется на любое тело (человек, волк, лось) и красится поверх цветом состава.

## Что нужно

По одной квадратной бесшовной плитке на вид, 1024×1024, повторяется без шва по обеим осям:
- **волк** — шерсть короткими крупными прядями, в языке крупных плоских граней, без фотореализма;
- **лось** — грубая шкура, длинные редкие пряди;
- **ёж** — кожа между иглами: мелкая жёсткая щетина;
- **змея** — ромбическая чешуя с килем вдоль ромба, ромбы внахлёст.

Каждая плитка в двух видах: **цвет** (оттенки серого, светлая середина, без цвета вида — цвет даст игра) и **рельеф** как карта высоты (белое — выше). Узор крупный: на теле 1.85 м плитка ложится примерно 3–4 раза по высоте спины; мелочь мельче ладони не нужна.

Проверка бесшовности: плитка 3×3 рядом — шва не видно.
