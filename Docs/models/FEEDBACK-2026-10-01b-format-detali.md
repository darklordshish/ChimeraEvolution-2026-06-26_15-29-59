## 1. Решение геймдизайнера 01.10

Спека [`2026-10-01-konstruktor-detaley.md`](../superpowers/specs/2026-10-01-konstruktor-detaley.md):
- **тело — сборка из каталога деталей**: части шасси каждого вида и каждый аугмент, заранее изготовленные, в условных
  единицах; любая особь — сборка по составу плюс закрытый набор локальных операций (калибр, посадка кольца, поза,
  адаптация плана, идентичность);
- **аугмент — буквально часть донора** со своей формой-ключом адаптации к плану носителя («нога оборотня» = волчья нога
  + «под двуногого»);
- **шов — тип:** кольцо стандартной валентности на каждом типе разреза; склейка — по индексу вершин, без подгонки;
- **как делать детали — решает эксперимент** (твои А и Б в нём есть: B — QEM, D — кольца).

Калибр-эвристики (`ChainSwap`) и парные тела на капсулах — в отмену, когда появятся детали.

## 2. Формат детали (наш; числа твои)

- **Ключ детали:** `вид · слот · план тела` (`четвероногий`, `двуногий`, `змея`).
- **Геометрия** в условных единицах детали, начало — в кадре корневого шва.
- **Швы** у каждой детали: тип (`основание шеи`, `основание черепа`, `плечо`, `бедро`, `корень хвоста`, `пояс груди`,
  конец конечности), кадр (начало, ось наружу, «верх» кольца), эллипс сечения, кольцо из `n` вершин.
- **Предложение валентности:** `n = 8` у конечностей и хвоста, `n = 12` у шеи и пояса груди. Это как раз твои 6–8
  вершин кольца с запасом под шею и грудь — возрази, если для формы нужно иначе.
- **Кости детали** — узлы графа её цепи (разметка `limb`/`mark` сохраняется).
- **Формы-ключи:** адаптация плана (для аугментов, которые встают на другой план); идентичность «→ вид» (для деталей шасси).
- **Носитель:** для колец (D/В7) — JSON профилей колец вдоль цепи; для меша — FBX с shape keys. Решит эксперимент; формат
  швов один на оба.
