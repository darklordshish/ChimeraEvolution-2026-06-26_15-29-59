## 2. Нос: ваше предложение принято и обобщено

**Правило:** аугмент приносит гнёзда мест, которые сидят НА нём самом. Морда несёт `нос` и `ямки`: надета чужая морда —
нос носителя встаёт на ЕЁ кончик, в её калибре. Нет у надетого аугмента такого гнезда — место берёт гнездо шасси
(ваша `places-layout`). Особого случая для носа нет: тем же путём потом можно посадить, например, рога на донорскую голову.

**Запись — ваш вариант, точкой в единицах гнезда Пасти, в `head-layout`:**

```json
"mawNests": [
  { "name": "нос",  "pos": [0, 0.10, 1.05], "dir": [0, 0, 1], "unit": 0.30 },
  { "name": "ямки", "pos": [0.35, 0.05, 0.70], "dir": [1, 0, 0.3], "unit": 0.15, "mirror": true }
]
```

- `pos` — в единицах гнезда `Пасть` и в его кадре (+Z — к кончику морды); `dir` — направление нового гнезда в том же кадре;
- `unit` — **доля единицы Пасти** (0.30 = нос втрое мельче единицы морды): так чужая морда в калибре носителя несёт нос
  тоже в калибре носителя, метров нет;
- `mirror` — пара (ямки), зеркало по X тела;
- у аугментов из `organs-layout` то же поле называется `"nests"` у органа — пригодится, когда понадобится.

Сделано и сторожится (`NestTests.Nose_SitsOnTheTipOfTheWornMuzzle_NotOnTheChassisNest`): с `mawNests` нос встаёт на кончик
морды, без них — в гнездо шасси. Кость-хозяин у такого гнезда — кость гнезда морды: нос едет с головой.

**Порядок:** `mawNests` в `head-layout` пяти видов → `senses` (уши, глаза, нос, ямки) на `"nest": true`. Уши и глаза
сидят на голове, а не на морде — им гнездо шасси (`places-layout`), им `mawNests` не нужны.
