# Пробник сочетаний на поджаром теле

По предложению геймдизайнера собрал пять сочетаний + базу: готовые волчьи Руки/Чутьё/Шкура, ежиные иглы/Игломёт по существующей раскладке, рога лося по готовым швам и месту. Два одинаковых ракурса и крупные детали — `Референсы/работа/дизайн/augment-combinations-2026-10-31/`.

Тело r2 неизменно, 5894 треугольника; отдельная проверка сохранения всех ключей, весов и костей прошла. Это **статический тест наружных частей при полном росте**, без областных/видовых ключей и расчёта игровых билдов. Не выдавать за кадры игры.

В этом режиме волчьи уши/гребень расходятся с новой базой, Руки выглядят лопастями; рога и иглы дают ясное изменение контура. Следующий полезный контроль — органы вместе с областными ключами и их настоящим диапазоном роста, затем посадка и анимация. По одним этим кадрам менять голову/кисть носителя или объявлять сломанным игровой билдер нельзя. Ограничения и источники — README рядом.

Исходники — `Experiments/augment-combinations-2026-10-31/`. В Assets/витрину не переносилось.
