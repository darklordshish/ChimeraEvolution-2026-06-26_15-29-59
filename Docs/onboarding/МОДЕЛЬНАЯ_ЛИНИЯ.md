# Онбординг модельной линии CHIMERA

Для того, кто принимает модельную линию (форма существ). Написан координатором 06.10.2026; дополняется письмом передачи
от прежней модельной линии — `Docs/models/PEREDACHA-modelnoj-linii.md` (там — то, что знает только она). Это навигация,
а не правила: правила живут в `CLAUDE.md` и документах, на которые здесь ссылки. Разошлось — прав источник.

## 1. Твоя роль одной фразой

**Сколько и какой формы.** Анатомия, силуэт, пропорции, референсы, меши деталей, блоки, граф формы вида. Не твоё:
в каком графе, в каких единицах и по каким правилам это записано, код игры, детекторы, `Data/*.asset` — это механики
(координатор). Граница — по предмету решения, не по файлам: `Docs/ЗОНЫ.md`. Решения на развилках — геймдизайнер.

Твои файлы: `Anatomy/species/`, `Anatomy/README.md`, `Tools/Blender/`, `Assets/_Chimera/Models/`, `Docs/models/`
(свои спеки, ТЗ, поставки; ответы механик туда же — файлами `FEEDBACK-*.md`). Чужое — только читать; замечание — письмом.

## 2. С кем работаешь

**Геймдизайнер** — математик-физик, хаскеллист: думает АТД, композицией, теорией категорий; C# не знает. Объясняй через
типы и операции, давай варианты с трейдоффами, не решай за него и не поддакивай. Мыслит системами, не любит латки
(«систематизировать, а не латать»). Сам просит осаживать его к игре, когда уходит в матмодели. Арт и нарратив — не его
сильная сторона: поэтому от тебя он ждёт и вкус, и аргументы. Пишет коротко, с опечатками — переспрашивай смысл, а не
буквы. Критерий формы у него игровой: **силуэт читается в тумане, химера узнаётся по контуру** (GDD §9), а не
«похоже на образец в сантиметрах».

**Координатор (ГеймБосс)** — линия механик в `ChimeraEvolution/` на `main`: принимает поставки, держит гейт, пишет
код сборки (`ChainSwap`, `PartAssembly`, `BoneMesher`, `SpeciesHandoff`). Всё, что меняет схему данных, — его.

**Лесная линия (Лесник)** — мир павильона; с тобой пересекается редко (флора, камни).

## 4. Конвейер формы — откуда что берётся

```
референс (лист / фото)                    Anatomy/species/<вид>/ref/   (картинки на диске, часть не в git)
   │  снять числа: grid.py, контуры
   ▼
граф формы вида                           Anatomy/species/<вид>/graph.py
   │  генерирует                          → Docs/models/handoff/<вид>-graph.json   (узлы, метки цепей, слой Rig)
   ▼                                      → <вид>-head-layout.json, <вид>-organs-layout.json, <вид>-places-layout.json
блоки (ригблоки)                          Tools/Blender/blocks.py → каталог Resources/Формы.asset (ShapeCatalog)
детали (меш части)                        Tools/Blender/detali/noga_iz_obrazca.py
   │                                      → Assets/_Chimera/Models/Parts/<вид>-<слот>-<план>.fbx
   │                                      → Docs/models/handoff/parts/<…>.json   (паспорт: слот, план, шов, объекты)
   ▼
игра: unity command chimera-species       SpeciesHandoff читает handoff → SpeciesSO; BoneMesher строит поле;
                                          MorphBuilder ставит блоки; ChainSwap/PartAssembly — химеры и детали
```

## 6. Мины, на которых линия уже подрывалась

- **Эталон снимается с референса, а не собирается из промеров.** Оценку референсу ставить, только открыв картинку:
  паспорт по имени файла врал трижды.
- **Мерить на оболочке из `main`** и одним кадром; осевые точки — со сдвигом 2–3 мм (по оси тела идёт ребро сетки).
  Замер — лучом по граням или срезом треугольников плоскостью, не окном по вершинам.
- **Круглый торец узла выходит за конец на радиус** (грудь глотала подбородок, таз свисал между бёдрами).
- **Клетка 0.042 срезает шар r ≈ 3–4 см на 1–2 см** — мелкое (подбородок, задний пучок дельты) делать блоком.
- **Ключ формы не должен делать позу.** Поворот и длина — костями; ключ — масса и форма.
- **Метка сустава ≠ граница поля.** Сустав ниже поля — узел `Rig` (layer 4).
- **Узел, висящий выше шва, не должен свисать за шов** (дельта человека на лопатке давала двойную дельту — сторож
  `SeamOverhangTests`).
- **Сравнения — на одних костях, одном калибре, одной огранке, одном свете; критерий решения — до прогона.**
- **Стиль — крупные грани.** Гладкий плотный меш рядом с полем читается «мятой фольгой» — главная претензия
  геймдизайнера к пилоту. Детали делать в той же огранке.
- **Блоки и детали не смешивают единицы:** в данных донора не бывает чисел в метрах (калибр — за носителем).
- Производные `Data/*.asset` после `chimera-species` у себя **не коммитить** (шум `rid`) — их коммитит координатор.

## 7. Как работать

- Своя папка, своя ветка, свой headless Unity (`.claude/skills/chimera-unity`); чужие редакторы не трогать.
- Публикация: `git fetch origin && git rebase origin/main && git push origin HEAD:main` — через гейт; `--no-verify` нельзя.
- Поставка: генераторы → handoff/FBX → `chimera-species` у себя → кадры + детекторы → коммит → письмо
  `Docs/models/POSTAVKA-<дата>-<тема>.md` (что сделано, числа, кадры, что открыто). Координатор отвечает `FEEDBACK-…`.
- Ресёрч — сначала готовая практика и инструменты, потом свои скрипты. Генерация референсов картинками — твоя сильная
  сторона: лист для вида делай согласованным по ракурсам (сгенерированные ракурсы противоречат друг другу — проверяй).
