# План: генеративные карты CHIMERA

**Дата:** 2026-10-29. **Основание:** [`RESEARCH-2026-10-29-generativnye-karty.md`](RESEARCH-2026-10-29-generativnye-karty.md).
**Статус:** В РАБОТЕ. **Ветка:** `les/runtime-builder`.

Правило: каждый шаг — вертикальный срез. Сначала данные/детектор, потом поведение.
A/C/B0 не меняются без `worldVersion` и отдельного профиля.

## Статусы

- `[ ]` не начато
- `[~]` в работе
- `[x]` сделано и проверено
- `[!]` заблокировано (причина рядом)

## P0 — видимость решений

- [x] `SamplingContract`: шаг меша, `e` уклона, клетка маршрута, NavMesh-воксель в одном месте.
- [x] `GenTrace`: слой, кандидатов, принято, причины отказов, маржи.
- [x] `WorldFingerprint`: хэш пола, POI, чанков/деревьев/логов, плана.
- [x] Тесты: trace есть у fallback; fingerprint стабилен на `(seed, version)`.
- [x] `СТАТУС`/`УКАЗАТЕЛЬ`: ссылка на план и статус P0.

## P1 — честный пол

- [x] Индекс русла вместо линейного поиска.
- [x] `ForestRouteGraph` с зазором (distance transform) и компонентами.
- [x] NavMesh берёт `navVoxelSize`/`navTileSize` из `DomeGenConfigSO`.
- [~] `NavParityTests`: route graph ↔ NavMesh, расхождение — записанный долг (route graph и NavMesh проверены отдельно; прямой `Entry → LabDoor` в NavMesh остаётся `PathPartial`).

## P2 — станция

- [x] `Site.Margins` вместо bool.
- [x] Решётка 40→20→10 м, лучший кандидат.
- [x] `platformY` от финального поля, стык плиты и поля — маржа.
- [x] 20–30 сидов: strict ≥ 90 %, fallback = 0 (`SiteMarginsTests`, 20 сидов).

## P3 — план

- [x] Валидатор: дверь на общей стене, глубина от лобби, `MD(hall)`.
- [!] BSP/beam за `labPlanVersion=2` — нужен выбор планировки: фиксированные комнаты 46×36 или новая нарезка (меняет `DomeLabComplex` и A/C).
- [ ] Геометрия и мебель — из плана, не из констант (после выбора планировки).

## P4 — флора

- [~] Цель — кроновый покров/плотность, не 700. Сейчас: `treeCount=1500` для `ForestPavilion`; 700 остаётся дефолтом A/C; кроновый покров **2.1 %** (детектор `CrownCover`).
- [x] Пятна леса/поляны низкочастотным fBm; A/C не трогают (`patchyFlora=false`). Poisson/blue-noise — следующий шаг.
- [x] B-lite: 4–6 полян-арен R30, коридоры 16 м, 20–30 укрытий с геометрией (`ForestSpace` + `DomeFlora`), деревья вне полян/коридоров, 300–500 коллайдеров стволов; A/C без разметки.

## P5 — эрозия

- [ ] Офлайн-прототип (Anaconda), метрика до/после.
- [ ] В рантайм — только thermal erosion, если метрика оправдает.

## P6 — дороги

- [ ] POI → MST → 1–2 петли.
- [ ] После B1, когда POI стабильны.

## Что не делать

- Не переписывать `SampleGround` и `DomeWorld.Build`.
- Не тащить WFC на весь купол.
- Не запускать гидроэрозию в рантайме до замера.
- Не вводить числа без происхождения.
