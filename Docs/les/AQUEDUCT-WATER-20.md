# AQUEDUCT-WATER-20: каталог воды на 20 сидах

**Источник:** v2, Ø2000, `terrainQuads 48`, `ForestProfiles.PavilionV2` (seed 1–20, `erosion:false`, thermal erosion on). Это фактический водный генератор мира, без геометрии акведука.

**Что это:** Task 0 — каталог воды. Акведук не строится, кромка/опоры не меняются. `AW-R` river, `AW-L` lake, `AW-RS` reservoir, `AW-F` waterfall-spillway.

`waterTypes` — все найденные водоёмы; `primaryType` — приоритет для будущей посадки: AW-F → AW-RS → AW-L → AW-R → absent. `hasReservoir` в текущем v2 — false: искусственного водохранилища в данных нет; озеро не считается водохранилищем. `absent` в выборке 0: у всех 20 сидов есть lake+river; это не значит, что `absent` невозможен в другой конфигурации.

`riverLevel` — `riverBedMid + 0.25` (поверхность воды по тому же правилу, что `DomeWaterMesh`); `lakeLevel` — уровень озера из `DomeHydro`.

## Что осталось

- `AW-RS` пока отсутствует на всех сидах: нужна отдельная модель искусственного водохранилища или явный `absent` по умолчанию.

- 20 сидов — только вода; посадка/опоры/лоток — Task 2–5.
- Озеро/река в каталоге не меняются: это baseline `Hydro`; проверка — `AqueductWaterCatalogTests`.
