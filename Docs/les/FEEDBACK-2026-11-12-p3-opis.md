`ForestPavilion` (тот самый лес, но пустой, с каньоном и замороженным)?

Если `ForestFragment` — по плану выключить флагом овраги (`buildRavines: 0`); если `ForestPavilion` — выключить
каньон, террасу и станции или вернуть каньон из архива. Профили сцен заморожены тестом
`ForestSceneBaselineTests`, так что смена флага правится тем же заходом, что и сторож.

## 3. Что нужно любой из двух сцен, чтобы в ней шёл вечный цикл

Сравнил компоненты сцены с `SampleScene` из `main`. Игрок совпадает, включая `PlayerDeath`. Не хватает:

| компонент арены | нужен лесу? | почему |
|---|---|---|
| `WorldClock` | **да** | один носитель игрового времени; без него сон и кулдаун босса идут по `Time` (спека 12.11, §5 п.1.3) |
| `BossChimeraSpawner` | **да** | босс выходит из лаборатории — точка спавна у входа в бункер (план §3 п.4) |
| `PackCoordinator` | **да, если волки** | стая волков |
| `ForageSpawner` | **да, если лоси** | кусты — корм лося (голод M2) |
| `IndividualityConfig` | да | разброс особей |
| `DebugHud` | да | итог смерти, счётчик химер, дев-панель |
| `NoiseWaves` | да | волны звука видны |
| `ArenaWalls`, спавнеры волков, змей, лосей, ежей, `TestChimeraSpawner` | **нет** | в лесу население ведут логова |
| `Volume`, данные света URP | по вкусу | постобработка арены; у леса свой свет и туман |

И **пул видов**: `ForestFragment` — пусто, `ForestPavilion` — одна змея. Для плейтеста — волк, змея, лось, ёж;
сова — логово выключено, тела нет.

Это правки сцены: мои (лесная зона), делаю в ветке по твоему слову и выбору сцены. Цикл проверит
`EndlessLoopSmokeTests` на лесной сцене (К-1…К-4) — сторож твой, сцену дам.
