# Кадры тел — эталон для сверки глазом

**Что это.** Снимки существ, собранных **настоящим `MorphBuilder`** в редакторе и снятых ортографической
камерой строго по оси. Не иллюстрации: это такой же детектор, как [`КАРТА_ТЕЛ.md`](../КАРТА_ТЕЛ.md), только
про то, что числами не ловится — силуэт, двойная геометрия, оторванные детали, «читается ли зверь зверем».

**Чем сняты.** `Tools/Agent/ShotSpecies.cs` + пайплайн живого редактора; рецепт — скилл
[`chimera-unity`](../../../.claude/skills/chimera-unity/SKILL.md), раздел «Кадры». Камера
**ортографическая** (пропорции без перспективного вранья), фон ровный, свой направленный свет — кадры
разных дней сравнимы между собой.

**Как пользоваться.** Правишь данные вида или билдер — пересними и сравни с тем, что лежит здесь.
Разошлось ожидаемо — положи новый кадр вместо старого; разошлось неожиданно — это дефект.

**Что эти кадры уже показали** (17.09, первый же прогон):

1. **Волчий силуэт — «лама».** Высокая холка, длинные прямые ноги без собачьего угла зада, длинная шея,
   узкая морда: читается как лошадь. Модельная линия назвала это «ламой» ещё 09.09 — подтверждено глазом.
   Плюс на спине торчат отдельные мышечные объёмы, а перед мордой висят в воздухе мелкие обломки.
2. **Двойная геометрия — не теория, а картинка.** У четверых из пяти кости и места рисуются ОБА: у лося
   84 примитива поверх костного поля, у ежа 64, у змеи 60, у человека 53. У волка 10 — его места скрыты.
   На кадре человека это видно буквально: серая плита-примитив поперёк голени.
3. **Смешение глазом не принять НИ НА КОМ.** Кадр химеры «человек + волчьи Пасть и Чутьё» почти
   неотличим от чистого человека: габарит тот же (калибр носителя — по закону), а волчьи детали тонут в
   костном поле, которое пропорции не смешивает вовсе. То есть совет модельной линии «проверяйте
   смешение на человеке, волк не покажет ничего» (письмо 10.09) верен лишь наполовину: **у человека оно
   тоже не покажется, пока кости рисуют его тело поверх мест.**
