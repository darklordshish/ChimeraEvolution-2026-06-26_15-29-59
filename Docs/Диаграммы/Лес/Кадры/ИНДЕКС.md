## Серии 10–17 — вне git (13.11)

Павильон (10), пилот станции (11), старый купол 24.09 (12), арена B-lite (13), эрозия S4 (14), G7 (15, 16) и
акведук (17) — 37 МБ. По правилу хранилища в git остаются только кадры срезов, на которых стоит первая зона.
Эти серии лежат:

- целиком — в теге `archive/les-zamorozka-2026-11-12` (путь тот же: `Docs/Диаграммы/Лес/Кадры/<серия>/`);
- рабочей копией — вне репозитория, в `Chimera_game/_refs-local/les/kadry/`.

Вернуть серию в рабочую папку: `git checkout archive/les-zamorozka-2026-11-12 -- "Docs/Диаграммы/Лес/Кадры/<серия>"`.
