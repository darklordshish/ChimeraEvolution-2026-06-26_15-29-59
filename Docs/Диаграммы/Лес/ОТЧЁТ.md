## 1. Геймплей / экосистема (`psyche-ecologist`)

**Сделано — логова как учёт, хук, возврат:**
- s2: `Scripts/Forest/Habitats/LairSite.cs` — `tier 1..3`, кап, `respawnSeconds`, радиусы дом/спавн/страх (12/6/18), страх `0.34/0.02/0.7` с формулой `·2/tier`; рантайм `[NonSerialized]`; `Tick(dt)` — спад → очередь → события `Exhausted/Recovered`.
- `LairRules.cs` (чистая математика) + `LairRegistry.cs` (`TotalCapacity/NearestHome`, без статики).
- s2b: `ForestSpawner.cs` — `Configure/Tick/DrainOnce`: очередь → `ChimeraFactory.Spawn` (шасси=вид, доноры=весь пул — выводок обычный NPC), позиция детерминирована (`SeededHash`, без `Random`); смерть → `ReportDeath` + `ReportKill` логовам того же вида в их `fearRadius` («запах смерти», не память о хищнике).
- s6: крыша `reservedHolders/TryReserve/Release` (отдельный счётчик — иначе врёт учёт выводка), `IsFull` считает всё; `body.home` ставит спавнер; пилот `WolfPsyche` (`returnHomeEnabled=false`, `Homing/homeTarget`, ветка первой в сытой до `Wander`, гейты; дома — резерв+отдых; уход/бой/паника/смерть — `Release`).

**Замкнулось:** очередь→тела, смерть→страх географией, сыт→дом→отдых (волк), выводок качает существующую эволюцию/`Metamorph`, а не касту.
**Не замкнулось:** `PackCoordinator` дом не держит, `NearestHome` пилотом не используется (идёт к своему `home`), домой ведёт только волк, `Morale` со страхом места не связан.

## 5. Сквозные риски (консолидировано)

1. **Популяция опередит сторожей** (архитектор): рельеф/очередь детерминированы, а живая сцена (перенаселение без деспавна, кадр) — нет; первым ляжет не рельеф, а кадр.
2. **Учёт мимо хука** (эколог): зверь, рождённый/убитый мимо `ForestSpawner`, молча рвёт кап и крышу; сайтов в сцене нет — лес это пока не ловит.
3. **Красота vs детектор** (художник): тот же туман, что даёт воздух в 3/4, убивает топдаун; второй канал ночью не проверен — риск красить вслепую.
4. **Кэш `BoneMesher`** (архитектор): при смешении силуэтных графов ключ по имени вида отдаст чужую оболочку молча.

## 8. s10: павильон-купол Ø2000 (19–22.09, ветка `forest/s10-dome-pavilion`)

**Что:** тёплый биом под куполом одной командой (`DomeShowcase.Build("1337","2000")`, сид сквозной):
чанки 8×8×250м (швы 1:1, тест) + FBM/Ridged/Warp + Burst-джоба + скальное кольцо (Rin 920/Rout 1140,
пик 100) + озеро (r≤150, spill+epsilon) + река 590м (монотонна, тест) + флора 3880 GO
(ели/папоротники/пояса) + 3 устья-пещеры + 6 гнёзд + ясень 45м с совой (Nest) + лаборатория
(4 бокса) + ангар-Gateway + свод (квантованный шейдер) + мох-звёзды + orbital-свет + дождь.
Тесты: EditMode 237→238 (s10), PlayMode 111. Кадры (`Кадры/Купол-*`, 14 шт.): топдаун, река,
устье, лаб, ангар, ясень, день/закат/ночь, дождь, лес.

**Принято с отклонениями:** Ø2000 вместо ×10 (купол R1000 накрывает 1200→2000 по формуле
`n=ceil(D/250)`); NavMesh моно-бейк запрещён (только тайлами, пруф на Ø500);
рантайм-стриминг/CDLOD/volumetric/снег/VFX — не брать (таблица s10).
Кость `#DED4B8` отменена (читалась снегом) → сухая охра `#A8905E` + тест.

**Поймано (уроки в код и тесты):**
- ~~`Mathf.SmoothStep` в этом окружении врёт~~ — *поправка механик 23.09:* не врёт. `Mathf.SmoothStep(from, to, t)` —
  интерполяция от `from` к `to`, и S(0,0.5,0.5)=0.25 верно; шейдерный `smoothstep(edge0, edge1, x)` — другая функция.
  Ручной Hermite оставлен: нужна ступень по `x`, а не интерполяция.
- URP рисует скайбокс ПОСЛЕ опаков → своду нужен `ZWrite On`, иначе его нет.
- Небо красить направлением ВЗГЛЯДА (`_WorldSpaceCameraPos`), не радиусом купола
  (пояс заката селился на зарытой кромке и не был виден).
- Звёзды — в центр свода, не в начало координат (были снаружи, прятались за свод).
- Сцена копит дубли превью (Find отдаёт первый!) → снос ВСЕХ корней по префиксу.
- Протухшая окклюзия сцены режет мелкую процедурную мелочь → `useOcclusionCulling=false`
  в `SetupCameras` навсегда (генеративный мир окклюзию не печёт).
- Статики умирают при reload, объекты сцены живут → `Reattach()` + сид в имени корня.
- ~~Ручные `.vertices/.triangles` меши не рисуются в этом пайплайне~~ — *поправка механик 23.09:* рисуются
  (`Tools/Agent/Stand.Unweld` строит меши ровно так). У пропавшего меша была другая причина; кит-стиль
  (`SetVertices/SetTriangles`) — просто принятый стиль, а не обход.
- Плоскость capture: кадры снимать СРАЗУ за фреймером (камера не дрейфует, но память врёт).
