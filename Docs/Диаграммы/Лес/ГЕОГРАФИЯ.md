# География леса — снимок

**Дата:** 2026-10-29. **Сцена:** `ForestPavilion`, сид 1337.
Это снимок фактов, а не описание замысла. Числа пересчитываются тестами
`ForestBaselineTests` и `ForestPavilionTests`; при смене среза файл переснимается.

## Купол и профили

| что | факт |
|---|---|
| диаметр | 2000 м |
| чанк | 250 м, `terrainQuads 48` |
| чанков в A/C | **52** (8×8 минус квадратные углы) |
| деревьев в A/C | **700** |

## Рельеф и маршруты

- терраса: R91.8, +12.6 м; каньон: длина ~300 м, полуширина ~7 м;
- озеро: R150; вода без физики;
- `Entry → LabDoor` в **NavMesh** сейчас `PathPartial` — это отдельный долг;
- маршрутный граф `ForestRouteGraph` по `SampleGround` на **20 сидах** связывает
  `Entry → LabDoor → LabAtrium`; это проверка пола/воды/кольца, не NavMesh;
- станция ищется по сырому полю, после географии `platformY` корректируется
  по `TerrainGround` (см. `DomeWorld.Build`).

## Чем проверяется

- `ForestBaselineTests` — A/C/B0: чанки, деревья, логова, спавнер, сова;
- `ForestPavilionTests` — холм, расщелина, путь до северной двери;
- `ForestBuilderRuntimeTests` / `ForestFragmentTests` — сборка, `Clear`, B0.

## Что не закрыто

- `DomePreview` всё ещё строит превью по сырому полю;
- `DomePass` не рантайм-детектор;
- вода без физики/плавания;
- спавнер и логова не фильтруют воду и обрывы.
