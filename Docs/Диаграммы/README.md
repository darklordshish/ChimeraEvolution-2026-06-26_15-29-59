# Схемы тел

Карта сокет-плана: кто к кому крепится, где цепи звеньев, где закрытые места.
**Файлы выгружаются командой `Chimera → Выгрузить схемы тел` — не править руками.**

> **По волку читать с поправкой (21.08.2026).** Места в плане остались и держат механику слотов, но
> форму десяти из них теперь строит СКЕЛЕТ (`SpeciesSO.skeletonHides`: хребет, Шкура, шея, Сердце,
> Руки, Ноги, голова, уши, нос, Хвост). То есть дерево верно как план креплений и калибров, но не
> как ответ на вопрос «что рисуется». См. `Docs/УСТРОЙСТВО_ТЕЛА.md` §6.
