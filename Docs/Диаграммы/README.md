# Схемы тел

Карта сокет-плана: кто к кому крепится, где цепи звеньев, где закрытые места.
**Файлы выгружаются командой `Chimera → Выгрузить схемы тел` — не править руками.**

Дерево отвечает на вопрос «кто к кому крепится и с каким калибром». На вопрос
«что рисуется» отвечает пометка **(форму даёт СКЕЛЕТ)**: такое место держит
механику слота и остаётся адресом для детей, но собственной формы не строит —
её даёт кость (`SpeciesSO.skeletonHides`). Сам скелет, если он у вида есть,
выведен отдельным разделом в файле вида.
