# Размеры тел в игре

> Генерируется `Tools/Agent/GameSizes.cs` (снято 20.10.2026): тело собрано настоящим `MorphBuilder` тем же путём, что в игре
> (меш вида + ключ + черты; поле — у видов без меша), габарит по вершинам. Высота — Y, ширина — X (вбок), длина — Z (вперёд-назад).
> «Человек + все органы вида» — каждый слот человека, который есть у вида, занят органом вида; «по составу» — ступень, которую даёт `GlobalLayer.Step`.
> **«Рост по массе» и «должно быть»** — множитель `GlobalLayer.Growth` (масса видов `SpeciesSO.mass`, геометрическое среднее) и рост шасси,
> умноженный на него: спеки `superpowers/specs/2026-10-20-rost-i-gabarity-vidov.md` и `2026-10-20-shkala-morfov.md` (шкала морфов, витрина `морфы-ст2/`). Это ЕДИНСТВЕННЫЙ источник чисел размера — тексты ссылаются сюда.

**Чтение.** «Должно быть» — цель: в сборку тела рост по массе ещё не включён, поэтому у морфов высота в игре расходится с ней.
Оборотень сейчас выше цели на ~0.2 м (голова и черты ключа поднимают верх). Человеку-лосю не хватает роста: 2.15 против 3.06, человек-Хеджхалк — человек 1.85 против 1.06.
У ежа и змеи на человеке ключа ещё нет, тело остаётся человеческим (1.85 м). Змея на человеке по составу выше ступени 0 не поднимается:
её органы «Тело-хвост» и «Погремушка» — только для родного шасси, долей хватает не на 65 %. Чистые виды растут собственным калибром
(множитель 1). Чистый Хеджхалк в отчёте ещё 1.27 м — цель ≈0.7 м по верху игл (спека `2026-10-20-razmer-hedzhhalka.md`), ждёт поставки модельной линии.
