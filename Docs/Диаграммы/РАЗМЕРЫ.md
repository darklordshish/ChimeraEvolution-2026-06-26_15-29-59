# Размеры тел в игре

> Генерируется `Tools/Agent/GameSizes.cs` (снято 20.10.2026): тело собрано настоящим `MorphBuilder` тем же путём, что в игре
> (меш вида + ключ + черты; поле — у видов без меша), габарит по вершинам. Высота — Y, ширина — X (вбок), длина — Z (вперёд-назад).
> «Человек + все органы вида» — каждый слот человека, который есть у вида, занят органом вида; «по составу» — ступень, которую даёт `GlobalLayer.Step`.

| тело | ступень | путь | высота м | ширина м | длина м |
|---|---|---|---|---|---|
| Человек | 0 (по составу: 0) | меш | 1.85 | 0.69 | 0.33 |
| Человек + все органы: Ёж | 2 (по составу: 2) | меш | 1.85 | 0.69 | 0.33 |
| Ёж | 3 (чистый вид) (по составу: 0) | поле | 1.27 | 0.93 | 1.56 |
| Человек + все органы: Волк | 2 (по составу: 2) | меш | 2.12 | 1.11 | 1.28 |
| Волк | 3 (чистый вид) (по составу: 0) | меш | 1.52 | 0.53 | 2.06 |
| Человек + все органы: Змея | 2 (по составу: 0) | меш | 1.85 | 0.69 | 0.33 |
| Змея | 3 (чистый вид) (по составу: 0) | поле | 0.30 | 0.33 | 5.54 |
| Человек + все органы: Лось | 2 (по составу: 2) | меш | 2.15 | 1.22 | 1.03 |
| Лось | 3 (чистый вид) (по составу: 0) | меш | 3.22 | 2.68 | 3.23 |

**Чтение.** Калибр — за шасси: у ежа и змеи на человеке ключа ещё нет, тело остаётся человеческим (1.85 м). Змея на человеке по составу
выше ступени 0 не поднимается: её органы «Тело-хвост» и «Погремушка» — только для родного шасси, долей хватает не на 65%.
