# Памятка для Codex — песочница CHIMERA

Написана координатором (ГеймБосс, линия механик) 06.10.2026 по просьбе геймдизайнера.

## Где ты

- Папка: `Chimera_game/ChimeraEvolution-codex/`. Ветка: `line/codex` (git worktree того же репозитория, что и у всех).
- Это **песочница**: работай свободно, коммить в свою ветку и пушь её (`git push origin line/codex`).
  **В `main` не пушь** — туда всё идёт через координатора и гейт `Tools/git-hooks/gate-main.sh` (`--no-verify` запрещён).
- Страж `.codex/hooks/svoya-papka.ps1` не пускает писать вне этой папки. Соседние папки и ветки — **только читать**:
  `git log main`, `git show main:<путь>`, `git diff main...line/modeli`, файлы в `../ChimeraEvolution-modeli/` и т.д.
  Свежий `main` к себе — `git fetch && git merge origin/main` (конфликты — твои, в своей ветке).
- Геймдизайнер думает передать тебе **модельную линию**. Пока решения нет — ты песочница: предлагаешь, пробуешь,
  меряешь. Когда передаст, это запишется в `Docs/ЗОНЫ.md`, и эта памятка обновится.

## Правила проекта

`CLAUDE.md` в этой папке действует для тебя целиком — где там написано «Claude», читай «ты». **Копию правил не делай**:
второй экземпляр правил расходится с первым молча (так в проекте уже было). Если правило кажется неверным — письмо
координатору, а не правка.

Главное из него, чтобы не наступить:
- Дизайн-решения принимает геймдизайнер; предлагай варианты с трейдоффами. Он хаскеллист и математик (АТД,
  композиция, теория категорий), C# не знает — объясняй через типы и операции. Пиши по-русски.
- Граница зон — **по предмету решения**: форма (сколько и какой формы) — модельная линия; структура (граф, схема данных,
  единицы, правила, код, детекторы) — механики. В чужую зону — письмом `Docs/models/FEEDBACK-*.md`.
- Спеки — «одна линия партии»: тело принятой спеки не правится; `python Docs/tools/spec_status.py` должен быть зелёным.
- Что проверяется машиной — проверяется машиной: тесты, детекторы, кадры. Плейтест — только «как играется».
- Python на этой машине — только Anaconda: `/c/ProgramData/anaconda3/python.exe` (голый `python` — заглушка).

## Как сдавать

Коммиты в `line/codex` — по-русски, тематически раздельные. Что предлагаешь в общий код или данные — письмом
координатору (`Docs/models/FEEDBACK-<дата>-codex-<тема>.md` в своей ветке) со ссылкой на коммиты: координатор
сверит с тестами и детекторами и перенесёт в `main`. Сравнения — на одних костях, одном калибре, одной огранке и
одинаковом свете; критерий решения пиши до прогона.
