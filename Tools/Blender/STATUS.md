## Где мы

Тело вида собирается **клеткой**: слот описан таблицей сечений (M станций вдоль оси × N секторов),
размерности одинаковы у всех видов. Волк проходит цепочку целиком и даёт **512 полигонов, 11 частей
по слотам**. Пасть — отдельная оболочка, она открывается.

```
референс → анатомические точки → кости + мышцы → воксельная отливка → обмер лучами → таблица → меш
 (Anatomy/)      species/wolf.py                  chimera/volume.py   cagerun.py  species/wolf_cage.py  chimera/cagemesh.py
```

Запуск:

```bash
python cagerun.py wolf
blender -b -P make.py -- --species wolf --cage --views profile,front,head
blender -b -P make.py -- --species wolf --cage --views head --slots     # окраска по слотам
```

`species/<вид>_cage.py` — **генерируемый файл, руками не править**: правится болван, клетка
снимается с него. Прогон 6 секунд.

### Главное: калибр не масштабировал вид

В каждом файле вида написано «все размеры задаются долями: так вид можно пересчитать целиком одним
числом». Проверки этого не было ни одной. Оказалось: **голова у всех пяти видов задана в метрах** —
смена `W` растягивала тело, а череп, челюсть, зубы, скуловая дуга и ухо стояли на месте.

Ловится только поимённо (собрать при `W` и при `2W`, сверить каждую кость); габаритом не видно.
Теперь ловится машиной: `kalibr.py`, все пять видов проходят. Правка тождественна — у волка, лося,
человека и змеи не сдвинулась ни одна кость (`seg5.py`).

## Сделано за 28.08

### Метод

| что | зачем понадобилось |
|---|---|
| **воксельная отливка** вместо луча по прутьям | скелет с мышцами — решётка с пустотами, «внутри» для луча значит «попал в прут». Диагональ вдоль ребра живёт долго, прямой бок обрывается сразу → сечение выходило ножом 0.012 × 0.364 |
| **послойная заливка** полостей по трём осям | грудная и брюшная полости — ТРУБЫ, открытые с торцов; объёмная `binary_fill_holes` берёт только замкнутые пузыри |
| **параллельный перенос** кадра сечения | кадр от мировой вертикали вырождается на почти вертикальной оси: ноги выходили скрученными лентами |
| **парный слот мерится с одной стороны** | центр «Рук» садился на среднюю линию, лучи стартовали в пустоте между лап |
| **марш до первого выхода** (было — до последней своей точки) | по залитой отливке правильный ответ первый; «последняя точка» пускала луч вдоль трицепса и давала радиус 0.198 при соседях 0.018 |
| **глубина погружения измеряется по телу** (`sink`) | части входят друг в друга, а не сшиваются кольцом; глубина не может быть числом из головы — у хвоста назад лежит круп, у челюсти затылок в трёх сантиметрах |
| **оболочка черепа попадает в отливку** | форма черепа живёт 49 сечениями с пластины, а в костях `череп` — стержень; обмерщик щупал стержень и возвращал голову коробкой |
| **пояс конечности рисует корпус** (`SURFACE_BONE`) | ось слота шла цепью из пяти костей с изломом в поясе; после переноса — ноль пустых секторов у обеих конечностей, бедро 0.070 → 0.122 |

## Что в работе

**Шов торса и шеи.** В числах: переднее кольцо торса 0.172 вверх / 0.160 вниз (грудь 33 см высотой),
корневое кольцо шеи — кружок радиусом 0.04. Шея выходит из груди спичкой и раздувается только к
следующей станции. Причина системная: **в корне слота собственный обмер занижен хозяином плоти** —
мясо шеи у основания принадлежит торсу. Готовая правка (не применена): корневое кольцо берёт радиусы
следующей станции, оставаясь на своём месте.

## Мины, каждая стоила круга

- **ширину слота нельзя читать из ОДНОГО сектора.** Сектор «вбок» идёт на высоте центра станции, а
  грудь широка ниже неё. По сектору 2 волк вышел 0.160 м («доска»), по максимуму поперечной
  составляющей — 0.260. Ложная тревога стоила полудня;
- **`Object.Destroy` в Blender-скриптах не при чём, а вот `np.interp` при чём**: станции оболочки
  идут в долях длины кости, и путать их с долями оси слота нельзя;
- **имя файла не описывает кадр.** Дважды за день: `moose_skeleton_front.jpg` числился скелетом с
  шириной по кости, а `wolf_front_REFERENCE` — строгим анфасом; под сеткой оба оказались другим;
- **правило обмера, которому нужно исключение, — признак дырки в данных.** Развёрнуто в оценке.
