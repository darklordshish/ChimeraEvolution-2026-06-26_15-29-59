# Прототип «мельче клетка + прореживание» (модельная линия, 23.09)

Проверка одной гипотезы: лоу-поли листа геймдизайнера держится на крупных плоскостях по мышцам, а оболочка поля на клетке
0.042 рисует решётку («шашечка», тёмные проколы) и срезает выпуклости радиусом до ~4 см на 1–2 см (подбородок, задний
пучок дельты, щиколотка). Если собрать поле на клетке мельче и прорядить до того же бюджета треугольников, плоскости лягут
по кривизне формы. Это прототип для механик — оболочка (`BoneMesher`) их зона; здесь только доказательство.

Результат на человеке (поставка 17): клетка 0.021 даёт ~12 500 треугольников поля; прореживание (QEM, симметрия по X) — до
3 500 при 3 000 у клетки 0.042. Независимая рецензия по листу: 4/10 → 5/10 при той же форме, выпуклости не срезаны.

## Как повторить

```
# 1. выгрузить оболочку и блоки вида в OBJ (граф и раскладки — файлы поставки или черновики генераторов)
unity command run_script --file Tools/Blender/prorezhivanie/ExportObj.cs --entry ExportObj.Run --args '["Человек","Docs/models/handoff/chelovek-graph.json","Docs/models/handoff/chelovek-head-layout.json","Docs/models/handoff/chelovek-organs-layout.json",0.021,"C:/temp/h-0021.obj"]'
# 2. склеить оболочку по слотам и прорядить до бюджета
blender -b -P Tools/Blender/prorezhivanie/decimate.py -- C:/temp/h-0021.obj C:/temp/h-0021-3500.obj 3500
# 3. (кадр) собрать стенд с корнем «~СТЕНД» той же клеткой и подменить оболочку прорежённой
unity command run_script --file Tools/Blender/prorezhivanie/ShotObj.cs --entry ShotObj.Swap --args '["C:/temp/h-0021-3500.obj"]'
```

Оговорки прототипа: прорежённая оболочка — статичный меш без весов (для кадра); в игре прореживать надо до скиннинга, а
время сборки поля на 0.021 — в 8 раз больше ячеек (важно, если химер пересобирают в игре). Раскладку головы (глаза, губы)
надо мерить на той клетке, на которой собирается оболочка: `head_layout.py --cell 0.021`.
