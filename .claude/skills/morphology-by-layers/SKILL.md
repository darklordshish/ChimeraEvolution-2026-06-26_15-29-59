# Морфология по слоям

Тело строится **слоями**, части раздаются **парам агентов**, собирает и проверяет **ревизор**.
Полная спека: `Docs/superpowers/specs/2026-08-21-metodika-morfologii.md`.

**Ядро:** три оси — СЛОЙ (когда) × ЧАСТЬ (кто) × РЕФЕРЕНС (по чему). Часть = слот аугумента: тело уже
разделено по этим швам (`Bone.socket`), работа делится по ним же.

## Порядок слоёв — жёсткий

```
1. КОСТИ     конструкция и суставы
2. МЫШЦЫ     объём: грубо, но анатомично
3. ПОКРОВЫ   шкура, шерсть, уши, глаза, пасть
```

Слой не начинается, пока предыдущий не принят пользователем. Приёмка — скрин из Unity с
`SpeciesSO.buildLayers = 1/2/3`. **Свой рендер проверяет меня, а не игру.**

## Роли

| Роль | Делает | Не имеет права |
|---|---|---|
| Ревизор (главный чат) | Референсы, эталоны, брифы, мерж, сборка целого, стыки, запись в файлы | Строить части сам, пока их строят пары |
| Скульптор | Строит кости своей части, отдаёт фрагмент + **свой замер** | Чужие части, общие файлы, пограничные суставы |
| Критик | Меряет ту же часть по тем же референсам, отдаёт «где и насколько» | Править данные |

Ревизор — единственная точка сборки: **дефекты живут на стыках**, а стык не виден изнутри части.

## Цикл слоя

1. Ревизор готовит бриф (шаблон ниже) на каждую часть.
2. Скульптор строит, прикладывает прогон детектора.
3. Критик меряет, отдаёт расхождения числами.
4. Ревизор мержит, строит целое, проверяет стыки → шаг 2, пока не сойдётся.
5. Ревизор пишет в `<вид>.py` → `SpeciesBootstrap.cs`, просит «Chimera → Создать дефолтные виды».
6. Пользователь принимает слой скрином. Не принял — на шаг 1 с его «где и насколько».

## Правила

1. **Референс — изображение, а не таблица.** Файл на диске в `Anatomy/species/<вид>/ref/`, смотреть
   через Read. Текстовые промеры применяются только поверх увиденного.
2. **Работа без замера не принимается.** Нет прогона детектора — ревизор фрагмент не читает.
3. **В общие файлы пишет только ревизор.** Агент возвращает фрагмент — кости своего слота.
4. **Пограничные суставы заморожены.** Двигать через ревизора.
5. **Бриф самодостаточен** — агент стартует холодным.
6. **Эталон снимается с натуры**, попиксельно. Ни числа «из общих соображений».
7. **Поза референса ≠ нейтральная стойка.** С монтажа и экорше берут устройство, углы — с фото
   живого зверя.
8. **Детектор считает ИГРОВОЕ поле.** Правишь `BoneMesher` — сверяешь детектор в тот же заход.
9. **Часть мерится в масштабе части.** У головы свой контур и свой порог.
10. **Имя = анатомия + слой** (`.м`/`.п`/`.р`).

## Шаблон брифа

```
ЧАСТЬ: <слот>          СЛОЙ: кости|мышцы|покровы          ВИД: <вид>
РЕФЕРЕНСЫ (смотреть через Read, не описания!):
  Anatomy/species/<вид>/ref/skeleton/...   — устройство
  Anatomy/species/<вид>/ref/photo/...      — углы и пропорции
ЭТАЛОН ЧАСТИ: Anatomy/species/<вид>/etalon/<часть>.py   (контур + порог)
ЗАМОРОЖЕНО: <суставы на границе> — не двигать, запросить у ревизора
ТЕКУЩИЕ ДАННЫЕ: <кости части из <вид>.py>
ДЕТЕКТОР: python Anatomy/tools/render.py --part <слот>
ВЕРНУТЬ: (1) фрагмент — только кости своего слота; (2) вывод детектора;
         (3) что НЕ удалось и почему.
ЗАПРЕЩЕНО: править общие файлы, трогать чужие части, отдавать числа без замера.
```

## Красные флаги — остановись

- «Численные проверки чисты» — а картинку смотрел? Метрика мерит лишь то, что догадались померить.
- Правишь часть, не открыв ни одного референса.
- Двигаешь деталь, потому что метрика показала расхождение, — это ремонт, а не конструкция.
- Эталон собран из чисел, а не снят с фотографии.
- Взялся за мышцы, а кости не приняты пользователем.
- Часть тела описана «одной костью плюс объёмы сверху» — конструкции нет.

## Отговорки — из реальных провалов

| Отговорка | Реальность |
|---|---|
| «Двадцать проверок ok» | Уживается с демоном на экране: голова — десятая часть пикселей профиля |
| «Расхождение с эталоном упало вдвое» | Эталон бывает перевёрнут. У волка голова ВЫШЕ спины, а выдуманный эталон вёл линию вниз |
| «Слои есть в коде» | Наличие `buildLayers` ≠ приёмка по слоям. Ни разу не показать голый скелет — значит слоёв нет |
| «Подвину на два сантиметра» | Если части нет как конструкции, двигать нечего. Конус с наростами останется конусом |
| «Агент найдёт референсы» | Принесёт текстовые промеры — тот самый источник, что посадил глаз внутрь черепа |
| «Свой рендер показывает нормально» | Он дважды расходился с `BoneMesher`. Рендер не того поля вреднее отсутствия |
