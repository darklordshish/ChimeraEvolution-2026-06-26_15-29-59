# Раздача моделей: кто какую работу делает и на чём

Лимиты Anthropic общие на все сессии линий (ГеймБосс, Модельный, Лесник, субагенты). 22.10 недельный лимит кончился у
двух линий разом и встал на пять дней. Правило одно: **работа идёт на самом дешёвом исполнителе, который делает её
надёжно**. Модель исполнителя выбирается явно при каждом запуске. Унаследованная по умолчанию модель — тоже выбор, и
обычно неверный.

## 1. Таблица раздачи

| работа | исполнитель | почему |
|---|---|---|
| найти файлы и места, прочитать и пересказать логи, сводка документов, «где это записано» | субагент `Explore` или `general-purpose` с `model: "haiku"` | чтение и поиск не требуют суждения; ответ проверяется по путям |
| опрос доски, расписания, сверка статусов, перенос файлов, переименования | `haiku`; если нужно без лимита Anthropic — opencode `-free` (§3) | механика |
| правки по готовому плану, тесты к ясному правилу, прогон и разбор красных, рефактор по образцу | `model: "sonnet"` | код по образцу; план и решение уже есть |
| ресёрч в вебе со сводкой | `sonnet` | широко, но без архитектурного выбора |
| спека, архитектура, развилка, баг с неясной причиной, правило конструктора | **сам** (основная модель сессии), не субагент | решение остаётся у того, кто держит контекст |
| **критик формы** (`model-critic`) | основная модель, **без понижения** | его оценка — порог показа 8.5; дешёвый критик обесценивает порог |
| дизайн-взгляд, разбор по массам, лист для модельной | Codex (дизайн-линия), свежая `codex exec` (§3) | не из лимита Anthropic; независимый глаз |
| второе мнение по коду или тексту | opencode `-free` (§3) | не из лимита Anthropic, другая модель семейства |

Сомневаешься между двумя строками — бери дешёвую и проверь результат. Перезапуск на дорогой модели дешевле, чем дорогая
модель на каждую мелочь.

## 2. Как задавать

- **Субагент:** `Agent({ subagent_type, model: "haiku" | "sonnet" | "opus" | "fable", prompt })`. `effort` — только если
  геймдизайнер или этот навык прямо велят. Форк (`subagent_type: "fork"`) всегда на модели сессии — для дешёвой работы не
  годится.
- **Отдельная сессия:** `start_session({ ..., model: "<id Sonnet/Haiku>", effort })` — только той же семьи или дешевле.
  Сессия, которая только читает, — дешёвая модель и `use_worktree: false`.
- **Бриф субагенту самодостаточный:** пути, что считать ответом, формат ответа коротким. Длинный ответ субагента —
  мои токены на чтение.
- **Ответ дешёвого исполнителя — данные, не истина.** Проверить по месту (открыть файл, строку, прогнать) до того, как
  на нём строить.

## 3. Внешние исполнители (не из лимита Anthropic)

- **opencode** (подписка геймдизайнера OpenCode Go): из ПАПКИ ПРОЕКТА, `opencode run --pure -m opencode-go/beam-free "…" < /dev/null`.
  **Только модели с `-free` в имени — они $0.** Остальные списываются с подписки (лимит Go: $12 за 5 ч, $30 в неделю) — без
  слова геймдизайнера не брать: подписку ест и лесная команда. Папку `-les` не трогать — там её конфиг и навыки.
  Подробности — память `chimera-opencode-konsol`.
- **Codex** (дизайн-линия): `codex exec -s workspace-write -c 'notify=[]' -` в папке `-codex`, **новой сессией** (~50–90 тыс.
  токенов на задачу). Возобновлять большой тред — около 5 млн токенов на любой ход. Только при закрытом приложении Codex
  (проверить процессы `OpenAI`); коммит — за координатором. Память `chimera-codex-konsol`.

## 4. Дорогие проверки — по вехам

- **Unity headless**: поднимать под блок команд и закрывать в конце (`Tools/Agent/Quit.cs`). Брошенный редактор съел ОЗУ 22.10.
- **Критик**: на вехе (новый вид, новая схема, ряд к показу), не на каждую правку. Между правками — машинные детекторы:
  тесты, карта тел, стенд модельной линии в Blender (~15 с на ступень).
- **PlayMode** (~1–2 мин): когда тронуты психики, сцены или доставки. EditMode гоняет гейт на каждый пуш в `main`.

## 5. Сторож

Перед запуском агента или сессии — одна мысль: «какая строка таблицы?». Нет подходящей строки — значит работа
решающая, делать самому. Таблица меняется по опыту: дешёвая модель стабильно ошибается в работе какого-то рода —
поднять её строку и записать сюда, когда и почему.
