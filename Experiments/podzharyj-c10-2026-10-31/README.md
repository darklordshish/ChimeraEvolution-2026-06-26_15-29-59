# Продолжение поджарого человека c9 → c13

31.10.2026, Codex, по прямому поручению геймдизайнера временно продолжить задачу модельной линии.

Результат и ограничения: [пакет c13](../../Референсы/работа/дизайн/podzharyj-chelovek-c13-2026-10-31/README.md).

Вход `c9.blend` — **kc9e.blend**, сохранённый рабочий файл модельной линии для c9, коммит исходников `7f5cace7`. Восстановлен из её scratchpad; SHA-256 — в `sources.json` пакета. Все операции и выходы — в папке Codex. Чужой worktree не изменялся.

`run.ps1` воспроизводит кандидата, проверяет инварианты, экспортирует FBX и снимает две диагностические серии. Запускать PowerShell 7; Blender 5.2. Все имена и пути передаются аргументами, оболочка не собирает текст команды из путей. Файл `.blend` сохраняется с нулевыми ключами, как ожидает экспорт: для просмотра включить **Поджарый = 1**; позовый корректор по умолчанию выключен.

## Шаги

1. `refine_c10.py`: перестройка плохих диагоналей с пробой настоящего winding Blender на временном BMesh, проверкой цели и базы; линии переломов защищены. Ограниченная правка глубины груди и подмышек. Вершины, риг и веса не добавляются.
2. `pose_guard.py`: ограниченная подгонка **только экспериментальной цели** по знаку площади треугольников в покое и диагностических позах 40°, 70°, 100°. Швы решаются общими переменными. Это не анатомический детектор и не доказательство качества формы; без просмотра может испортить покой.
3. `build_c13.py`: не переносит эту экспериментальную цель в покой! Разность с ней записывает отдельным относительным ключом **Поджарый·ПодъёмПлеч**, вес 0. Нейтральная форма остаётся от шага 1. Численно проверяет композицию двух ключей.
4. `verify_invariants.py`: сравнивает координаты базы, риг, веса, инвентарь и координаты остальных ключей, число треугольников. Разрешает только ожидаемый новый корректор.
5. `eksport_k2.py`, `stend_k2.py` — снимки инструментов Клода из `7f5cace7`; в стенд добавлены **явно диагностические** угол подъёма рук и угол камеры. Это не новая реализация игрового `KeyPose` и не анимация игры.

## Отбракованные пробы

- Первый c10 с гипотетическим winding треугольников давал развороты; проверка заменена фактическим поворотом на копии BMesh. В кандидат не входит.
- c11 исправлял одну позу, но не переносился на другие углы.
- c12 решал несколько углов, однако давал лишние изломы боков/спины в покое. Не выбран как база; используется только для построения необязательного позового корректора.

Временные blends, рендеры проб и резервные `.blend1` остаются локально и исключены через `.gitignore`. Финальный c13, исходный c9, скрипты и выбранные отчёты сохраняются. Полный запуск `run.ps1` как единой команды после оформления пока отдельно не прогонялся; его стадии были выполнены по отдельности с теми же параметрами. Unity не запускался.
