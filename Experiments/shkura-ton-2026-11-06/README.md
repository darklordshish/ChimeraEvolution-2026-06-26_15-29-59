# Воспроизведение пробы Шкуры

Изолированный опыт 06.11.2026. Художественный результат и ограничения — `Референсы/работа/дизайн/shkura-po-granyam-2026-11-06/README.md`.

Источник `source.fbx` заморожен из модельной папки. `inventory.py` импортирует его и сохраняет `source.blend`. Снимки `ton_kozhi-source.py`, `eksport_k2-source.py`, `organy-source.json` — для воспроизводимости, не второй источник правил.

Порядок в Blender 5.2, каждая команда с `--python-exit-code 1`:

1. `inventory.py`.
2. Открыть `source.blend`, запустить `ton_kozhi-coarse.py` с аргументами после `--`: `<эта папка>/snake-coarse.blend Шкура Змея --obj хребет,шея,Сердце,Руки --shag 0.065 --kromka 0.006 --tony 1.0,0.84,0.64`.
3. `build.py`: формирует `candidate.blend` и проверяет точное сохранение вершин/ключей/весов относительно подготовленной геометрии покрытия. Местная версия coarse отличается от снимка исходника лишь отключением полушага и дополнительных резов кромок; художественная раскраска в `build.py`.
4. `inspect_surface.py`, `check_coverage.py`, `verify_interpolation.py` — соответствующие JSON. `check_coverage.py` дополнительно читает оставшийся `snake-coarse.blend` и раннюю пробу `snake-expanded.blend` не использует; `check_degenerate.py` — диагностический исторический скрипт ранней пробы.
5. `render.py -- original`, затем `render.py -- proposal`. Тоны рендерятся как множители одной базовой окраски, без проверки игровых эмоций. Камеры одинаковы.
6. `export.py`, затем `verify_fbx.py`: удаляет объекты сравнения только из экспортной копии, штатный экспортёр проверяет веса, проверка повторно импортирует FBX.
7. `compose.py` через Anaconda Python собирает листы из рендеров.

`candidate.blend` содержит спрятанные при рендере исходные тоновые объекты с префиксом `ИСХОДНИК_`; для передачи FBX экспортировать через `export.py`, а не всю сцену вручную. `candidate.fbx` содержит все исходные органы/черты остальных видов, но только выбранные новые тоновые объекты Волка/Змеи. Старый рисунок Лося не изменён.

`snake-expanded.blend` — ранний опыт с частой сеткой, не итог. `snake-coarse.blend` — промежуточная кожа до новой раскраски. `source.blend` — исходник для сравнения. В итоговом FBX игровые правила видимости не включены: `organy-source.json` — снимок, не обновлённая конфигурация.
