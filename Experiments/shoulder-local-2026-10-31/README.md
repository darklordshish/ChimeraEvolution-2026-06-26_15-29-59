# Локальная проба плеча, 31.10

Разрешённый геймдизайнером опыт на копии support.blend. Только сторона +X; противоположная сторона остаётся контролем. Поджарый=1, позовый ключ выключен. Новых вершин и костей нет. Сначала диагонали треугольников, затем ограниченное перераспределение двух уже существующих весов.

До прогона: сравнить покой, подъём 45/70/90/100°, движение вперёд 60°. Сохранить все координаты и ключи, 5738 треугольников, максимум четыре влияния и согласованные веса общих швов. Не допускать увеличения числа отрицательных ориентированных площадей в проверяемой области ни в одной из этих поз. Изменение направления нормали — диагностический признак, не оценка анатомической достоверности. Окончательная оценка — по одинаковым кадрам. Нет обещания исправить все складки.

Это проба, не игровая поставка. Витрина, Assets и чужая папка не меняются.
