# Памятка морфолога (Скульптор) — 05.09.2026

**Проект:** Рогалик по флоу, Unity 6 URP, 5 видов (Человек/Волк/Змея/Лось/Ёж), 25 особей 20k трис. Точка входа `Docs/СТАТУС.md` → `УКАЗАТЕЛЬ.md` → `CONSTRUCTOR_GUIDE.md` → `SPEC-kletka-tela.md`.

**Сокет-план:** `SpeciesSO.cs` + `BodySlots.cs` — 12 слотов (`хребет` Chassis, `Тело`/`Погремушка` Chassis, `Пасть`/`Чутьё`/`Сердце`/`Шкура`/`Руки`/`Ноги` Base, `Хвост`/`Рога`/`Игломёт` Appendage) + 7 мест. Правило: `имя сокета == Organ.slot`, `visualPart` нет. Флаги `inner`/`graft`/`codeDriven`. Граф `parent+attach+attachOffset`, корень `хребет` (змея — голова).

**Клетка:** `M станций × N секторов`, `M,N` одинаковы у всех видов → `Σ вес·таблица × калибр`. Бюджет 324 квада ~830 трис (хребет 8×10 ADR-1, было 310/8×8; … Пасть 4×6). Станции на ландмарках (`таз→колено→…`), не равномерно. Швы — общее кольцо N, Пасть исключение.

**Оси:** длинная ось = max `baseSize`, запас ≥5%. При смешении `axisOf` приколота по чистому шасси.

**Детектор:** `Chimera → Выгрузить карту тел` → `КАРТА_ТЕЛ.md` (реальный `MorphBuilder`, ближайшая пара деталей). Пороги: щель 8%, нахлёст 75%, запас 5%.

**Гочи:** `Destroy` отложен → `~dead`, `CC` перебивает `position`, `SerializeField 0` → дефолт, `FindAnyObjectByType`, `Blender (-90,0,0)`, неравномерный масштаб → пустой узел, торец капсулы → шар.

**Мастерская:** `Anatomy/README.md` — тело только отсюда, не из `SpeciesBootstrap`. Инструменты `skel.py`/`audit.py`/etc. Референсы локально, в git `REFS.md`.
