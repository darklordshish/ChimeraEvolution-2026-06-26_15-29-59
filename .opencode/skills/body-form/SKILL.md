# Body Form (CHIMERA, с 13.10)

**Источник формы — цельный меш вида, химера — из кусков тех же мешей.** Поле (оболочка по графу)
остаётся рабочим телом только у непереведённых видов; новое под поле не писать.
Правило — `CONSTRUCTOR_GUIDE.md`, «Перевести вид на меш и нарезать на куски»; довод и история —
`Docs/superpowers/specs/2026-10-09-chistyj-vid-meshem.md`.

## Что где

- `Assets/_Chimera/Models/<вид>_mesh.fbx` — меш вида: объект на слот, имя объекта = слот,
  `слот.что` — кусок со своим цветом. `BodyMesh` сажает по ИМЕНАМ костей; повороты/масштаб экспорта
  не важны, важны имена и поза привязки.
- `BodyMesh.FieldOnly()` — путь детекторов; в игре — `BodyMesh.FitsChimera` (вариант Б, 19.10):
  шасси с мешем рисуется мешем при любой прививке, орган без куска на силуэте не виден.
- `PartPieces.cs` — нарезка/посадка кусков по шву; `PartAssembly.MeshPieces` по умолчанию `true`.
- `Docs/models/handoff/` — `parts/`, `cherty/`, `<вид>-head-layout.json`, `<вид>-organs-layout.json`,
  `klyuchi/`, `organy/<вид>.json`. Числа в код не переписываются: читает `SpeciesHandoff`.
  Оговорка на 24.10: в `main` каталога `organy/` ещё нет (файл едет из модельной линии) — это
  известный долг учёта, а не разрешение молча не загружать правило.
- `BodyMesh.KeysFor` — форма-ключ вида; правая колонка листа на ЧУЖОМ шасси = ступень 2
  (`KeyStep1` — ступень 1). Ступень 3 достижима только на родном шасси.
- `BodyMesh.OrganObjectsFor` — объект `<слот>@<вид>` на шаблоне (уши Чутья, когти Рук). Виден только
  с прививкой органа, растёт ключом `рост`, снимает свои объекты по `handoff/organy/<вид>.json`.
- Рост — по массе: `GlobalLayer.Growth`, `SpeciesSO.mass`, `BodySize`/`formScale`. Длины ∝ M^(1/3),
  визуал масштабируется целиком, физика/камера пересчитываются, дальности приёмов — нет.

## Законы

- Форма вида живёт в файле поставки, а не в `SpeciesBootstrap`; правишь `handoff/`/модель, не числа в коде.
- Куски — по принадлежности: орган приезжает графтом, черта — ступенью; «посадочное место» — кольцо
  на сплошной коже. Своему шасси кусок не ставится.
- Смешение: пропорции — от идентичности, калибр и топология — от шасси; у корня `хребет` пропорция
  не выражается. Смешение включено, чистых видов не ждёт.
- Шов двигается только у самого шва (`Fit.Weld` + `WeldBand`/`WeldLimit`), а не по всему мешу.
- Сначала числа, потом глаз: карта/силуэт/матрица/размеры, затем кадр. Дефект — «где и насколько».
