# Morphology by Layers — ⛔ ОТМЕНЕНА 10.09.2026

Этот скилл описывает **отменённый метод**: тело лепилось костями, затем мышцами и покровами,
а химера считалась смешением клетки M×N. Метод отменён вместе с посылкой «анатомическая кость —
источник формы»; кости остались только ригом.

**Не использовать для новых тел.** Действует `body-form`: цельный меш вида + куски по швам.

## Что пережило отмену

- Эталон снимается с референса-картинки, а не собирается из промеров (выдуманный эталон однажды
  оказался зеркальным, и «схождение 2.1 см» было схождением с выдумкой).
- Оценку референсу ставить, только открыв картинку; паспорт по имени файла врал трижды.
- «Где и насколько» вместо «плохо»: дефект переводится в число.
