# Docs Sync (CHIMERA)

## Три сорта (`УКАЗАТЕЛЬ.md:8-14`)
- **Генерируемые** `Диаграммы/` — руками не править, числа оттуда.
- **Живые** `GDD`, `CONSTRUCTOR_GUIDE`, `СТАТУС`, `Паспорта`, `УСТРОЙСТВО_ТЕЛА` — ведутся руками, обновляются на каждом этапе.
- **Спеки** `superpowers/specs/` — снимок на дату, не обновляются задним числом, ищи преемника.

## Чеклист
- [ ] `Docs/СТАТУС.md` — точка входа: дата сверки, §1 где мы абзацем, §3 что сделано, §5 что дальше, §7 решено. Обновляет `orchestrator`+`docs-keeper` при смене этапа. Если разошёлся с `КАРТА_ТЕЛ` — прав отчёт.
- [ ] `Docs/УКАЗАТЕЛЬ.md` — аннотации сняты с текста, не имени.
- [ ] `GDD` резолвнутое не переоткрывать (`CLAUDE.md:9`).
- [ ] Новый вид/орган/способность/химера-NPC — через `CONSTRUCTOR_GUIDE.md` рецепты, тюнинг-карта, проверить `BodySlots`/`ValidateSockets`.
- [ ] Крупное → спека в `specs/` (spec-first), план в `plans/` если строительная.

Хранитель `docs-keeper` — единственный кто помнит 79 доков и ловит дрейф терминов.
