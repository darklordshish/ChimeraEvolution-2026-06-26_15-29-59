# Spec-first (CHIMERA)

Крупная фича без спеки — гадание вслепую. В CHIMERA так уже потеряли недели на морфологии.

## Когда триггерить

Новый орган/способность/вид, новая психика, новый закон конструктора, смена источника формы,
новый слой мира (лес/павильон), рефактор ядра, крупный UI. Если не знаешь — спроси `docs-keeper`,
где это уже записано.

## Воркфлоу

1. **Спека** — `Docs/superpowers/specs/YYYY-MM-DD-<slug>.md`: проблема → довод → решение → инварианты →
   что НЕ делаем → преемник/отмена. Спека — запись решения НА ДАТУ, тело после принятия не правится,
   меняется шапка. Один действующий источник (спека `2026-09-11-odna-liniya-partii.md`).
2. **План** — `Docs/superpowers/plans/<same>.md`, если работа строительная: файлы, код, команды
   проверки, точки коммита. Для чисто структурной спеки плана может не быть.
3. **Код** — вертикальными срезами: игра играбельна после каждого шага. Абстракцию вытаскивать после
   2–3 непохожих примеров (правило трёх), не раньше.
4. **Проверка** — тесты/детекторы (`chimera-testing`, `chimera-validation`), форма — кадром.
5. **Доки** — `СТАТУС`, `УКАЗАТЕЛЬ`, шапки спек; `python Docs/tools/spec_status.py` должен быть чистым.

## YAGNI-чек

- Есть ли ≥2 носителя? (мульти-сенс ждал второго вида.)
- Экономит ли 3+ дубля или чинит реальную щель/дрейф?
- Можно ли отложить, не ломая текущий срез?
- Не переоткрываем ли уже решённое (`GDD`, `CONSTRUCTOR_GUIDE`, `СТАТУС` §«Решено»)?

Если нет — режь слайс или откладывай. Математик предлагает, команда осаживает — это норма.
