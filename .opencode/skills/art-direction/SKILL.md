# Art Direction — CHIMERA low-poly атмосферный

**GDD §9 + СТАТУС:140-150 — стиль покупает бюджет.**

- **Low-poly фасеточный ≈830 трис/зверь** (324 квада, хребет 8×10 ADR-1; было 310/800), 25 зверей ≈20.7k. Экономия → свет, туман, тени, VFX. Рефы: **VOIN** (тон мрачный брутальный), **Valheim** (техника дешёвой красоты), **Boltgun** (вес+скорость).
- **Силуэт первичен:** узнаёшь «человек+волк» по контуру без текстур. Фасеточная грань — не приближение к гладкости, а стиль (`SPEC-kletka:164`). Излом на шве — ок, щель — нет.
- **Атмосферность:** цветокор/LUT по зонам, объёмный туман, реалтайм тени — почти бесплатно на low-poly. Перцепция (термо/эхо) — пост-пассы поверх.
- **Язык трансформации:** органично, не вивисекция. Модульность в системе/UI, органика на теле: аугумент *прорастает* (когти, мех), свап = переморфинг + короткая мясная VFX, не шов. Ужас в неправильности тела.
- **Шкала мозга — аватар игрока** интерполирует к вервольфу «Ван Хельсинг» (двуногий звероподобный). Босс Вервольф = полюс воплощён — предупреждение.
- **Конструктор — тетрадь да Винчи** (GDD §6): витрувианец морфит, слоты-выноски, созвездия родства.

## Чеклист на любую модель
- [ ] Бюджет держит 800? 25× влезает?
- [ ] Силуэт читается в профиль + анфас с 10м?
- [ ] Фасетка, не смус? Свет/туман дороже полигонов?
- [ ] Трансформация — прорастание, не пришивание? VFX есть?
- [ ] Профиль/анфас/сверху сверены, не только профиль?
- [ ] Портретная узнаваемость химеры локальна (морда волчья, ноги свои)?
