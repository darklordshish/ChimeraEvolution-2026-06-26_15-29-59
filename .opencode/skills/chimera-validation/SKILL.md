# Chimera Validation — детектор, а не описание

Детекторы строят объект настоящим билдером и меряют результат, поэтому разойтись с игрой не могут.
Числа брать отсюда, а не из пересказов.

## Детекторы формы

| что | команда / файл | что ловит |
|---|---|---|
| карта тел | `Chimera → Выгрузить карту тел` (`chimera-map`) → `Диаграммы/КАРТА_ТЕЛ.md` | габариты, стыки, щели/нахлёсты |
| силуэты | `chimera-silhouette` → `Диаграммы/СИЛУЭТЫ.md` | IoU против маски листа, читаемость |
| химеры | `chimera-matrix` → `Диаграммы/ХИМЕРЫ.md` | каждая пара «шасси + донор»: поломки по аугментам |
| размеры | `Tools/Agent/GameSizes.cs` → `Диаграммы/РАЗМЕРЫ.md` | рост по массе, `BodySize`, `formScale` |
| кадры | `Диаграммы/Кадры/` (`ShotSpecies` + `capture_game_view`) | то, чего числа не ловят: силуэт, двойная геометрия, оторванные детали |

Карта/матрица/выгрузки формы идут через `BodyMesh.FieldOnly()` — то есть меряют поле формы, а не
старую клетку. Если детектор и текст расходятся — прав детектор.

## Как меряет

- Стык — по БЛИЖАЙШЕЙ ПАРЕ ДЕТАЛЕЙ, не по коробкам мест: коробка прощает щель (у рогов — метровую).
- Порог от детали шва: щель — толщиной, нахлёст — глубиной. Пороги берутся из распределения фактов,
  а не назначаются; валидатор не должен кричать на намеренное.
- Ось `axisOf` не переключилась после правки `baseSize`; мерить в той же системе координат.
- После сборки — `Telegraph.RebuildRenderers()` и `PlayerController.ReapplyFirstPerson()`, если менялись имена.

## Что чем принимается

- **Логика, числа, инварианты** — тесты (`chimera-testing`) и детекторы; плейтест не обязателен.
- **Форма: силуэт, стыки, пропорции, двойная геометрия** — кадр + карта/силуэт/матрица; плейтест не обязателен.
- **Как играется: отзывчивость, вес, читаемость боя, звук** — только геймдизайнер.

## Мир

Для леса тот же жанр, но своя зона: `Docs/Диаграммы/Лес/` (рельеф, крутизна, кадры купола). Не смешивай
детекторы формы тела с картой мира: у них разные билдеры и разные вопросы.
