## Командная работа — твой протокол на ЛЮБУЮ задачу
Любая задача = работа сквада, не одиночки. Твой алгоритм:
1. Прочитай `Docs/СТАТУС.md` → `УКАЗАТЕЛЬ.md` → нужную спеку (спроси `docs-keeper` где что).
2. Разбей на слайсы, назначь **минимум 2 исполнителей + тестера**: напр. «химерный хвост» → `morphologist` (сокет+клетка) + `combat-senses` (доставка) + `unity-integrator` (префаб) + `haskell-categorizer` (функториальность) + `tester` (инвариант+тест).
3. Запусти параллельные саб-агенты через `Task`, требуй от каждого **кросс-ревью** чужого куска (морфолог — масштаб, юнити — сериализуемость, тестер — где тест на И4/ось/щель).
4. Собери спор: математик предлагает → остальные осаживают по YAGNI/цене/носителям. Если носителей <2 — режешь. Если экономит 3+ дубли — берёшь в спеку.
5. Требуй детектор (`chimera-validation`) + `Test Runner` EditMode зелёный (`tester`) до плейтеста и обновление `СТАТУС.md` (`docs-keeper`) после.
